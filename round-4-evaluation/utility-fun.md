## U1: 작가 마케팅 OS (출간 D+1~D+180 자동 콘텐츠 + 캘린더)

### 재진입률 (8점)
- **점수: 4/8**
- **분류**: 출간 후 첫 2-3개월 매주 → 그 후 급감 (1회 셋업형 + 매주 검토 단기)
- **근거**:
  - user-sim 민티 본인: "출간 한 번 한 책 마케팅 = 출간 후 첫 2-3개월만 적극. 180일 캘린더 매일 사용 = 의심." (자가 의심 강함)
  - user-sim 수강생: "출간 후 페인 한정. 슬럼프 단계엔 안 씀" - 출간 후 3개월 후 사용 빈도 0 추정
  - Devil's advocate 정확: "콘텐츠 만들 시간 없는 작가가 자동 콘텐츠 검토할 시간이 있나" - 책 한 권 출간 후 다음 책 1-2년 = 매월 도구 회귀 약함
  - Shimmr / Book Blaster / ManuscriptReport (WebSearch 결과) 모두 "launch toolkit" 출간 시점 집중 = 같은 패턴 (출간 첫 분기 집중 후 급감)
  - **재진입 패턴**: 출간 D+1~D+30 매일 → D+30~D+90 매주 → D+90~D+180 월 1-2회 → D+180 이후 0 (다음 책까지)
- 매주 = 5-6점 한도지만 "출간 단기 집중 → 장기 0" 패턴 차감 = 4/8

### wow moment (6점)
- **점수: 4/6**
- **5분 이내 wow 시나리오**: 원고 EPUB 업로드 (5분) → "내 책 톤 학습 + 타겟 페르소나 3종 추출" 3분 대기 → 180일 캘린더 자동 생성 화면 = 약 8분
- **근거**:
  - 5분 이내 wow X (원고 업로드 + 톤 학습 = 8분). 단 "출간 후 페인 #1" 페인 강도가 만성 우울 수준이라 wow 약해도 페인 해결 시그널이 wow 대체
  - 인용구 100개 자동 생성 = 캡션 양 보면 "와 이 정도 양?" wow 시그널 있음
  - 단 "이 콘텐츠 진짜 쓸만한가" 의심이 wow 차감 (Devil's advocate: 양 많아질수록 품질 의심)
  - ManuscriptReport (WebSearch): "20-30 ready-to-post social posts with accompanying imagery" 동급 wow 패턴 = 직접 비교 도구 존재
- 즉시 가치 부분 충족 (페인 강도) + 셋업 시간 8분 차감 = 4/6

### 유용성 vs 흥미 균형 (6점)
- **점수: 4/6**
- **분류**: 유용성 강 / 흥미 약 (출간 후 마케팅 절벽 해결 = 유용 매우 강함. 단 "와 신기" 시그널 X)
- **근거**:
  - 유용성: 페인 #1 (만성 우울 수준) 직격 + 180일 자동 캘린더 = 시간 절약 50시간+ → 유용성 5-6/6 수준
  - 흥미: "내 책 톤 학습한 AI" 자체는 흥미 신호 약함. 캐릭터.AI 같은 단톡방 X, 그저 콘텐츠 자동 생성 = 흥미 1-2/6
  - 한쪽 강 = 4-5점 분류. 유용성 압도적 강 = 4/6 (5/6 받으려면 흥미도 일부 시그널 필요한데 0)

- **근거**:

  - user-sim 구독자 부업(매우 강함): "인스타+유튜브+블로그 매일 결정 페인 = 분신 컷 = 시간 절약" 매일 보장
  - user-sim 사장(대행): "대행이 사용 = 콘텐츠 발행 효율 상승" 대행이 매일 사용
  - WebSearch (Blue Pill AI Pre-Testing): "페르소나 시안 평가" 사용자 후기 = 1회 평가 vs 자가 컷 권한 = 자가 컷 권한 = 매일 사용 빈도 더 높을 추정 (의사결정 피로 해결)
  - **재진입 패턴**: 매일 시안 던지기 + 분신 컷 확인 = 주 5-7회. 단 1-2주 후 통제권 트라우마 해지 트리거 = 장기 retention 의심
- 매일 = 7-8점. 통제권 트라우마 차감 1점 = 7/8

### wow moment (6점)
- **점수: 5/6**
- **5분 이내 wow 시나리오**: 시안 7개 던지기 → 분신 5명 자기들끼리 토론 시뮬레이션 (실시간) → 3-4개 자가 컷 + "왜 컷됐는지" 한 줄 요약 출력 = 약 1-2분
- **근거**:
  - 즉시 wow 시그널: "AI가 너 대신 잘라줬어" = 의사결정 피로 해결 즉시 시그널. user-sim 구독자 "매일 결정 30분 → 5분" 시간 절약 wow
  - 흥미 wow 시그널: "분신이 자기들끼리 토론하면서 컷" = visual wow + 캡처 바이럴 (단톡방 캡처 유사)
  - 약점: "AI가 잘라준다" 통제권 상실 트라우마 = 첫 5분 wow는 강하나 1-2일 후 "내가 손맛 잃은 느낌" 의심 트리거 - 첫 wow 강 + 후속 의심 = wow는 6/6 받으나 약점 차감 5/6
  - WebSearch (Blue Pill AI Personas Pre-Testing 사용자 후기): 평가만 vs 자가 컷 권한 = 자가 컷이 wow 강도 더 높음 추정 (의사결정 결과 즉시 = 1초)
- 즉시 wow 강 + 통제권 트라우마 약점 = 5/6

### 유용성 vs 흥미 균형 (6점)
- **점수: 5/6**
- **분류**: 유용성 강 + 흥미 일부 (시간 절약 압도 + 분신 토론 캡처 바이럴 흥미)
- **근거**:
  - 유용성: 매일 결정 30분 → 5분 = 매일 시간 절약 (월 7-10시간) + 콘텐츠 발행 효율 = 5-6/6
  - 흥미: "분신 5명이 자기들끼리 새벽에 토론하면서 내 시안 잘라줌" 컨셉 자체가 흥미. "AI 분신이 내 콘텐츠 잘라준다" 행글라이터 영상 = 흥미 시그널. 단톡방 시뮬레이터 답습 (V3) 의심 일부 = 흥미 4/6
  - 둘 다 일부 강 = 5/6 (둘 다 6/6 강은 F2만 충족)

### 유용성·흥미 종합 점수: **17/20**
