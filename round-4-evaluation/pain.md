## 후보별 평가

### #11 카톡방 정치 시뮬레이터 → **24/30**

- **페인 강도 (7/10)**: 단톡 페인 강도는 "안 죽을 페인". 카톡 단톡 평균 10개+ (R1 pain.md 카테고리 10) → 시댁 단톡 / 학부모 단톡 / 회사 단톡 → 매번 톡 보내기 전 신경 쓰임. 단 "이 톡 잘못 보내서 인생 망함" 수준은 X (전세사기 강도 10 대비 7).
- **다수성 (10/10)**: 한국 카톡 점유율 95%+ (R1 pain.md). 사실상 거의 모든 한국 성인. user-sim 5명 중 4명 7+ 통과 (영수 45세 제외) = 20-30대 약 1500만 + 30-40대 직장인 일부 = 약 2000만+ 즉시 시장.
- **매일성 (9/10)**: 단톡 보내는 행동 자체는 매일 수십 회. "보내기 전 시뮬" 호출 빈도는 보낼 톡이 진짜 신경 쓰일 때 = 매일 1-2회 추정. user-sim 민지(스타트업 마케터) "매일 1회+ 사용" 직접 진술.
- **페인이 진짜? (운세류 X)**: ✓ 진짜. 매일 한국인이 카톡 보내며 머뭇거리는 실제 행동. 운세/심리테스트 X.
- **약점 자가 의심**: 영수(45세 부장) 페르소나 user-sim 4점. **40대+ 부장급 시장 제외 = 다수성 10점이 부풀려진 면 있음**. 다수성을 9로 깎을지 고민했으나 20-30대 + 마케터/직장 1년차/크리에이터 = 한국 직장인 다수 매칭으로 10 유지.
- **점수**: 7 + 10 + 9 = **27 → 자가 인플레이션 의심으로 -3 차감 = 24**
- **차감 사유**: (a) 영수 페르소나 약함으로 다수성 실질 9. (b) "보내기 전 시뮬" 호출 빈도 일 1회는 매일 9가 좀 후함. 진짜는 7-8.

### #15 카톡 1년 wrapped → **17/30**

- **페인 강도 (5/10)**: ⚠️ **결정적 균열**. "1년 카톡 회상 욕구"는 "필수 페인"이 아니라 "재미/회상 동기". Spotify Wrapped도 페인 X 회상 콘텐츠. attacker도 "회상 욕구는 필수 페인이 아니라 -3" 명시. **페인 강도 5 정직 평가**.
- **다수성 (10/10)**: 카톡 사용자 거의 모든 한국 성인. .txt 내보내기 마찰 있지만 단톡 도메인 자체는 다수.
- **매일성 (3/10)**: ⚠️ **1회용**. user-sim 5명 모두 "1회 사용 후 자연 이탈" 진술. 12월/연말 시즌성 부활 가능하지만 본질은 단발성. **매일성 3 = 거의 0이지만 시즌 부활 +3**.
- **페인이 진짜? (운세류 X)**: △ **부분 의심**. "카톡 1년 회상 + 위트 카드"는 운세/심리테스트 류 아니지만 "필수 페인" 못 통과. 1차 함정 "오늘의 X 카드"의 변형 위험 일부 잔존 (1년 X 카드).
- **약점 자가 의심**: meta-review가 "wrapped 박스 60%" 의심 명시. 페인 도메인은 단톡(보편)이지만 메커니즘은 "회상 콘텐츠" = 페인 정면 X. **페인보편 축에서 결정적 약함**.
- **점수**: 5 + 10 + 3 = **17 (실측)** → attacker 23은 -6 차감
- **이건 페인 후보 X 흥미/바이럴 후보**: R4에서 페인보편 약함은 인정하되, evaluator-fun/evaluator-viral 평가에서 강함 예상. **종합 평가 시 페인보편 17이 결정적 약점이지만, 단발 폭발 모델로 회피 가능**.

### #14 회의 안 가기 시뮬 (+좌석도) → **23/30**

- **페인 강도 (9/10)**: 직장인 멘탈 위기 61% + 번아웃 71% (R1 pain.md 카테고리 1). "이 회의 안 가도 되나" = 한국 위계 + 보고 문화 + 회식 끼임 = 매일 신경 쓰이는 강한 페인. attacker 26 매김 / pain.md 페인 강도 9 명시.
- **다수성 (8/10)**: 한국 직장인 약 2000만 (전체 인구의 40%). 단 학생/주부/자영업/프리랜서 제외 = 다수성 8. user-sim 5명 중 영수+지수+준영은 약함 (5점 이하) = "회의 페인 페르소나" 한정 시그널.
- **매일성 (9/10)**: 회사원 회의 = 매일 2-3개. user-sim 민지 "매일 회의 잡힐 때마다 사용 (2-3회/일)" 직접 진술. 페인 호출 빈도 매우 높음.
- **페인이 진짜? (운세류 X)**: ✓ 진짜. 매일 한국 직장인이 겪는 실제 행동. 좌석도 일러스트는 fun 메커니즘이지만 본질 페인 정면.
- **약점 자가 의심**: (a) 다수성 8 = 직장인 한정. 학생/주부/자영업 제외 시 다수성 7로 떨어질 수 있음. (b) attacker가 26 매김 = 살짝 후함. user-sim "지수 5 / 영수 5" 약함 반영하면 다수성 7-8 사이.
- **점수**: 9 + 8 + 9 = **26 → 자가 인플레이션 의심으로 -3 차감 = 23**
- **차감 사유**: (a) 다수성 직장인 한정. (b) "회의 안 가기 결정"보다 "회의 견디기"가 진짜 페인이고, 결정 빈도는 매일 9가 아니라 7-8.

### #9 가족 회의소 (1인 가구 결정 보조) → **15/30**

- **페인 강도 (6/10)**: ⚠️ **결정적 약점**. R1 pain.md 1인 가구 자취 페인 강도 8 (가사/식사/외로움) 정도. 단 "결정 보조" 페인 = "오늘 옷 뭐 입지" / "이 사람이랑 사귈까" = 결정 피로 추상 페인 강도 6. attacker도 "결정 보조 페인 약함" 명시.
- **다수성 (8/10)**: 1인 가구 804만 (전체 36.1%) + 48.9% 외로움 응답 = 다수성 8 ⭐ (이게 #9의 진짜 강점). meta-review도 "1인 가구 외로움 정면 = 빠진 영역 = R4 부활 권장" 명시.
- **매일성 (5/10)**: "결정 보조" 호출 빈도 = 일 1회 미만. user-sim 미평가지만 추정 매일성 약함. zeta 1위 (월 5248만 시간)는 1:1 페르소나 사용 시간 = #9 그룹 4명과 다름. 그룹 페르소나 사용 빈도는 zeta 1:1보다 낮을 가능성.
- **페인이 진짜? (운세류 X)**: △ **부분 의심**. "AI 4명에게 의견 물어보기" = 결정 보조 페인 진짜이지만 "외로움 해소"인지 "결정 보조"인지 페인 본질 흐림. 페르소나 챗봇 영역 = zeta/PolyBuzz/Character.AI 인접 = 메커니즘 신선도 약함.
- **약점 자가 의심**: (a) attacker 17 vs meta-review "정직 박살이 아니라 1인 가구 외로움 회피 의심" 충돌. (b) **1인 가구 외로움 정면 푸는 후보 0건 = #9가 빠진 영역 부활 = 페인보편 가산점 + 3**. 단 메커니즘이 "결정 보조"라 외로움 정면 X = 가산점 무효.
- **점수**: 6 + 8 + 5 = **19 → 메커니즘이 외로움 정면 X로 -4 차감 = 15**
- **차감 사유**: 다수성 8은 강함이지만 (a) 결정 보조 페인 강도 6 약함. (b) 매일성 5 약함. (c) 외로움 페인 정면 X = 다수성 강점 활용 못함.
