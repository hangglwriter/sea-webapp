## U1: 작가 마케팅 OS

### 페인 강도 (10점)
- **점수: 9/10**
- 근거: 글로벌 r/selfpublish 분석에서 **"discoverability(노출/발견)이 인디 작가 1순위 페인"** 명시. pain.md #1 "출간 첫 1-2주 친구·가족 매수 후 판매 절벽. 한 작가 한 달 뒤 7권 (4권은 어머니)" 후기 = 만성 우울 강도. 출간 후 6개월 매일 마케팅이 진짜 일인데 지원 도구 없음 = 매일 짜증 + 만성 우울 사이. r/selfpublish 1순위 = "있으면 좋겠다" 절대 아닌 진짜 페인.
- 출처: [Ingramspark r/selfpublish 분석](https://www.ingramspark.com/blog/reddit-for-self-published-authors-building-trust-before-selling-books), [부크크 자가출판 후기](https://brunch.co.kr/@manofpeace/119), [출판N 2023 매출 4.8% 감소](https://nzine.kpipa.or.kr/sub/inside.php?ptype=view&idx=905)

### 페인 보편성 (10점)
- **점수: 5/10**
- 1차 사용자 풀: 위너책쓰기 졸업생 100명 (매년 50-100명 누적, 1-2년차면 100명 미만)
- 외부 확장: 한국 자가출판 활성 작가 추정 1000-3000명 (한국출판인협회 2024 통계 + 부크크/유페이퍼). 그 중 결제 의향 = 5-10% = 100-300명. **한국 자가출판 시장 작음 + 4.8% 매출 감소 진행중** = 외부 확장 한도 명확.
- 침투율 가정 5% 침투 = 50-150명 = 매우 작은 풀.
- attacker 박살 "ARR 1억 비현실" 정확. user-sim 수강생 + 민티 = 2명만 결제 의향. 행글라이터 구독자 + 인테리어 사장 = 결제 X.
- 외부 시장 작아서 보편성 평균 이하.

### 페인 vs 흥미 (5점)
- **점수: 5/5**
- 페인 직격 (출간 후 매출 절벽 = 만성 우울). 흥미 시그널 거의 0. 도구가 페인 진짜 해결하는가는 차별/실현 평가 영역이라 페인-흥미 구분만 보면 = 페인 직격.

### 페인 종합 점수: **19/25**

## U4: 1인 대행 리포팅 + 영업자료 OS

### 페인 강도 (10점)
- **점수: 8/10**
- 근거: 1인 대행 매월 리포팅 5-10시간 hell + 영업 자료 매번 새로 만들기 = **매월 짜증 + 신규 영업 시 매번 짜증** = 매일 짜증은 아니나 매월 보장 + ROI 측정 가능. user-sim 민티 "매월 리포트 + 영업 자료 수동 작업 = 매월 5-10시간 소요" 정확. 인테리어 클라이언트 사장 측 "대행 만족도 = 대행비 유지/증액 정당화" = 페인 명확. 만성 우울은 아니나 "매일 시간 도둑" 강도.
- 글로벌 검증: 광고대행사 시장 + 인플루언서 마케팅 시장 2032년 USD 1.24B (CAGR 23%) = 시장 자체 성장 중 + Metricool 같은 도구 시장 검증.
- 출처: [한국 인플루언서 마케팅 시장 CAGR 23%](https://www.coherentmi.com/ko/industry-reports/%ED%95%9C%EA%B5%AD%EC%9D%B8%ED%94%8C%EB%A3%A8%EC%96%B8%EC%84%9C%EB%A7%88%EC%BC%80%ED%8C%85%ED%94%8C%EB%9E%AB%ED%8F%BC%EC%8B%9C%EC%9E%A5-123), [2026 소상공인 마케팅 가이드 - 소상공인 570만 명](https://oneplan.co.kr/small-business-marketing-guide-2026), pain.md #5 (자영업자 인스타 운영 매일 페인)

### 페인 보편성 (10점)
- **점수: 9/10**
- 1차 사용자 풀: 민티 본인 + 인테리어 클라이언트 1개 = 2개 즉시 검증 + 행글라이터 구독자 중 1인 마케팅 프리랜서 100명 = **100+ 명**
- 외부 확장:
  - 한국 1인 콘텐츠 마케팅 프리랜서 추정 1만+ (인크루트/원티드 프리랜서 등록 기준)
  - 소규모 콘텐츠 에이전시 (2-5인) 한국 2000+ (광고대행사 시장 + 인플루언서 마케팅 SaaS 시장 USD 291M → 1.24B)
  - **자영업자 직접 사용 트랙: 한국 소상공인 570만 명 + 인스타·블로그 매일 페인** = pain.md #5 직접 매핑. 침투 0.01% = 570명 추가.
- 침투율 0.5-1% × 1만 명 = 50-100명 + 0.01% × 570만 명 = 570명 = **합계 수천 명 잠재**
- user-sim 3명 결제 의사 (민티 + 구독자 + 사장 대행 우대) = 모든 페르소나가 접점 있음.
- 보편성 **최고 점수권**.

### 페인 vs 흥미 (5점)
- **점수: 5/5**
- 페인 직격 (시간 절약 + 영업 ROI). 흥미 시그널 거의 0 (대행 리포팅은 재미 X). 페인 완전 직격.

### 페인 보편성 (10점)

  - 침투 1% × 한국 유튜브 1만+ 채널 수만 명 = 수백-수천 명
- 인테리어 클라이언트도 카드뉴스 시안 검증 = B2B 확장 트랙. 자영업자 인스타 시안 = 추가 확장. 보편성 강함.

## eval-pain 한 줄 요약

**U4 22점 1위** - 페인 강도 (매월 짜증 + ROI 측정) + 보편성 (1인 프리랜서 1만 + 소상공인 570만 = 외부 확장 최강) + 페인 직격 5점 합. **F2 20점 2위** - 매주 짜증 + 한국 유튜브 1만+ 채널 + B2B 대행 트랙. **U1 19점 3위** - 페인 강도 9점 최강이지만 보편성 5점 (자가출판 시장 작음) = 합계 떨어짐. **D4 18점 4위** - 매일 짜증 + 인스타 운영자 보편성 OK 단 흥미 비중 = 페인 직격 깎임. **D3 15점 5위** - 매주 데이터 입력 마찰이 페인 강도 자체를 약화 + 6개월 인내 필요 = 보편성 깎임.
