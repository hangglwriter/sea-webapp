2. **개인정보보호법 + 정보통신망법 ([Lexology](https://www.lexology.com/library/detail.aspx?g=76c97a49-41c7-4ce6-aa78-f25cf93f3289), [법률신문](https://www.lawtimes.co.kr/news/articleView.html?idxno=218033)) 핵심 위반 영역**:
   - 카톡 .txt = **본인 발화 + 상대방 발화 모두 포함**
   - 사용자가 본인 동의 가능, **상대방 동의 0** → 정보주체 동의 위반
   - 본인 가족/친구/시댁/직장 인물 식별 가능 정보 = 개인정보
3. **카카오톡 운영정책** ([카카오 운영정책 2025-06](https://t1.kakaocdn.net/talksafety/file/policy/%EC%B9%B4%EC%B9%B4%EC%98%A4%ED%86%A1_%EC%9A%B4%EC%98%81%EC%A0%95%EC%B1%85_20250616.pdf)): 무단 수집/탈취/거래 명시 금지. .txt 자체 내보내기는 카카오가 허용한 사용자 권리이나 **외부 앱 전송은 미규정 (회색 지대)**.

### 위험 정량

| 위험 | 수위 | 1인 비개발자 운영 가능? |
|------|------|------------------|
| 본인 동의 X 상대방 정보 처리 | **높음** | X (변호사 자문 필수) |
| 데이터 영구 저장 = Tea 패턴 | 높음 | X (CLAUDE.md 명시 위반) |
| 데이터 즉시 삭제 + 클라이언트 단독 처리 | 낮음 | O (단 LLM API 호출 시 OpenAI/Anthropic 서버에 전송 = 또 위반 영역) |
| 카카오 자체 wrapped 출시 (2026 하반기) | **높음** | 회피 불가 |

### 회피 가능한가?

**옵션 A**: 100% 클라이언트 처리 + LLM API 호출 0회 → JS만으로 텍스트 분석. 위트 톤 X (LLM 없으니까). = 차별성 0 = 정밀 분석기 (이미 존재)와 동일.

**옵션 B**: LLM API 호출 + 즉시 삭제 + 약관 명시 "본인 데이터만 업로드, 상대방 정보는 익명화" → **사용자 무시할 가능성 + 약관 면책 한국 법원에서 약함**.

**옵션 C**: 카나나가 2026 하반기 자체 wrapped 출시 시 = 사용자 마찰 0 + 카나나 공식 = 외부 앱 사용 동기 사라짐.

→ **3가지 옵션 모두 운영 가능성 낮음.**
