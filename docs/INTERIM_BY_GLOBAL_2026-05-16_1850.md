## 1. 무엇을

```
시장조사(3명) → PM 종합 → 아이디어 3-5개
   → 리뷰어 비판 → 1개 선택
   → UX 와이어프레임 + 디자이너 시안 (병렬)
   → 엔지니어 구현
   → QA + 리뷰어 검토
   → GitHub + Cloudflare Pages 배포
   → 최종 보고서
```

**실제 완료된 단계**: 시장조사 3건 (A·B·C) + 본 최종 보고서.

## 2. 왜

### 프로젝트 목표
- 민티(1인 콘텐츠 크리에이터, AI/글쓰기/콘텐츠 마케팅 전문)가 글로벌(동남아 강조) 시장에 진출 가능한 웹앱 프로토타입을 2-3시간 안에 만들고 Cloudflare Pages에 배포.
- 한국어 UI 우선 (i18n은 v2). 민티 운영 편의 + K-브랜드를 강점으로 활용.

### 사이클 중단 원인 (추정)
본 에이전트는 시장조사 B만 직접 수행했고, PM 종합부터 배포까지의 단계가 폴더에 흔적이 없다. 가능성:
1. PM 에이전트가 종합 단계에 진입하지 못함 (오케스트레이션 단절)
2. 시간 한도 또는 컨텍스트 한계로 자동 사이클 중단
3. 태스크 시스템(TaskList)이 비어있어 후속 에이전트들이 작업을 픽업하지 못함

이 보고서는 PRD의 "종료 조건: 시간 한도 도달 → 강제 종료 + 현재까지 산출물 보고" 규정을 따른다.

## 3. 어떻게

### 시장조사 A (동남아 6개국)
- **방법**: e-Conomy SEA 2025, 한국문체부 2024 해외한류조사, Deloitte, GSMA, Statista, Antom Knowledge, Cosmetics Design Asia 등 1차·2차 출처 수십 건 종합.
- **결과**: 8개 미충족 니즈 + 한국 1인 운영자 적합 5개 후보 도출.
- **추천**: K-Diary(K-콘텐츠 자기성장 저널), K-Lyric Lab(K-팝/드라마 가사 해설), K-Caption(동남아 마이크로 크리에이터 콘텐츠 어시스턴트).

### 시장조사 B (글로벌 신생 트렌드)
- **방법**: Product Hunt 1·3·4월 + 연간 leaderboard 직접 fetch, Reddit/Indie Hackers/Hacker News 트렌드 검색, 1인 indie 화제작(Kleo/Polsia/HeadshotPro/Pieter Levels) 사례 수집.
- **결과**: PH 화제 10개 + 1인 화제작 5개 + AI 신규 카테고리 5개 + 동남아 우회 가능 후보 5개.
- **추천**: AI 저널링 동남아 native(시장 $6.34B 2026 전망), 회의/음성→소셜 콘텐츠 변환, Brila SE 버전.

### 시장조사 C (한국어 UI 적합 도메인)
- **방법**: 언어 의존도 낮은 도메인 5 + K-콘텐츠 팬덤 매력 도메인 5 + 민티 능력 매칭 도메인 5 + 한국풍 디자인 도메인 4를 카테고리화. 5가지 기준(A~E 각 5점) 가중치 평가.
- **결과**: 종합 1위 K-사주 미니, 2위 이름 궁합, 3위 AI 콘텐츠 아이디어 룰렛, 4위 컬러 팔레트+행운 운세, 5위 인스타 카드뉴스 템플릿.
- **추천**: 1위 + 4위 결합("K-사주 + 행운 컬러" 카드 한 장)이 MVP 스코프에 가장 적합.

## 4. 결과

### 3개 시장조사 종합 의견 (B 에이전트 시각)

세 산출물이 추천하는 도메인을 교차 분석하면 **수렴되는 영역**과 **각자만 강조한 영역**이 보인다.

**수렴 영역 (A·B·C 모두 추천 또는 시사)**:
- **자기성장 저널/자서전 계열** (A의 K-Diary, B의 AI 저널링 동남아 native, C의 3-2 AI 일기→자서전 변환기). 민티 dailybook·위너책쓰기 자산과 직결.
- **콘텐츠 크리에이터 보조 도구** (A의 K-Caption, B의 회의→소셜 변환, C의 3-4 AI 콘텐츠 아이디어 룰렛). 민티 행글라이터 채널 IP와 직결.

**A만 강조**: K-Lyric Lab(가사 해설), K-뷰티 루틴, K-식문화 보조 → 동남아 한류 코어 직접 타깃.

**B만 강조**: Brila식 SMB 자영업 사이트 자동 생성, AI 음성 OS, vibe design → PH 화제 카테고리 추종.

**C만 강조**: K-사주/이름 궁합/타로 → 한국어 UI를 약점이 아니라 K-브랜드 강점으로 전환하는 시각. 2-3시간 MVP 친화성 1위.

### MVP 후보 3개 (PM에게 제안)

세 조사의 교집합 + PRD 5개 기준 모두 충족하는 후보:

**후보 P1: K-사주 + 행운 컬러 미니 카드** (C 1위 + C 4위 결합)
- 입력: 이름 + 생일 / 출력: 사주 한 줄 + 행운 컬러 3색 + 행운 숫자 카드 1장
- A·B 조사와 직접 매칭 약함, 하지만 **MVP 2-3시간 스코프 최강** + Saju World 베트남어 확장이 동남아 수요 검증
- 한국어 UI가 K-브랜드 매력으로 작동

**후보 P2: K-Diary 미니** (A 1위 + C 3-2)
- 입력: 5문항 답변 / 출력: AI가 한국 크리에이터식 문체로 다듬은 자기소개·자서전 카드
- 민티 dailybook·위너책쓰기 IP 그대로 활용
- 한국어 UI 자연스러움 (저널은 본인 언어로 쓰는 게 자연스러움)
- 약점: AI API 호출 비용 (OpenAI/Claude 키 필요)

**후보 P3: 콘텐츠 아이디어 룰렛** (A 2위 K-Caption + C 3위)
- 입력: 닉네임 + 주제 / 출력: 인스타·유튜브 콘텐츠 아이디어 7개 카드
- 민티 행글라이터 채널·강의·위너책쓰기 도구로 즉시 활용
- 약점: K-매력 약함 (글로벌 보편 도구)

### 핵심 인사이트

1. **한국어 UI 우선이 단점이 아니다**. 동남아 한류 코어층(필리핀·인니·태국)에서 한국어는 호기심·고급 인상 후크로 작동 (A 1단원, 한국문체부 2024 해외한류조사 기준 한국어 학습 관심도 필리핀 88.9%).
2. **민티 IP가 그대로 차별점**. dailybook·위너책쓰기·행글라이터 콘텐츠가 동남아엔 무주공산. 한국식 "자기 스토리 → 콘텐츠/책" 워크플로가 K-콘텐츠 팬덤과 만나는 지점이 비어있음.
3. **MVP 시간 한도에 가장 안전한 카테고리는 "정적 사이트 + 카드 1장 출력"**. 사주/이름 궁합/컬러 팔레트 계열. AI API 호출 없이도 작동 가능.

## 5. 한계

### 사이클 한계
- **PM 종합~배포 7단계 미진행**. 본 보고서는 시장조사 종합과 후속 권고에 그침. 실제 동작하는 프로토타입 없음.
- **GitHub repo `hangglwriter/sea-webapp` 미생성**, Cloudflare Pages 배포 미수행.
- **TaskList 비어있음**: 태스크 트래킹 시스템이 사용되지 않아 후속 에이전트들이 작업 픽업할 컨텍스트 없었음.

### 시장조사 한계
- **WebSearch는 미국 IP 기반**. 베트남/인니/태국 현지 앱 차트·SNS 트렌드는 직접 확인 못함 (A·B·C 공통).
- **민티 채널 기존 시청자 동남아 비율 데이터 없음**. 추정 기반.
- **현지 사용자 인터뷰 0건**. 동남아 미진출 갭은 "한국 IP에서 검색해서 못 찾았다" 수준 (B의 신뢰도 메모 참조).
- **시장 규모 수치 일부는 2차 소스**. AI 저널링 $6.34B 시장 (B), Korean language learning $67B 2034 전망 (A) 등은 1차 산업 보고서 재검증 권장.
- **저작권 위험 미검토**: C의 K-pop 멤버 매칭(IP), 관상 AI(윤리), K-타로(일러스트 출처)는 법무 검토 필요.

### 본 보고서 한계
- 본 에이전트(B)는 자기 시장조사 + 최종 보고서만 직접 수행. **PM 종합 단계를 대신 수행했으나 정식 PM 권한 없음**. 도메인 최종 선택은 민티가 직접 또는 별도 PM 에이전트가 해야 함.
- 사이클 중단 원인은 정확히 모름. 폴더 흔적과 빈 TaskList로부터 추정.

## 6. 다음 단계

### 즉시 가능 (사용자가 직접 또는 새 세션에서)

1. **도메인 1개 선택**. 본 보고서 후보 P1/P2/P3 중 선택. 추천 순서:
   - 시간 정말 부족 + 동작 확실 → **P1 (K-사주 + 행운 컬러)**
   - 민티 IP 100% 활용 → **P2 (K-Diary 미니)**
   - 강의·코칭 도구 즉시 활용 → **P3 (콘텐츠 아이디어 룰렛)**

2. **새 세션에서 단순 사이클 재시작**. PRD의 7단계 자동 사이클 대신:
   - "P1 도메인으로 정적 HTML 1페이지 만들고 GitHub push + Cloudflare Pages 연결"
   - 단일 에이전트 1-2시간 안에 충분히 가능

3. **GitHub repo 선생성**. `hangglwriter/sea-webapp`을 GitHub에서 빈 repo로 만들고 README.md만 push. Cloudflare Pages는 GitHub Connect to Git으로 연결 (CLAUDE.md "Cloudflare Pages 배포 순서 절대 규칙" 준수).

### 사이클 재설계 권고 (다음번 자동 사이클 시)

PRD의 자동 사이클이 한 번에 7단계 진행하다 중단된 패턴이 보임. 다음번엔:

1. **TaskList를 미리 채워두고 시작**. PM이 첫 단계로 TaskCreate 10개 (시장조사 3개, 종합 1개, 리뷰 1개, 와이어 1개, 디자인 1개, 구현 1개, QA 1개, 배포 1개, 보고 1개).
2. **각 단계 산출물을 폴더에 명시적으로 작성**. `decisions/`, `wireframe/`, `design/`, `build/` 폴더 미리 만들기.
3. **단계 간 위임은 SendMessage로 명시**. 다음 에이전트가 어떤 파일을 읽고 무엇을 만들어야 하는지 message에 명시.
4. **시간 한도 도달 시 자동 종료 트리거**. 각 단계마다 시간 체크 + 시간 초과 시 즉시 본 보고서 같은 스냅샷 작성.
