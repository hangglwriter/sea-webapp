**흥미 메커니즘 작동 (4개)**:

### 후보 3: 단톡 1년 — "카톡·페이·계좌 한 해 영수증 자동 생성 + 인스타 공유"

**한 문단 컨셉**:

AI가 한 해를 분석해 **시각화된 영수증 카드 12장**을 생성: "당신은 2026년 총 14,328번 ㅋㅋㅋ를 쳤습니다 / 가장 많이 이모티콘 보낸 사람은 엄마 (이유: 매주 일요일 안부) / 가장 폭주한 단톡은 회사 (오후 9시-11시 433번) / 1년치 결제 영수증 = 배민 84만원 vs 헬스장 12만원". 인스타 스토리에 그대로 공유되는 9:16 카드 자동 생성. 멜론 MY RECORD가 음악만 하는데 이건 **카톡+페이+계좌 통합 + 한국식 영수증 미학**.

**신생 카테고리 검증**:
- newcat.md 사례: Receiptify (Spotify→영수증), Spotify Wrapped (200M+ 공유), Apple Health Wrapped 2025 (솔로 개발자 Show HN), Day by Data

- 결론: 멜론은 음악 wrapped 있음 (=음악만으로 가면 함정), **통합 wrapped + 한국식 영수증 비주얼은 미진입**
