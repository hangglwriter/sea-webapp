### 후보 1: 카톡방 정치 시뮬레이터 - "이 톡 보내도 돼?"

### 후보 2: 출근길 영혼없음 자동 일기 - "오늘도 9호선에서 죽음"

### 후보 3: 단톡방 안 읽음 자동 핑계 생성기 - "왜 안 읽었어?" 박살내기

**계보**: "GPT 밈"(과잉 공감 안티) 위트 + "장항준적 사고"(솔직 마인드) + AI 의외성. 단톡 페인(pain.md 카테고리 10) + 직장 페인 결합.

**한 문단 컨셉**: 단톡 1234건 안 읽음 → 누가 "야 왜 안 읽어?" 톡 옴 → 진땀. 이때 이 앱에 **상황 한 줄 입력** ("회사 단톡에서 부장이 갑자기 회식 잡았는데 안 읽음 표시 5시간") 하면 AI가 **장항준적 톤의 핑계 5종 자동 생성**. 1번 = 솔직 핑계 ("회식 가기 싫어서 안 읽었습니다"), 2번 = 위트 핑계 ("핸드폰이 죽었습니다. 부활이 늦었습니다"), 3번 = 어이없음 핑계 ("저는 5G 시대에 살지만 마음은 2G입니다"), 4번 = 영혼없음 핑계 ("아 미안 못 봤어 ㅎㅎㅎㅎ"), 5번 = 핵폭탄 핑계 ("부장님 단톡은 제가 매일 읽었지만 답하지 않는 것은 명상의 일부입니다"). **사용자가 5개 중 골라서 카톡에 붙여넣기 = 즉시 사용**. 위트의 핵심 = 5종 톤 비교 자체가 웃김.

**왜 폭발할까**:
- **X**: "ㅋㅋㅋ AI가 핑계 생성해줌 ㅋㅋㅋ" 인용 트윗 폭발. "5번 핑계 미친" 시리즈 형성
- **인스타**: 카톡 스샷 + 핑계 5종 캡처 = 릴스 친화
- **디시**: 회사갤/맘갤에서 "이번 단톡 핑계 뭐 쓰지" 댓글 폭발. 디시의 단톡 짤 문화 정면 매칭
- **더쿠**: "AI 핑계 미친 적나라 정확" 류 글
- **추가**: 직장인 단톡 회피 = 보편 페인 + 위트로 풀린 적 없음 (기존 대안 0)

**흥미 후크 (몇 개)**:
- 메커니즘 1 (능동 과몰입 = 상황 한 줄 입력)
- 메커니즘 5 (위트 = 5종 톤 비교, 어이없음)
- 메커니즘 8 (AI 의외성 = 5번 핑계가 너무 어이없어서 웃김)
- **한국 단톡 95% 페인 정면 매칭 + 위트만으로**

**한국 페인 살짝 결합**:
- 단톡방 피로 (pain.md 카테고리 10, 보편 10/10, 한국 특화 10/10)
- 회의/회식 회피 페인 직장 페인 결합
- 위트가 본진. 페인 동정 X

**1차 함정 자가 검토**:
- 운세/사주/MBTI/타로 = 0
- "오늘의 X 카드" 류 = X (결과는 핑계 5종 텍스트, 카드 X)
- 친구 강제 판결 #16 변형 = X (친구 0건)
- 단순 AI 생성기 = **주의** AI가 5종 답을 생성하는 패턴 = ChatGPT 5분 가능?
- **반박**: ChatGPT에 "단톡 핑계 5개 만들어줘" 가능하지만 **장항준적 톤 + 한국 단톡 맥락 + 시댁/회사/맘 단톡별 페르소나 분기 + 5종 톤 비교 UI**는 캔바+ChatGPT 못 함. 단 차별성 약점 분명 = R3 attacker 박살 가능성 50%

**2차 함정 #6 자가 의심 (새 박스인가?)**:
- "AI 답장 추천" 박스 위험 (newcat.md 카테고리 3 = Rizz/Mei/BestInterest)
- **반박**: Rizz는 데이팅, 이건 단톡 핑계. 한국 단톡 시댁/회사/학부모 페르소나 분기 = 글로벌 클론 못 따라옴

- **이 후보는 attacker가 박살할 가능성 가장 높음. 그러나 1주일 MVP 가능 = 빠른 검증 가치 있음**

**1인 빌드 가능?**: YES. 입력 폼 + LLM API 5번 호출 (톤별 프롬프트) + 결과 5종 카드 + 복사 버튼. 3일 MVP.
