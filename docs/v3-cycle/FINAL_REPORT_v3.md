## 최종 결과물 (#11 카톡방 정치 시뮬레이터)

### 차별화 한 줄

> **"카톡 보내기 전, 시댁·회사·학부모·베프 4명이 그 톡을 받았을 때 어떻게 답장할지 동시에 시뮬한다. 답장 화면은 진짜 카톡 말풍선 스샷이라 인스타 스토리에 박으면 그 자체가 광고."**

### 구현 사양

- 단일 정적 HTML + Tailwind CDN + html2canvas
- Anthropic Claude Haiku 4.5 API (사용자 본인 키 입력, 운영자 책임 회피)
- 6명 페르소나 (시댁어머니/직장상사/학부모회/베프 + 옵션: 남친·여친/가족 단톡장)
- 카톡 말풍선 UI 정확 재현 (#B2C7D9 배경 / 노랑 / 흰 / Noto Sans KR / "1" 안 읽음)
- 공유 3종: 일반 PNG / 인스타 스토리 9:16 PNG / 클립보드 텍스트
- 정신건강 가드레일: 18+ / 자해 키워드 13개 차단 + 1393 안내 / 24h 자동 삭제

### 차별성 (vs 경쟁)

- **카카오 카나나 (2026-04 답장 추천)**: 받은 톡에 1대1 답장. 카톡 안에서만. 자체 광고 X.
- **#11**: 보내기 전 4명 동시 시뮬 + 카톡 밖 + 스샷 자체 광고. K-factor 자동.

## R8 권장 사항 (사용자 검토)

1. **모델 검증** (haiku-4-5 vs sonnet-4-5): 시댁어머니 격식 톤 + 베프 위트 톤 실제 시뮬 1-2회로 검증. 약하면 `src/claude.js:47` 모델명 교체 (1줄)

3. **API 키 허들**: 비개발자 = API 키 발급 자체가 마찰. R8에서 서버 프록시 또는 사용자 결제 방식 고려
