## 페르소나별 솔직 반응

### 지수 (22세 서울 여대생, Gen Z, 단톡 헤비)

**#11 카톡방 정치 시뮬 → 9점**
- 첫인상: "와 미친 이거 진짜 시댁/엄마 단톡 시뮬 돌려보고 싶다"
- 1주일: 친구 단톡에 매일 공유. 인스타 스토리 캡처 3-4번
- 친구 초대: 100%. "야 이거 너네 엄마 단톡 페르소나 정확함 ㅋㅋㅋ"
- 결제: 무료 5회 후 ₩2000 = 가능. "한 학기 단톡 짤 농사값" 인식
- 이탈: 페르소나 답장 톤이 1주만에 반복되면 = 위트 디테일 부족 시 7일 안 이탈
- 인스타 공유: **자체 광고 메커니즘 빌트인**. 카톡 말풍선 스샷 = 인스타 스토리 친화 9:16. K-factor 2+ 추정

**#15 카톡 wrapped → 8점**
- 첫인상: "Spotify Wrapped는 매년 인스타 도배함. 카톡 버전 있으면 당연히 함"
- 1주일: 단발성. 한 번 돌리고 끝. **단 친구한테 강제 추천**
- 친구 초대: 90%. "야 너 카톡 wrapped 해봐. 단톡 짤 미친 ㅋㅋ"
- 결제: 1회 ₩3000 한정판 결제 가능. 구독 X
- 이탈: 1회 사용 후 자연 이탈. 12장 카드 끝나면 재방문 이유 0. **단 친구 N명 끌어오는 1회 폭발 가치 큼**
- 인스타 공유: **자체 광고 최강**. 인스타 스토리 12장 연속 도배 가능

**#14 회의 안 가기 시뮬 → 5점**
- 첫인상: "회의가 없어서 페인 약함. 학회 회의? 잘 모르겠음"
- 1주일: 1-2회 호기심 사용. 회사 단톡 페르소나 시뮬보다 약함
- 친구 초대: 30%. 직장인 친구한테만
- 결제: 안 함. "내 페인 X = 돈 안 씀"
- 이탈: 3일 안 이탈
- 인스타 공유: 20%. 좌석도 일러스트는 귀엽지만 본인 코드 매칭 X

**#4 자취방 진단 → 6점**
- 첫인상: "엄마집 살아서 안 맞음. 단 친구 자취방 사진으로 장난칠 수 있음"
- 1주일: 호기심 1-2회. 친구 자취방 사진으로 1회 시뮬
- 친구 초대: 40%. 자취 친구한테만
- 결제: 안 함
- 이탈: Vision API 결과가 거짓이면 즉시 이탈 ("이거 곰팡이 없는데?")
- 인스타 공유: 30%. 5단계 미스터리 + 친구 잠금 메커니즘은 끌림. 단 본인 페인 X

**#12 출근 영혼없음 일기 → 5점**
- 첫인상: "출근 안 하는 학생이라 페인 X"
- 1주일: 0회. 통학 지하철 일기? 약함
- 친구 초대: 20%
- 결제: 0%
- 이탈: 즉시
- 인스타 공유: 10%

**지수 종합**: #11 압도, #15 1회용 폭발, 다른 후보 약함. **결제 의향 가장 큰 후보 #11 (학기 가격대 ₩2K)**

### 민지 (30세 서울 스타트업 마케터, 단톡 + 회의 헤비)

**#11 카톡방 정치 시뮬 → 9점**

- 결제: ₩3000-5000 월구독 가능. "내 정신건강값". **B2B 직장인 시장 잠재**
- 이탈: 페르소나 4명 = 회사/가족/시댁/학부모 외 (예: 친구/연인) 페르소나 없으면 3주 안 이탈 위험

**#15 카톡 wrapped → 8점**

- 이탈: 1회 사용 후 자연 이탈. **단 12월/연말에 다시 옴 = 시즌성 부활**
- 인스타 공유: 80%. **마케터 페르소나 = 인스타 스토리 도배 본업**

**#14 회의 안 가기 시뮬 → 9점**
- 첫인상: "오늘 회의 4개 잡혔는데 시뮬 돌려서 어떤 거 빠질지 정한다"
- 1주일: 매일 회의 잡힐 때마다 사용 (2-3회/일)
- 친구 초대: 90%. 회사 동료 단톡에 무조건
- 결제: ₩5000 월구독. "회사값 = 정신건강값"
- 이탈: 좌석도 캐릭터가 1주만에 반복되면 = 일러스트 디테일 부족 시 위험
- 인스타 공유: 60%. 회의 좌석도 = 직장인 인스타 친화

**#4 자취방 진단 → 6점**
- 첫인상: "1인 가구 직장인. 페인 매칭. 단 한 번 보면 끝일 듯"
- 1주일: 1회 호기심. 친구 자취방 사진으로 1회
- 친구 초대: 50%. 자취 친구 단톡에만
- 결제: 안 함 (1회용 인식)
- 이탈: 즉시
- 인스타 공유: 40%. 47점 결과는 캡처 가능

**#12 출근 영혼없음 일기 → 8점**
- 첫인상: "9호선 통근. 매일 영혼없음 = 정확"
- 1주일: 매일 1회 입력 (출근길 1줄). 1주일 카드 = 일요일 저녁 인스타 스토리
- 친구 초대: 70%. 통근 친구 단톡
- 결제: ₩2000 월구독 = 가능 (일기값)
- 이탈: 매일 입력 강제 = 1주 안 30% 이탈 위험 (푸시 없으면)
- 인스타 공유: 80%. 1주일 카드 = 인스타 스토리 비율 = 자동 공유

**민지 종합**: #11 #14 동률 9점. **회사 + 단톡 + 회식 페인 다층 매칭 = 한국 직장인 페르소나 최강 매칭**. 결제 의향 5개 후보 중 가장 큼

- 친구 초대: 60%. 직장인 친구 단톡
- 결제: ₩3000 가능
- 이탈: 1주 안
- 인스타 공유: 50%

**#4 자취방 진단 → 7점**
- 첫인상: "본인 자취 X. 단 콘텐츠 소재 = 친구 자취방 시뮬 영상 가능"
- 1주일: 1-2회 콘텐츠
- 친구 초대: 70%
- 결제: ₩2000 가능
- 이탈: 1주 안
- 인스타 공유: 60%

**#12 출근 영혼없음 일기 → 6점**
- 첫인상: "통근 안 함 = 페인 X. 단 위트 톤은 가져갈 만"
- 1주일: 0-1회
- 친구 초대: 50%
- 결제: 0%
- 이탈: 즉시
- 인스타 공유: 40%

**준영 종합**: **#11 #15 동률 9점**. 크리에이터 = 콘텐츠 소재 발굴 메커니즘 = **자체 광고 메커니즘 최강 페르소나**. 본인 채널 5K 통한 외부 유입 가능 = K-factor 증폭

## 핵심 발견

### 1. 가장 강한 후보 (5/5 페르소나 7+ 통과 여부)

| 후보 | 7+ 통과 페르소나 수 | 약점 페르소나 |
|------|---|---|
| **#11 카톡방 정치 시뮬** | 4/5 (지수9·민지9·하늘7·준영9) | 영수 4점 |
| #15 카톡 wrapped | 3/5 (지수8·민지8·하늘7·준영9, 영수 3) | 영수 3점 + 1회용 |
| #14 회의 안 가기 | 3/5 (민지9·하늘8·준영7) | 지수 5·영수 5 |
| #4 자취방 진단 | 1/5 (하늘 9) | 영수 2·민지 6·지수 6 = 페르소나 좁음 |
| #12 출근 영혼없음 | 2/5 (민지8·하늘8) | 지수·영수·준영 모두 6 이하 |

**결론**: **#11이 4/5 페르소나에서 7+ 통과 = 진짜 보편 페인 매칭 확인**. attacker 90점 평가 정당화. **#4은 1/5 통과 = 페르소나 좁음 박살**. attacker 80점 간신히 통과 = user-sim도 같은 판단.

### 2. 영수(40대+ 부장) 페르소나 모든 후보 약함

5개 후보 모두 영수에서 5점 이하. **시장 사이즈 = 20-30대 한정 = 약 1500만 (한국 인구의 30%)**. 글로벌(특히 동남아) 확장 시 페르소나 더 좁음 (한국 단톡/회의 페인 문화 차이). PM이 R6에서 **시장 사이즈 정직 명시 필수**.

### 3. 위험 시그널 (이탈/사고)

- **#11**: 페르소나 4명(회사/가족/시댁/학부모) 외 추가 필요 (친구/연인). 3주 안 이탈 위험. R7에서 페르소나 확장 로드맵 필수
- **#15**: 1회용 = 단발성 폭발 후 자연 이탈. 12월 시즌성 부활 외 재방문 동기 약함. **B2C SaaS 모델 부적합. 1회 결제 + 친구 N명 K-factor 모델 필요**
- **#14**: 좌석도 일러스트 + 4명 캐릭터 풀 = 디테일 부족 시 2주 안 이탈. 일러스트 누적 + 페르소나 시리즈 로드맵 필수
- **#4**: Vision API 거짓 결과 = 즉시 신뢰 박살. **MVP에서 Vision 일부 + LLM 무작위 결합 명시 + "재미 도구 X 진단 아님" 디스클레이머 필수**
- **#12**: 매일 입력 강제 + 푸시 알림 없는 웹앱 = 1주 안 30% 이탈. **PWA 푸시 또는 카톡 알림 필수**. 또는 1주일 카드 보상 강조

### 4. 자체 광고 가능성 (인스타 스토리 / 카톡 공유)

| 후보 | 인스타 친화도 | 카톡 공유 친화도 | 자체 광고 종합 |
