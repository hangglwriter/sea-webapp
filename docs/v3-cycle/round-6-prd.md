## 차별화 한 줄

> **"카톡 보내기 전, 시댁·회사·학부모·베프 4명이 그 톡을 받았을 때 어떻게 답장할지 동시에 시뮬한다. 답장 화면은 진짜 카톡 말풍선 스샷이라 인스타 스토리에 박으면 그 자체가 광고."**

## 왜 카카오 카나나 / ChatGPT 안 쓰고 이걸 쓰는가

- **카카오 카나나 (2026-04 답장 추천)**: 받은 톡에 1대1 답장 추천. **카톡 안에서만** 작동. 자체 광고 X.
- **ChatGPT**: "이 톡 어때?" 물어보면 1명의 GPT가 답. **4명 페르소나 동시 X**. 카톡 말풍선 UI X. 스샷 자체 광고 X.
- **#11**: **보내기 전** 4명 동시 시뮬. **카톡 밖**에서 작동 (스샷 → 인스타/단톡 공유 = 자체 광고). 4명 페르소나 자동 (시댁/회사/학부모/베프).

## 코어 사용 시나리오 (3초 안의 가입 트리거)

1. 사용자: "엄마, 이번 주 못 가겠어 일 때문에" 같은 어려운 톡 + 송신 대상 (예: 시댁어머니)
2. 시스템: 시댁어머니 답장 + 회사 동료 답장 + 학부모회 답장 + 베프 답장 4개를 카톡 말풍선 4개로 동시 출력
3. 사용자: "와 시댁어머니가 진짜 이렇게 답할 것 같다" → 캡처 → 인스타 스토리 / 단톡 공유 / 베프에게 "너도 해봐"

## MVP 사양 (R7 빌더 작업 범위)

### 기능 (V1)
1. **입력**: 보낼 카톡 메시지 (textarea, 1-3 문장)
2. **페르소나 선택**: 6개 페르소나 중 4개 선택 (시댁어머니 / 직장상사 / 학부모회 / 베프 / 남친·여친 / 가족 단톡 단톡장)
3. **AI 처리**: Anthropic Claude API (sonnet) 1회 호출, JSON으로 4명 답장 반환
4. **출력**: 카톡 말풍선 UI 4개 (한국어 카톡 디자인 정확히)
5. **공유**: 다운로드 (html2canvas → PNG) + 클립보드 복사
6. **카운트**: 오늘 시뮬 N회 (소셜 증명)

### 기술 스택
- HTML + Tailwind CSS + Vanilla JS (Vite 빌드)
- Anthropic API 호출 (사용자가 직접 API 키 입력 → localStorage 저장)
- html2canvas (다운로드)
- Cloudflare Pages 배포

### 한국 카톡 말풍선 UI 정확도 (필수)
- 배경색: #B2C7D9 (카톡 배경)
- 말풍선: 노란색 (받는 사람) / 흰색 (보내는 사람)
- 폰트: Noto Sans KR
- 시간 표시 / 안 읽음 1 표시 / 프로필 이미지

### 정신건강 가드레일 (NGL FTC / Tea 학습 적용)
- 18+ 강제 (가입 시 생년월일 체크)
