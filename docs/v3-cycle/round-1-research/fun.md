## 발굴 흥미 메커니즘 (8개)

### 메커니즘 1: 능동적 과몰입 (입력 → 즉시 결과 → 캡처 공유)

- **어떻게 작동**: 사용자가 한 줄/번호/캐릭터 등을 입력하면 즉시 "내 결과/내 상황"이 만들어짐. 10초 만에 "세계관의 주인공" 체감. 진입장벽 0 (회원가입/입력 최소화). 만들어진 결과물을 캡처해서 X/인스타에 공유 = 자동 바이럴 엔진. 사용자가 능동적으로 자기 버전을 만들기 때문에 단순 시청 콘텐츠보다 체류 시간 길고 SNS 노출 폭발.
- **대표 한국 사례**:
  - "장시간 비행, 옆자리를 골라라" 밈 (X 시작, 2026년 1월 말 인스타·커뮤니티 전 플랫폼 점령) - 비행기 좌석에 캐릭터/사람 배치하고 "옆자리 누구 선택?" 밸런스 게임 형식
  - "갑차기스러운데 ○○해도 돼?" 템플릿 (2025년, 일본인 썸남 DM 오타에서 시작) - 누구나 자기 상황으로 변주 가능
  - "냐냐냥" - 정보 부분 공개 후 "냐냐냥" 입력하면 다음 내용 공개 (2026년 3월 정점, X·인스타·브랜드 계정까지 재유행)
  - 출처: [밈키피디아](https://letter.wepick.kr/post/23942)
- **흥미 강도**: 9 / 10
- **일반화 가능성**: 매우 높음. "한 줄 입력 → 내 카드/내 결과/내 비행기" 형태로 무한 이식 가능. **운세/사주 카테고리 아님** (입력값과 결과가 본인의 능동적 선택 + 위트 기반).

### 메커니즘 2: 친구 태그 → 무한 바이럴 엔진

- **어떻게 작동**: 콘텐츠가 본질적으로 "내 친구 ○○이는 어떻게 답할까?" 궁금하게 만듦. 댓글에 친구 태그 → 친구가 자기 버전 만들기 → 또 다른 친구 태그 → 노드 폭증. 1차 사이클의 단순 공유보다 4-5배 강력. 이미지 1장 + 캡션만으로 댓글 폭발.
- **대표 한국 사례**:
  - "윤정아 챌린지" (2026년 1월 초, 초등학생 김지윤 @j1_xun3 시작) - "윤정아~ 왜요쌤~" 영혼 없는 춤. 친구 태그하며 "너도 해봐" 확산
  - "젓가락워킹 챌린지" (2026년 2월, @sa.ram470 시작) - 친구랑 같이 찍어야 재미있는 포맷
  - 친구 태그 댓글 폭발 패턴 = 2026년 1월 초 시작된 모든 챌린지의 공통 메커니즘
  - 출처: [밈키피디아](https://letter.wepick.kr/post/23942), [careet 2026 트렌드](https://www.careet.net/1770)
- **흥미 강도**: 8 / 10
- **일반화 가능성**: 매우 높음. 웹앱 결과 화면에 "친구 ○○이는 누구일까?" CTA 박는 순간 작동. 단, 단순 "공유 버튼"으로는 부족 = 콘텐츠 자체가 "친구의 답을 궁금하게" 만들어야 함.

### 메커니즘 3: 밸런스 게임 / 양자택일 무한 변주

- **어떻게 작동**: A vs B 양자택일을 끝없이 반복. 토너먼트형(이상형 월드컵), 캐릭터 배치형(장시간 비행), 단순 선택형(밸런스 게임 표) 모두 동일 원리. **답이 없는 어려운 선택**에서 사용자의 자아 노출 + 친구와 비교 욕구 작동. 한국 X에서 2026년 1월 폭발.
- **대표 한국 사례**:
  - 장시간 비행 밈 (위와 동일)
  - PIKU (piku.co.kr) - 이상형 월드컵 전문 사이트, 2017년 시작, 2020년대 인터넷 방송인 콘텐츠 활용
  - 갈드컵 인스타 계정 @all_galdcup - 연예인/K-POP/음식/상황 모든 카테고리
  - K-POP 아이돌 / 음식 / 여행지 / 상황 등 분야 무한 확장 중
  - 출처: [이상형 월드컵 나무위키](https://namu.wiki/w/%EC%9D%B4%EC%83%81%ED%98%95%20%EC%9B%94%EB%93%9C%EC%BB%B5), [PIKU](https://www.piku.co.kr/)
- **흥미 강도**: 7 / 10 (단, 단순 PIKU형 토너먼트는 이미 포화. **장시간 비행처럼 "스토리/상황"이 들어간 변종**이 새로운 골든타임)
- **일반화 가능성**: 매우 높음. 단 "월드컵 또 만들기" 식 X. 시추에이션 + 양자택일 결합 (예: "지옥 같은 회의 중 옆자리에 ○○ vs ××") 형태로.

### 메커니즘 4: 미스터리 / 부분 공개 (단계적 언락)

- **어떻게 작동**: 답을 즉시 보여주지 않고 사용자가 한 단계씩 입력/클릭/공유해야 다음 내용 공개. "다음 컷을 보고 싶다"는 본능 자극. 2026년 3월 X·인스타 전 플랫폼 재유행 중.
- **대표 한국 사례**:
  - "냐냐냥" 밈 (2023년 카카오톡 시작 → 2026년 3월 정점) - "냐냐냥" 입력하면 다음 내용 공개. X·인스타·브랜드 계정까지 활용
  - 인스타 스토리 "직접 추가 (Add Yours)" 스티커 - 본인 추가하기 전엔 어떻게 변형되는지 안 보임
  - 출처: [밈키피디아](https://letter.wepick.kr/post/23942), [고구마팜 인스타 스토리](https://gogumafarm.kr/%EC%9D%B8%EC%8A%A4%ED%83%80%EA%B7%B8%EB%9E%A8-%EC%8A%A4%ED%86%A0%EB%A6%AC%EC%97%90%EB%8F%84-%ED%85%9C%ED%94%8C%EB%A6%BF%EC%9D%B4-%EC%9E%88%EB%8B%A4-%EA%B3%B5%EC%9C%A0%EB%A5%BC-%EB%B6%80%EB%A5%B4/)
- **흥미 강도**: 8 / 10
- **일반화 가능성**: 높음. 웹앱에서 "결과 보기 전 친구 태그" / "다음 컷 보려면 공유" / "한 단계씩 정보 공개" 모두 적용 가능.

### 메커니즘 5: 어이없음 / 위트 (장항준적 사고 = 안 맞춰주는 솔직함)

- **어떻게 작동**: 사용자가 안전하고 일반적인 답을 기대했는데 **예상 밖 솔직/대담/어이없는** 답이 나옴 → "와 이게 뭐야 ㅋㅋ" 반응 → 친구에게 캡처 보내기. 안전한 운세/사주의 정반대 포지션.
- **대표 한국 사례**:
  - "장항준적 사고" 밈 (2026년 2~3월, 천만 영화 감독 등극으로 정점) - 타인 시선 무시, 자기 행복 우선 마인드. 솔직함 + 위트의 결합
  - "GPT 밈" (와… 너 정말 핵심을 찔렀어) - 챗GPT 과잉 공감 말투 패러디 (2025년 말~2026년 초) - 안전한 답의 안티
  - "장시간 비행"도 이 결 - 답이 너무 솔직하고 어이없어서 웃긴
  - 출처: [밈키피디아](https://letter.wepick.kr/post/23942)
- **흥미 강도**: 9 / 10
- **일반화 가능성**: 매우 높음. **결과 카피의 톤이 핵심**. "당신은 친절한 사람입니다" X → "당신은 회의 중 졸면서도 회사 욕할 사람입니다" O.

### 메커니즘 6: 일상 디테일 페이크 다큐 / AI 시리즈물

- **어떻게 작동**: AI로 일상 한 부분을 과장 + 페이크 다큐 형태로 시리즈화. 사용자가 "내 일상도 저렇게 생기면 어떨까?" 상상하게 만듦. 1차 사이클의 "내 운세" 정적 카드와 정반대 = 움직이는 영상 + 시리즈성.
- **대표 한국 사례**:
  - "골반 통신" (크리에이터 퐁귀, 2025년) - "골반이 멈추지 않는" 여성의 일상. AI 편집 시리즈
  - "도마도마" (라이즈 원빈 숏폼, 브라질→중국→한국 역수입) - 일상 동작을 댄스화
  - 출처: [밈키피디아](https://letter.wepick.kr/post/23942)
- **흥미 강도**: 7 / 10
- **일반화 가능성**: 중간. 웹앱으로 옮기려면 "사용자 입력 → AI 영상/짧은 GIF 결과" 가 필요. 기술 난이도 약간 있음.

### 메커니즘 7: 토스 앱인토스형 푸시 알림 + 소액 보상

- **대표 한국 사례**:

  - 앱인토스 9개월 만에 2,000개 미니앱 돌파 (2026년 4월)
  - 출처: [토스 블로그](https://toss.im/apps-in-toss/blog/robin-26-3-13), [ZDNet Korea 미니게임](https://zdnet.co.kr/view/?no=20260501135556), [Daum 미니게임](https://v.daum.net/v/20260507063412054)
- **흥미 강도**: 6 / 10 (단독 흥미는 약함. 다른 메커니즘과 결합 시 강력)
- **일반화 가능성**: 높음 (단, 우리 웹앱은 토스 안이 아니라 독립이므로 푸시 보상 X. "재방문 유인" 메커니즘 별도 설계 필요)

## 추천 Top 3 (흥미 강도 기반)

### Top 1: 장시간 비행형 "시추에이션 양자택일" 웹앱
- **결합 메커니즘**: 능동 과몰입 (1) + 밸런스 게임 (3) + 위트 (5) + 친구 태그 (2)
- **왜**: 1) 1차 사이클 함정 0건 (운세/사주/MBTI 아님) 2) 2026년 1월 말부터 현재까지 한국 X·인스타·커뮤니티 전 플랫폼 점령 중 = 골든타임 진행 중 3) 친구 태그로 자동 바이럴 4) 결과 캡처 = 자동 공유 5) 동남아 이식 가능 (현지 시추에이션으로 변주)
- **차별화**: "오늘의 ○○ 카드" 류 X. **"오늘 회의에서 옆자리 누구?" "여행 가는데 누구랑?" 같은 일상 시추에이션 + 캐릭터 자동 배치 + 양자택일 + 결과 카피의 어이없음/위트**

### Top 2: 냐냐냥형 "단계적 언락 콘텐츠"
- **결합 메커니즘**: 미스터리 (4) + 능동 과몰입 (1) + 친구 태그 (2)
- **왜**: 2026년 3월 정점 진행 중. "한 번에 다 안 보여주기" = 체류 + 공유 강제. 단순 결과 카드보다 4-5배 강력
- **차별화**: 사주 카드 X. 예: "친구 A에 대한 진실 5단계 공개 - 1단계는 봤어요, 2단계 보려면 친구한테 공유"

### Top 3: AI 의외성 + 위트 결합 (한국어 카피)
- **결합 메커니즘**: AI 의외성 (8) + 위트 (5) + 친구 태그 (2)
- **왜**: 나노바나나 한국어 이미지 화제 + GPT 밈 결로 안전한 답 안티 = 결합 시 강력
- **차별화**: 단순 AI 이미지 생성기 X. **"사용자 한 줄 입력 → AI가 솔직/어이없는 결과 카피로 변환 + 한국어 캡션 이미지 자동 생성 → 캡처 공유"** 형태. 단 기술 난이도가 Top 1/2보다 높음

## 다른 R1 조사자에게 전달할 인사이트

### researcher-pain에게
- **페인 vs 재미는 결합 가능**: "장시간 비행"이 성공한 이유는 **답답한 비행 = 페인** + **선택의 위트 = 재미** 결합. 너의 페인 후보 중 "재미/위트로 풀 수 있는 페인" 찾으면 잭팟. 단순 "직장인 우울" 같은 무거운 페인은 1차 사이클 사주처럼 함정.
- **추천 페인 후보 카테고리**: 비행/대중교통 답답함, 회의 지옥, 단톡방 안 읽음, 인스타 알고리즘 답답함, AI 시대 자존감 (재밌게 풀 수 있음)
- **금지 페인**: 우울증/번아웃/현타 (재미로 풀기 어려움, 1차 무거움 함정 재현)

### researcher-newcat에게
- **메커니즘 7개는 너의 신생 카테고리에 이식 가능**: 능동 과몰입 / 친구 태그 / 양자택일 / 미스터리 / 위트 / AI 의외성. 너가 발굴할 신생 카테고리 (예: 게임화/AR/현지 페인포인트)에 이 메커니즘 중 2-3개를 결합해야 진짜 화제 가능.
- **단순 신생 = 함정**: "한국에 없던 카테고리" 자체로는 안 됨. 화제 메커니즘 결합이 필수. 1차 사이클이 그래서 실패 = 카테고리는 신생이었지만 메커니즘이 단순 "결과 카드" 였음.
- **확인 요청**: 너가 발굴한 동남아/글로벌 신생 카테고리 중 위 8개 메커니즘 결합 가능한 게 몇 개인지 알려주면 좋겠음.
