## 미친 후보 (5개)

### 후보 1: "Wingman Court" - 친구가 내 연애 결정을 강제로 내려주는 앱 (24h 판결 강제)

**한 줄 컨셉**: 사용자가 자기 연애/썸 상황을 익명 카드로 올리면 친구들(서클 3-7명)이 24시간 안에 "고백해 / 차단해 / 기다려" 3개 중 다수결로 판결을 내림. 본인은 결과를 거부 못 함. 거부 시 서클에서 본인이 자동 퇴출됨.

**왜 미쳤는가** (3줄 이상):
- 자기 의지 박탈. 디지털 시대에 정반대 행동 = 자율성을 의도적으로 친구에게 위임. 자유의지를 좋아하는 서구권 UX 상식 박살.
- 결과 거부 시 본인 퇴출이라는 페널티가 잔인함. 친구 관계를 게임 자원으로 만드는 행위 = 윤리적으로 회색
- 연애 결정은 가장 사적인 영역인데, 그걸 친구에게 강제 위임 = 한국적 "친구가 더 잘 알아" 문화의 극단 + 동남아 community-rooted 의사결정 문화 + 인도네시아/필리핀 가족 의사결정 문화의 디지털화

**왜 그래도 통할 수 있는가** (3줄 이상):
- 한국 Krushdating 2026 트렌드: Gen Z 아시아인이 swiping mentality 거부, community-rooted connection으로 회귀 (krushdating.co 기사). "친구 동의" 가 의사결정 단계에 이미 있음
- 결정 마비 (Decision paralysis) 가 Gen Z의 핵심 페인. Match Group 보고서 "readiness paradox" - 하드런칭 두려움으로 인한 데이팅 마비 (fortune.com)
- 익명이라 본인 정체 노출 X. 친구는 "X가 누군지 모르고" 판결. 결과만 X에게 전달. 윤리적 회색 영역을 익명으로 비껴감
- 강제성 = 바이럴 후크. "내 친구는 나한테 차단하라고 했다" 캡처를 SNS에 올림 = 자동 마케팅

**비슷한 글로벌 사례**:
- Sendit/NGL (Snapchat 익명 Q&A) - 익명성 + 친구 압박 부분 비슷. 하지만 그건 단순 질문. 우리는 "강제 판결".
- 222 / Friending - 친구 결정에 자율 위임. 하지만 그건 만남 매칭. 우리는 연애 결정 본체.
- Hopscotch (없어진) - 친구 압박 메커닉 시도. 하지만 그건 응답 강제. 우리는 결과 강제.

**인간 심리 어디 자극**:
- 결정 마비 (analysis paralysis) → 외부 의존
- FOMO + 친구 인정 욕구 + 자기 책임 회피
- 베트남/필리핀/인도네시아의 "친구가 너에 대해 더 잘 알아" 신뢰 문화
- 한국 Gen Z의 "썸 단계 무한 늘림"에 대한 자가 처방 욕구

**위험/논란 요소** (정직하게):
- 친구 익명 판결이 잘못된 경우 책임 소재. 누군가 다치면 누가 책임?
- 청소년 사용 시 윤리적 폭탄. 13세+ 강제 (COPPA Sendit 사고 참고)
- 본인 퇴출 페널티 = 약한 친구 관계 강제. 게임화 윤리 회색
- 우울증/자해 위험 있는 사용자에게 "차단해" 판결 = 잠재적 위험

### 후보 2: "Confession Roulette" - 매일 1명, 너의 비밀을 듣고 영원히 사라지는 친구

**한 줄 컨셉**: 매일 24시간마다 앱이 본인 친구 명단에서 랜덤 1명을 골라 알려줌. 그 사람에게 본인이 평소 말 못 한 비밀/속마음/사과를 음성/텍스트로 보내야 함. 메시지는 받는 사람만 24시간 본 후 자동 영구 삭제. 답장 불가. 그 친구는 다음 날부터 본인 명단에서 영구 제거됨 (다시 추가 불가).

**왜 미쳤는가** (3줄 이상):
- 친구 관계를 의도적으로 "1번 쓰고 버림". 이건 우정의 정반대 가치임. "내가 평생 친구 100명 다 거치면 끝" 컨셉
- 강제성 + 비가역성 결합. 한 번 친구 잃으면 다시 못 옴. 사용자가 "이거 진짜 보낼까?" 1시간 고민함
- 답장 불가 = 한쪽만 말함. 대화 X 일방통행. 우정 = 양방향이라는 상식 박살
- 친구 관계의 신성함을 콘텐츠 거래소로 격하. 윤리적 핵폭탄

**왜 그래도 통할 수 있는가** (3줄 이상):
- 동남아 Gen Z 외로움 핵심: 필리핀 = 동남아 최고 외로움 + 가장 연결됨 (seasia.co). 모순적 페인.
- 한 번도 못 말한 비밀을 "1회용으로 친구에게 토로" = 심리 치료에 가까운 카타르시스
- 비가역성이 바이럴 후크. 사용자가 "오늘 나는 X를 잃었지만 마지막으로 진실을 말했다"를 인스타에 올림 = 비통한 콘텐츠 = TikTok에서 폭발
- BeReal/Locket이 "친구와 매일 사진" 으로 성공. 우리는 "친구와 매일 진실" 의 다크 버전

**비슷한 글로벌 사례**:
- Locket - 매일 친구와 사진 공유. 우리는 그 다크 버전.
- BeReal - 강제 매일 1회. 우리는 강제 + 비가역.
- Snap 메시지 사라짐 - 비슷한 임시성. 우리는 친구 관계 자체도 사라짐.

**인간 심리 어디 자극**:
- 카타르시스 욕구 (말 못 한 비밀의 무게)
- 죽기 전 후회 심리 (You're going to die!)
- 한국/필리핀/베트남의 "체면 때문에 못 한 사과" 문화의 출구
- 메멘토 모리 - 관계는 영원하지 않다는 진실

**위험/논란 요소** (정직하게):
- 정신건강 위험 1급. 우울증 있는 사용자가 "마지막 메시지" 컨셉을 자살 의도로 해석할 가능성
- 친구 명단에 가족 포함 시 가족 관계 파괴 가능
- "친구 다 거치면 끝" 컨셉이 다단계 마케팅처럼 친구 강제 추가 유도 가능
- 본인 1회 사용 후 후회 가능성 100%. 환불/복구 정책 필요

### 후보 3: "Mom Mode" - 부모님이 절대 못 보는 친구만의 페이크 인스타 (Gen Z 동남아 효도 가족 강제 문화 회피 전용)

**한 줄 컨셉**: 부모님/친척 검증 차단 SNS. 가입 시 본인 가족 휴대폰 번호 (또는 인스타/페이스북 계정)를 등록하면 그 사람들이 절대로 검색/발견 못 함. 친구 초대도 본인 인증 후 "이 친구의 가족도 차단함" 확인 필수. 핵심 기능: 본인이 친구에게 "오늘 부모님이 X 때문에 화났음. 진짜 토했음." 류 글을 올림 = 동남아/한국 Gen Z의 부모 회피 욕구 전용 안전지대.

**왜 미쳤는가** (3줄 이상):
- 부모님 차단을 핵심 기능으로 광고. 가족 윤리에 정면 도전. 동남아/한국 사회에서 매우 도발적
- 가족이 "이 앱이 뭔데 너만 가입돼있고 우린 안 돼?" 라고 물으면 본인이 거짓말 해야 함 = 거짓말 강제
- "가족 차단" 자체가 마케팅 카피 = Apple App Store 정책 위반 가능성. 한국/베트남 부모 단체 항의 예상
- 안티-가족 컨셉을 정면으로 내세움 = 어른들이 욕할수록 Gen Z가 더 좋아함 (반항 메커닉)

**왜 그래도 통할 수 있는가** (3줄 이상):
- 페인포인트 데이터: 필리핀 230만 명이 해외 노동, Gen Z가 부모 없이 자람 (seasia.co). 부모 없는 일상 vs 가끔 와서 검열하는 부모 = 모순
- 한국 Gen Z의 "엄카" "엄빠 인스타 친추" 검열 페인 - 모든 한국 Gen Z의 보편적 페인
- 동남아 가족 문화 = WhatsApp 가족 단톡 검열 + 인스타 부모 친추 = 진짜 페인이지만 아무도 정면 솔루션 안 만듬
- 마케팅 카피 자체가 바이럴: "엄마가 못 보는 인스타" = 인스타에서 광고하면 자동으로 Gen Z가 가입
- 안전한 답 (예: 인스타 비밀계정 = 핀스타) 보다 훨씬 강력한 인증 차단

**비슷한 글로벌 사례**:
- 핀스타/세컨드 인스타 - 본인이 수동으로 만듦. 우리는 시스템이 강제 차단.
- Snap Stories - 친구만 봄. 하지만 부모도 친추 가능. 우리는 부모 원천 차단.
- Sidechat - 학생만 (대학 이메일 인증). 우리는 가족만 차단.

**인간 심리 어디 자극**:
- Gen Z의 부모 분리 욕구 (한국/동남아 = 분리 늦은 사회)
- 반항 + 안전 동시 욕구 (어른 모르게 + 친구는 진짜로)
- 동남아 가족 의무 vs 개인 성장 사이의 균열

**위험/논란 요소** (정직하게):
- 청소년이 위험한 행동 공유 시 부모가 막을 방법 X = 안전 사고 책임
- App Store 정책상 "가족 차단" 마케팅이 문제 될 수 있음
- 본인 아이폰 가족 공유 (Family Sharing) 사용 시 시스템상 차단 불가능
- 정치적 후폭풍: 보수 가족 가치 단체의 표적이 될 수 있음

### 후보 4: "Friendvy" - 친구가 너를 얼마나 부러워하는지 실시간 점수로 보여주는 앱

**한 줄 컨셉**: 본인 인스타/틱톡/링크드인 공개 활동을 친구 5-15명이 익명으로 "부럽다 / 안 부럽다" 1초 안에 평가. 그 결과를 본인에게 매주 "이번 주 너의 친구 부러움 지수: 73점 (지난주 81점). 가장 부러워한 게시물: X" 라고 알려줌. 친구는 자기가 "부럽다" 누르고 있는지 본인은 모름. 본인은 자기가 누구를 부러워하는지 친구에게 강제 공개.

**왜 미쳤는가** (3줄 이상):
- 부러움이라는 감정을 정면으로 측정 + 점수화. 모두가 부정하는 감정을 핵심 기능으로 만듦
- 비대칭 정보: 친구는 익명, 본인은 강제 공개. 이중 잣대를 의도적으로 설계 = 윤리적 회색
- 친구 관계를 경쟁 게임으로 만듦. 우정 = 협력이라는 상식 박살
- 부러움 점수 73 → 본인 자아 통째로 흔들림 = 사람 망가뜨리는 앱

**왜 그래도 통할 수 있는가** (3줄 이상):
- 다크 심리 데이터: 여성 Gen Z가 SNS 친구 부러움 1위 (psypost.org). 정확한 페인포인트 존재
- Friendvy 단어 자체가 Psychology Today에 등재 (psychologytoday.com/friendvy). 트렌딩 컨셉
- 다른 앱들이 부러움을 부정하지만 (Instagram = 진짜 모습, BeReal = 꾸미지 않은), 우리는 정면으로 인정
- 자아 흔들림 = 중독성. 매주 점수 확인 욕구 = 리텐션 1급
- 한국 인스타 비교 문화의 솔직한 거울. 모두가 비교하지만 인정 안 함. 인정 시 카타르시스

**비슷한 글로벌 사례**:
- Gas app - 익명 친구 칭찬. 우리는 정반대 (익명 친구 부러움).
- 부유 비교 앱 (직장인 부의 비교 - 도토리/위제이) - 본인이 자랑. 우리는 친구가 평가.
- LinkedIn - 자기 자랑 강제. 우리는 부러움 측정.

**인간 심리 어디 자극**:
- 사회 비교 이론 (Festinger 1954)
- "비교는 기쁨의 도둑" 인 줄 알면서도 못 끊는 중독
- 디지털 시대 자기 가치 측정 욕구
- 베트남/필리핀 Gen Z의 가족/친구 성공 비교 문화

**위험/논란 요소** (정직하게):
- 점수 30점 받은 사용자 정신건강 즉각 위험. 우울증 트리거
- 청소년 사용 시 자해 위험 (점수가 친구 인기 = 학교 사회 서열로 인식 가능)

### 후보 5: "Last Words Lottery" - 매일 랜덤 시각에 "지금 죽으면 마지막으로 하고 싶은 말 한 줄"을 친구에게 강제 전송

**한 줄 컨셉**: 메멘토 모리 + Locket + 위챗 모멘트. 매일 랜덤 시각에 알림 = "지금이 너의 마지막 1분이라면 친구 X에게 뭐라고 할래?" 알림 받고 5분 안에 답하지 않으면 자동으로 "응답 없음" 이 친구에게 전송됨. 답하면 친구에게 음성/텍스트 전송 + 즉시 자동 삭제 (스크린샷도 차단). 친구는 본인이 "마지막 말" 받았다는 사실만 영구 기록. 내용은 1회 보고 사라짐.

**왜 미쳤는가** (3줄 이상):
- 죽음을 매일 일상 알림으로 만듦. 메멘토 모리 의식을 강제. 종교적/윤리적 회색
- "응답 없음" 자동 전송 = 친구가 "쟤가 나한테 마지막 말 안 했음" 영구 기록 = 친구 관계 즉각 손상
- 미국 메이저 앱들이 절대 안 만드는 톤. 죽음을 미국 + 동남아에서 매일 광고할 컴포저 = 미친 짓
- 자살 우려 사용자가 진짜 마지막 말 전송 시 시스템이 구분 못 함 = 책임 폭탄

**왜 그래도 통할 수 있는가** (3줄 이상):
- WeCroak/Memento Mori Death Clock - 죽음 알림 앱 이미 시장 존재 + 성공 (apps.apple.com Memento Mori). 시장 검증됨
- 동남아 불교 문화권 (베트남/태국/캄보디아/라오스) = 메멘토 모리 + 무상관 (無常觀) 자연스럽게 수용 가능. 미국 기독교권보다 거부감 적음
- 한국 "오늘이 마지막인 것처럼 살아라" 자기계발 클리셰의 강제 실행 버전
- 메시지 1회 삭제 + 친구 기록만 남음 = 콘텐츠 X, 사건만 남음 = 강력한 emotional anchor
- 매일 강제 = 리텐션 1급. 알림 안 무시 가능 (못 무시. 무시 = 친구에게 통보됨)

**비슷한 글로벌 사례**:
- WeCroak - 매일 5회 "넌 죽는다" 푸시. 시장 검증.

**인간 심리 어디 자극**:

## "안 만들어진 이유가 사실은 잘못된 가정"인 케이스 분석

### 케이스 1: "친구 사이에 부러움을 정면으로 측정하면 안 된다" (후보 4 Friendvy 가정)

**가정**: 친구 관계는 협력. 부러움은 부정적 감정이라 측정/공개 시 친구 관계 파괴된다.

**왜 그 가정이 틀린가**:
- BeReal/Locket이 "꾸미지 않은 진짜 모습" 으로 친구 사이 비교 강도를 오히려 높였다. 즉 SNS = 비교 = 부러움. 부러움을 부정하는 게 거짓말.
- Gen Z는 이미 "Friendvy" 단어를 자체 발명함 (Psychology Today 2026). 페인이 이미 분명하고 이름까지 있음.
- 정면으로 이름 붙이는 게 카타르시스. AA Anonymous 모델 = "나는 알코올 중독자입니다" 인정이 회복의 첫걸음. 부러움도 동일.
- 친구가 익명이면 친구 관계 직접 손상 X. 본인 자기 인식만 흔들림 = 자기 성장의 도구로 포지셔닝 가능.

### 케이스 2: "친구 관계는 영원해야 한다. 일회용으로 만들면 안 된다" (후보 2 Confession Roulette 가정)

**가정**: 우정 = 평생. 1번 사용 후 친구 명단 제거는 비인간적.

**왜 그 가정이 틀린가**:
- 던바의 수 (Dunbar's number): 인간은 평생 약 150명 안에서 친구 관계 유지. 그 외 친구는 사실 "친구" 가 아닌 "지인" - 우리는 솔직히 인정 안 함.
- 인스타/페북 친구 평균 = 500명+. 이 중 진짜 친구는 5-15명. 나머지는 이미 죽은 관계. 우리는 사망 처리 안 했을 뿐.
- 일회용 = 의미 부여. "마지막"이라는 압박이 평소 못 한 말을 끌어냄. 평소 매일 만나는 친구에게 진심을 못 함이 디지털 시대 페인.
- 동남아 "체면 문화" 페인포인트 - 죽기 전에 못 한 사과의 무게. 1회용 메커닉이 출구.

### 케이스 3: "부모님 차단을 마케팅 카피로 쓰면 안 된다" (후보 3 Mom Mode 가정)

**가정**: 가족 가치 = 신성. 부모 차단 앱은 사회적으로 욕먹는다.

**왜 그 가정이 틀린가**:
- 호주 16세 미만 SNS 금지법 (time.com) - 사회가 이미 청소년 SNS = 부모 모르게 공간으로 인정. 단지 어른들이 "차단" 단어를 못 쓸 뿐.
- Snapchat이 성공한 핵심 이유 = "부모님이 못 봄" (메시지 자동 삭제). 즉 "Mom Mode" 컨셉은 이미 검증됨. 단지 정면으로 광고 안 했을 뿐.
- 동남아 가족 단톡 검열 + 인스타 부모 친추 페인 = 모든 Gen Z 보편 페인. 솔직히 광고하면 "내 마음 알아주는 앱" 으로 작동.
- 어른들이 욕할수록 Gen Z 가입률 ↑ (반항 메커닉 검증된 마케팅).
- 한국 "엄카" "엄빠 친추" 검색량 = 압도적. 페인 X. 페인 표현 단계 X. 솔루션 X. 표현 솔루션 발명 단계.
