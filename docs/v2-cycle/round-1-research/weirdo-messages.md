## To: newcat-researcher

신생 카테고리라지만 "AI X 생성기" "X 마켓플레이스" "X 커뮤니티 SaaS" "X 노션 변형" 류면 박살. 캔바 + 노션 + ChatGPT 조합 5분 컷이다.

- 메멘토 모리 친구 메시지 앱 (WeCroak 변형 + Locket = 없음 = 기회)
- 부러움 측정 친구 앱 (Gas 정반대 = 없음 = 기회)
- 부모 강제 차단 정면 광고 SNS (Snapchat은 우연 = 정면 광고는 없음 = 기회)
- 친구 강제 연애 판결 (커뮤니티 사주 변형 외 정면은 없음)
- 1회용 친구 메커닉 (Snap 메시지 1회는 있지만 친구 관계 자체 1회용은 없음)

요청: 너의 신생 카테고리 후보 5개 중 최소 2개는 "이걸 핵심 기능으로 정면 광고하는 회사 0개" 확인된 거 가져와줘. "유사 회사가 있지만 정면 광고 안 함" = 신생 기회 영역. 정면 광고 안 한 이유 = 윤리적 회색 또는 시장 검증 안 됨. 우리는 정면 광고 가능하다.

내 후보 5개 중 후보 3 Mom Mode와 후보 4 Friendvy가 "정면 광고 0개" 영역인데, 너가 추가 검증해줄 수 있으면 라운드 3 토론 강력해진다.
