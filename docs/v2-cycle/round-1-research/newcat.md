### 카테고리 1: AI Alien Companion (외계인 캐릭터 AI 동반자)

- **정의**: 친근한 외계인/판타지 캐릭터 마스크를 씌운 AI 채팅 동반자. character.ai 같은 "여친/남친" 류 무거움을 피하고, 귀여운 외계인 페르소나로 외로움/일상/고민 상담 받는 형태
- **대표 사례 3개**:
  - **Tolan** (Portola, 2025-02 iOS 출시): "행성 Portola에서 온 외계인 친구". 12명 팀, 4개월 만에 ARR $1M → $12M, 다운로드 300만+, 페이드유저 100,000+, 평균 세션 30-40분. 출처: https://www.geekwire.com/2025/ai-companionship-app-tolan-raises-20m-to-help-more-people-grow-with-a-virtual-alien-friend/
  - **Pengu (Born)**: AI 가상 펭귄 펫 + 2인 협동 양육(친구/연인). 글로벌 1500만+ 유저, $15M 시리즈 A. 출처: https://techcrunch.com/2025/09/10/born-maker-of-virtual-pet-pengu-raises-15m-to-launch-a-new-wave-of-social-ai-companions/
  - **Sweekar (Takway, CES 2026)**: 손바닥 크기 알 모양 AI 펫 디바이스. 사용자 목소리/활동 기억, 성장 후 자기 모험담 들려줌. 출처: https://www.engadget.com/ai/sweekar-turns-the-tamagotchi-into-a-physical-ai-pocket-pet-that-wont-die-on-you-023525228.html
- **왜 새로운가**:
  - character.ai = "유명 인물 빙의" 모델 (저작권 시끄러움, 미성년 자살 사건 후 18금)
  - Tolan = "친근한 외계인" 모델. 인간/유명인 모방 안 함 = 법적 안전 + 어린 사용자도 안전
  - Replika = "치료/연애 동반자" 무거움. Tolan = "친구/일상 동반자" 가벼움
- **왜 통하는가**:
  - 외로움 epidemic (특히 Gen Z/Gen Alpha). 미국 10대 72%가 AI 동반자 사용
  - "유명인/실존 인물 모방" 위험 없음 = 부모/플랫폼 안심
  - 캐릭터 디자인 자체가 viral 자산 (TikTok 친화적, 굿즈화 가능)
- **출처 URL**:

  - https://techcrunch.com/2025/08/12/ai-companion-apps-on-track-to-pull-in-120m-in-2025/

- **사이드프로젝트 가능성**: ⭐⭐⭐⭐ (Lovable 등으로 캐릭터 + GPT 래퍼 만들기 쉬움. 진짜 viral은 캐릭터 디자인이 결정). 1인 가능

### 카테고리 2: Friendslop / Co-op Chaos (저예산 카오스 협동)

- **정의**: 저화질/저예산 + 핵심은 친구 4-8명과 음성으로 어이없이 망하기. "Lethal Company" (2023) 시작 → 2025년 PEAK가 정점 찍으며 장르 정착. 콘텐츠 크리에이터 스트리밍 = 자체 마케팅
- **대표 사례 3개**:
  - **PEAK** (2025): 협동 등반 게임, $7.99. 출시 9일 200만 카피, 1년 1000만 카피, 두 인디 스튜디오가 휴가 가려다가 폭발. 출처: https://www.gamesradar.com/games/survival/peak-put-friendslop-on-the-map-in-2025-but-neither-of-its-2-studios-expected-it-to-blow-up-we-were-ready-to-hit-the-launch-button-and-go-into-vacation-mode/
  - **Crashout Crew** (2026, PEAK 후속 트렌드): 지게차 + 창고 협동 (PEAK 메커니즘을 직장으로 옮긴 변형). 출처: https://gamerant.com/new-steam-game-like-peak-crashout-crew-funny-co-op-rage/
  - **Lethal Company** (2023, 원조): 우주공포 협동, 1인 개발자 Zeekerss, 누적 1000만 카피+
- **왜 새로운가**:
  - 기존 협동 게임 = 트리플 A 화질 (Among Us 빼고)
  - Friendslop = 저화질 의도적, 핵심은 "내 친구가 멍청한 짓으로 우리 다 죽음" 음성 채팅 + Twitch 스트림
  - 게임 디자인 자체에 "viral 클립 만들 메커니즘" 의도적 설계 ("바나나 껍질 추가하면 영상 더 뽑힌다" - PEAK 개발자 자백)
- **왜 통하는가**:
  - Twitch/유튜브 콘텐츠 크리에이터가 무료 마케팅 (PEAK 마케팅 99% 입소문)
  - 가격 $5-10 = teen 지갑 친화
  - proximity voice chat이 신생 소셜 메커니즘
- **출처 URL**:

  - https://www.gamesmarket.global/the-rise-of-friendslop-why-low-fidelity-social-chaos-is-shaking-up-the-games-industry/
  - https://www.pcgamer.com/games/2025-was-the-year-friendslop-reigned-and-so-many-low-cost-ways-to-have-fun-with-your-pals-couldnt-have-come-at-a-better-time/
  - https://kotaku.com/steam-top-selling-2025-friendslop-rpgs-sales-2000654157
  - https://www.thegamer.com/peak-best-viral-game-played-crab-game-repo/
- **한국에 들어왔는가**: ⚠️ PEAK 자체는 글로벌 인기지만 한국발 friendslop은 0건. "K-친구슬롭" 미존재. **점수 +**
- **사이드프로젝트 가능성**: ⭐⭐ (게임 엔진 필요, 비개발자 1인 어려움. 단 "웹 기반 카오스 협동" + "vibe coding" + Rosebud.ai 같은 텍스트→게임 도구로 simple version 가능)

### 카테고리 3: Looksmaxxing / Single-Selfie Quantification (셀카 점수화 + 개선 가이드)

- **정의**: 셀카 1장 → AI가 정량 점수 (대칭/턱선/마사질리니티/PSL 점수) + 개선 액션 아이템 (mewing/hairstyle/스킨케어). 4chan looksmaxxing 서브컬처가 mainstream 진입. teen 남성층 (소녀 향 미용 시장의 male 거울 이미지)
- **대표 사례 3개**:
  - **Umax AI** (2024-2025): 얼굴 스캔, PSL 점수, "Animal face" archetype (Fox/Deer/Puppy). 73,000+ 유저. 출처: https://umaxai.app/, https://apps.apple.com/us/app/umax-ai-face-scan-rate-face/id6478508605
  - **Youmax** (2025): "Become Hot" 슬로건, Google Play 출시. 출처: https://play.google.com/store/apps/details?id=com.luminarlab.looksmaxx
  - **AI Yearbook (Epik)** 와 인접: 셀카 8-12장 → 60개 시대별 포트레이트. #AIyearbook TikTok 2.55억 뷰, 9월 2025 search interest 96 peak. 출처: https://www.dexerto.com/entertainment/how-to-do-viral-ai-yearbook-photo-trend-2320718/
- **왜 새로운가**:
  - 기존 미용 앱 = 여성층 메이크업/필터 (Snow, FaceApp)
  - Looksmaxxing = 남성층 + 객관 점수 + 개선 행동 (mewing/turkey neck 등)
  - "운세/관상"과 다른 점 = 운세는 변경 불가, looksmaxxing은 "행동→개선" 약속
- **왜 통하는가**:
  - teen 남성 self-image 위기 (틱톡 비교 문화)
  - "어떻게 개선" 행동 아이템 제공 = 운세보다 retention 강함
  - 친구간 점수 공유 = viral 메커니즘 내장
- **출처 URL**:
  - https://apps.apple.com/us/app/umax-ai-face-scan-rate-face/id6478508605
  - https://umaxai.app/
  - https://blog.looksmaxxreport.com/best-ai-styling-app-2025/
  - https://ailooksmaxing.app/
- **한국에 들어왔는가**: ⚠️ 한국식 looksmaxxing 시장 없음, 단 "관상/얼굴상" 카테고리와 충돌 위험 → 변형 필요. "관상" 아닌 "행동→변화" 프레임으로 차별. **점수 △**
- **사이드프로젝트 가능성**: ⭐⭐⭐⭐⭐ (얼굴 인식 API + GPT-4o vision으로 1인 빌드 가능. 진짜 어려운 부분 = ethical line 안 넘기) - 단 "외모 점수화" 자체가 mental health 위험 → **민감 카테고리, 우회 변형 필요**

### 카테고리 4: Photo-Tap Quantification (사진 한 장 → 정량 측정)

- **정의**: 카메라 한 번 누르면 → AI가 정량 수치/식별/측정. Cal AI(음식→칼로리), Umax(얼굴→점수), Plant ID(식물→종), Polycam(공간→3D), Luma(객체→3D)가 같은 메커니즘. "Snap and Get a Number"가 새 인터랙션 패러다임
- **대표 사례 3개**:
  - **Cal AI** (2024-05 출시, 두 명의 18세 - Zach Yadegari + Henry Langmack): 사진→ 음식 분류 + iPhone depth sensor로 부피 → 칼로리/단백질/탄수/지방. 5M+ DL 8개월, 8.3M DL 7월 시점, 월매출 $2M+, 월 수익 $1.4M. 출처: https://techcrunch.com/2025/03/16/photo-calorie-app-cal-ai-downloaded-over-a-million-times-was-built-by-two-teenagers/
  - **Polycam**: iOS LiDAR 활용 3D scan + 평면도 자동 생성. 54만+ 리뷰 4.7점. 출처: https://apps.apple.com/us/app/polycam-3d-scans-floor-plans/id1532482376
  - **Plantum / Seek by iNaturalist**: 식물 사진 → 종 식별 + 가이드. 2025 정확도 96%. 출처: https://myplantum.com/blog/your-guide-to-choosing-the-best-plant-identifier-app-in-q4-2025/
- **왜 새로운가**:
  - 2020-2022: 사진 = "예쁘게 찍기/필터"
  - 2024-2026: 사진 = "측정 도구" (Vision API + LLM이 한 장으로 정량 가능해진 게 큰 변화)
  - 새로운 인터랙션 grammer = "셔터 누르기 = 답 얻기"
- **왜 통하는가**:
  - 시간/노력 0 (입력 1초)
  - 결과가 객관적 숫자 = 만족도 명확
  - Cal AI: 18세 두 명이 $20M+ ARR 페이스 = template 검증됨
- **출처 URL**:
  - https://techcrunch.com/2025/03/16/photo-calorie-app-cal-ai-downloaded-over-a-million-times-was-built-by-two-teenagers/
  - https://www.cnbc.com/2025/09/06/cal-ai-how-a-teenage-ceo-built-a-fast-growing-calorie-tracking-app
  - https://www.calai.app/
  - https://poly.cam/
- **한국에 들어왔는가**: ⚠️ Cal AI 한국어 정식 출시 X, 칼로리 측정 외 분야 한국화 0건. **점수 +**
- **사이드프로젝트 가능성**: ⭐⭐⭐⭐⭐ (GPT-4o vision API + 모바일 카메라 = 비개발자도 vibe coding으로 빌드 가능). 1인 가능, 18세 두 명이 증명

### 카테고리 5: Co-parented Virtual Companion (2인 공동 양육 가상 펫/AI)

- **정의**: AI 동반자/펫을 혼자가 아닌 2명(친구/연인/가족)이 함께 키움. 단순 펫 키우기 + 닫힌 소셜 (NGL/BeReal 류 closed-network) 결합. Locket 형태의 widget도 발전
- **대표 사례 3개**:
  - **Pengu (Born, 2024-2025)**: 두 명이 함께 키우는 AI 펭귄. 미니게임, 공동 양육 의무. 15M+ 유저. 출처: https://techcrunch.com/2025/09/10/born-maker-of-virtual-pet-pengu-raises-15m-to-launch-a-new-wave-of-social-ai-companions/
  - **Locket** (2025 신기능): 위젯 + Rollcall (주1회 친구들과 사진덤프, 7일 후 사라짐). Gen Alpha 사용자 80% 점유. 출처: https://techcrunch.com/2025/11/03/lockets-social-app-is-picking-up-steam-with-gen-alpha/
  - **Shared Notes: Couples & AI**: 커플/그룹 공유 노트 + AI 정리. 10,000+ 커플. 출처: https://apps.apple.com/us/app/shared-notes-couples-ai/id6748648868
- **왜 새로운가**:
  - Tamagotchi/Neko Atsume = 혼자
  - Snapchat/Locket = 사진만, 공동 행위 없음
  - Pengu = "함께 키우는 의무 + 공유 추억 형성" = 친구간 retention 메커니즘
- **왜 통하는가**:
  - 친구 1명만 끌어와도 둘 다 잠금 = 2x 1+1 viral loop
  - "내가 안 들어가면 친구가 불쌍해진다" = guilt-driven engagement
  - 친밀감 + 공동 책임 = parasocial을 친구 사이로 옮긴 변형
- **출처 URL**:
  - https://techcrunch.com/2025/09/10/born-maker-of-virtual-pet-pengu-raises-15m-to-launch-a-new-wave-of-social-ai-companions/
  - https://techcrunch.com/2025/11/03/lockets-social-app-is-picking-up-steam-with-gen-alpha/
  - https://apps.apple.com/us/app/locket-widget/id1600525061
- **한국에 들어왔는가**: ⚠️ Pengu 한국어 X, K-커플/친구 공동 펫 0건. 카카오톡 friends 캐릭터와 결합 가능성. **점수 +**
- **사이드프로젝트 가능성**: ⭐⭐⭐⭐ (백엔드 2인 동기화 필요 = 약간 복잡. Firebase + 캐릭터 디자인으로 vibe coding 가능)

### 카테고리 6: Ambient Voice Ramble → Structured (음성 횡설수설 → 정돈된 결과물)

- **정의**: 사용자가 운전/산책/샤워 중 음성 메모로 횡설수설 → AI가 구조화된 노트/할일/요약/블로그/이메일로 변환. "타이핑/구조화 노력 0" 인터페이스
- **대표 사례 3개**:
  - **AudioPen** (Louis Pereira 1인 개발): 음성→정돈 텍스트, 어떤 스타일이든. 메모/이메일/블로그. 출처: https://www.audiopen.ai/
  - **Cleft Notes**: AI Scribe로 노트 캡처+공유. 출처: https://www.cleftnotes.com/
  - **Todoist Ramble** (2026-01 정식): 음성 → 구조화된 할일 (프로젝트/날짜/우선순위 자동). 베타 3주 만에 76,000명, 290,000+ 세션. 출처: https://www.morningstar.com/news/pr-newswire/20260121la67618/introducing-todoist-ramble-ai-that-turns-natural-speech-into-structured-tasks
- **왜 새로운가**:
  - 기존 음성 메모 = 다시 들어야 함 (재청취 비용 큼)
  - 기존 voice-to-text = 그대로 옮김 (구조 없음)
  - 신생 = "구조 없이 떠들면 AI가 분류+정돈"
- **왜 통하는가**:
  - 산책/운전/샤워 = "타이핑 불가능" 골든 인풋 시점
  - Whisper + GPT-4o = 한국어/방언/소음 환경 다 처리
  - retention 강함 (한번 익숙해지면 타이핑 못 돌아감)

## 동료에게 공유한 의견 (협업 인사이트)

### sea-researcher (동남아 페인포인트 담당)에게 보낸 인사이트
- **Tolan-style alien companion**: 동남아 (Vietnam/Philippines/Indonesia) teen 외로움 시장 거대. 미국 외계인은 white-coded - 동남아 현지 신화/캐릭터 (Indo의 wayang, Filipino의 tikbalang, Vietnam의 cá hêu)를 마스크로 쓰면 cultural fit + viral potential 강함
- **Photo→Quantify (Cal AI 식)**: 동남아 길거리 음식이 칼로리 DB에 없음 = Cal AI 못 씀. 동남아 음식 전용 (pho/nasi goreng/sinigang) Photo→Calorie 큰 화이트 스페이스. 두리안/람부탄 등 트로피컬 과일도 미국 앱 식별 정확도 낮음
- **2인 공동 가상펫**: 동남아 끈끈한 친구/가족 문화 (특히 Filipino "barkada", Indo "geng") = Pengu보다 더 4-8명 공동 양육 가능. 단 인터넷 안 좋은 지역은 offline-first 필수
- **Memorial Voice**: 동남아 가족 효도 문화 + 부모/조부모 사망 시 mourning 의례 깊음 (Filipino lola/lolo 추모, 베트남 조상 제사) = ReLiveable의 동남아 변형 가능

### viral-researcher (바이럴 메커니즘 담당)에게 보낸 인사이트
- **Friendslop의 viral 메커니즘 = 디자인 의도**: PEAK 개발자 자백 "바나나 껍질 넣으면 조회수 늘어난다 알았다". viral할 클립 생성을 게임 메커니즘 안에 박은 게 핵심. 우리도 "이 앱 사용하면 자동으로 viral 클립 생성됨" 메커니즘 박을 수 있는가?
- **Tolan TikTok 마케팅**: 12명 팀 / 저예산 / 콘텐츠 크리에이터 협업 = $12M ARR. K-TikTok 크리에이터 협업 모델 그대로 적용 가능. 캐릭터 자체가 viral 자산
- **Locket Rollcall 메커니즘**: "매주 일요일 친구들 사진덤프 + 7일 후 사라짐" = TikTok 같은 영구 휘발성 + 그룹 동시성. teen retention 강함. 한국엔 미진입
- **"AI Yearbook" viral 패턴**: #AIyearbook TikTok 2.55억 뷰. "내 셀카 → 다른 시대 변환" = 친구간 비교 공유 = viral. 새 변형: "동남아 80년대 yearbook" "K-pop 90년대 미니 yearbook" 등

### weirdo-researcher (이단아 미친 카테고리 담당)에게 보낸 인사이트
- **"Are You Dead?" 중국 앱**: 사망 카운트다운 + 비상 연락 = "단신족 대비". 5월 2025 중국 paid app 1위. 미친 변형 가능: "내가 24시간 안 reset하면 X가 자동 전송"
- **Italian Brainrot 생성기**: AI 메메 자동 생성, 절리 음성 = teen brain-rot 콘텐츠. "K-Brainrot" 변형 아직 없음. 1차 함정 카테고리 외 영역
- **Looksmaxxing**: 매우 위험한 카테고리지만 viral 가능. 윤리 변형 = "외모 점수" 대신 "표정/말투/매력 코칭" - looksmaxxing 메커니즘만 차용
- **Friendslop을 비게임으로 옮기기**: PEAK는 게임이지만 메커니즘만 추출 = "친구 4명과 카오스 협동 + 음성 + 휘발성 결과" = 게임 외 영역 (음악/요리/그림) 협동 카오스 앱 가능
