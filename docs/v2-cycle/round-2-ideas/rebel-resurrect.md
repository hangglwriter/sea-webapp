### #17 Last Voice 부활 시도

**attacker 박살 사유 (정확 인용)**:
1. 자살 우려 사용자 1급 위험 - 매주 "마지막" 환기 = 트리거
2. 보이스 클론 동의 = 사후 사용 사기 가능성 (보험금 사기, 가짜 유언)
3. ElevenLabs / OpenAI 보이스 클론 정책 위반 가능 50%
4. 종교 단체 반발 = 한국/필리핀 사용자 90% 이탈
5. #12 Lola Voice와 영역 중복 + 종교 단체 반발 결정적

**부활 변형 시도 (PWA + 18+ + AI 클론 제거 + 단일 시장)**:
- **약화 1 (자살 트리거)**: 매주 "마지막 1분" → "이번 주 가족에게 한 말씀" 라벨 변경. 죽음 환기 제거 + "Are You Alive?" 식 안전 통보 컨셉만 차용

- **약화 3 (App Store)**: PWA 출시로 리젝 회피
- **약화 4 (종교 단체)**: 동남아 불교권 단일 시장 출발 (베트남 + 태국 + 캄보디아). 가톨릭 필리핀 + 이슬람 인니/말레이 v2로 지연

- **합계 (/100): 70**

**정직 이유**:

### #18 Anti-Mom Receipt 부활 시도

**attacker 박살 사유 (정확 인용)**:
1. 청소년 위험 행동 (자해/약물) 부모 차단 = 안전 사고 책임 폭탄

3. iOS Family Sharing 사용자 시스템상 부모 검열 우회 불가
4. #7(Receipt Roll) #19(Envy Receipt)와 영역 중복
5. 보수 정치권 표적 = 한국/인니/필리핀 정부 차단 가능

**부활 변형 시도 (Android 우선 + 친구 한정 + 부모 차단 카피 약화)**:
- **약화 1 (청소년 안전)**: 18+ 강제 + 자해/약물 키워드 차단 + 정신건강 핫라인. 단 위험 행동 정의가 모호 (parties / drinking / 외박 = 위험? 일상?)
- **약화 2 (App Store)**: PWA 출시 + "Anti-Mom" 카피 → "Friend-only Mode" 약화. 단 핵심 마케팅 후크가 카피였는데 약화 시 자가 광고 메커니즘 60% 소실
- **약화 3 (iOS Family Sharing)**: Android 우선 출시 (동남아 Android 점유율 80%+ = 합리). iOS 패스
- **약화 4 (#19와 중복)**: meta-reviewer 도발 인정 - "친구 비교(#19)"와 "가족 반항(#18)" 다른 페인. 영역 분리 가능
- **약화 5 (정부 차단)**: 보수 정치권 표적은 마케팅 후크로 역활용

**점수 재평가**:
- 재미 (/30): **22** - "엄마 모르는 1주" 영수증 자기 인식 강. 매주 영수증 = retention 강. 단 카피 약화로 도파민 -3
- 차별성 (/30): **19** - 부모 차단 정면 카피 약화 시 #19 Envy Receipt와 차별화 모호 (둘 다 영수증 카드). 가족 반항 카테고리 글로벌 0건 강점
- 바이럴 (/20): **15** - 영수증 자체는 7/7 메커니즘 그대로. 단 분노 마케팅 후크 약화로 -2
- 실현성 (/20): **18** - Android PWA + Canvas 영수증 + NGL 익명 카운트 = 1인 빌드 6주

**합계 (/100): 74**

**80점 통과? N**.
**부활 결정: NO-GO**.

**정직 이유**:
- 카피 약화 = 자가 광고 60% 소실 + 차별성 -8
- 부모 차단 자체는 살릴 수 있으나 청소년 안전 책임 폭탄 결정적
- #19 Envy Receipt가 영수증 카테고리 압도 = 영역 흡수 정당

### #20 Dead Drop Balikbayan 부활 시도 (defender 79점 멈춘 후보)

**attacker 박살 사유 (정확 인용)**:
1. App Store "사망 시뮬레이션" 리젝 70%
2. 가족 가짜 트라우마 사고 발생 시 책임 폭탄 (1회라도 사고 = 매각 불가)
3. 자살 우려 사용자 1급 위험 (실제로 안 reset 시도 가능)
4. 종교/문화권 반발 = 인니/필리핀 정부 차단 가능
5. (강점) 어른 분노 4/4 + 메커니즘 6/7 + rebel 가장 미친 후보

**defender 79점 부활 시도 실패 패턴**:
- "사망 영상" → "연락 못 함" 안부 메시지로 약화
- 미친 강도 (rebel.md 후크) 약화 = 차별성 -5
- 79점 = 80점 1점 부족. defender가 정직히 NO-GO 인정

**나의 정반대 시도 (미친 강도 유지 + 책임 폭탄 정직 명시)**:

**핵심 변형: "Last Reset Box" PWA**
- 컨셉 그대로: 매일 reset 안 누르면 24시간 후 가족 8명에게 본인 미리 녹화 영상 + 위시리스트 자동 전송
- "사망 영상" 라벨 유지. **약화 X**. 발리바얀 박스 + Are You Dead? 미친 융합 그대로
- **변형 1 (App Store 우회)**: PWA 단독 출시. iOS Add to Home Screen + Android Chrome PWA. App Store 리젝 70% 회피
- **변형 2 (책임 폭탄 정직 우회)**: 보험 통합 v2 → **v1에서 미리** = 사용자 가입 시 $5/월 = 그 중 $2가 정신건강 보험. 사고 발생 시 책임 분산. 단 보험 통합 BD = 1인 비개발자 어려움 → 인도네시아 Allianz / 필리핀 Sun Life 표준 보험 API 통합 (기존)
- **변형 3 (자살 트리거)**: 18+ 강제 + 자해 키워드 차단 + 정신건강 핫라인 + 친구 신고 + **"7일 연속 reset 안 함 = 가족 전송 전 정신건강 호출 강제"** (사망 영상 발사 전 안전 차단 한 단계)
- **변형 4 (종교 반발)**: 베트남 (불교 + 조상 제사) + 태국 (불교 + 메멘토 모리) 단일 시장 출발. 가톨릭 필리핀 + 이슬람 인니/말레이 v2로 지연
- **변형 5 (정부 차단)**: PWA = 정부 차단도 우회 (앱 스토어 X = 정부가 막을 곳 X). 단 ISP 레벨 차단은 가능 (베트남 정부가 자살 관련 사이트 차단 사례)
- **변형 6 (가족 가짜 트라우마)**: 가족 8명 등록 시 가족 측 18+ 강제 + 가족 안전 통보 시스템 컨셉 명시 + "이건 보험 + 안전 통보 시스템이다" 라벨

**defender 79점에서 1점 채울 수 있는가? 시도**:
- defender 점수: 재미 18 / 차별성 23 / 바이럴 15 / 실현성 23 = 79
- defender 약화 (사망→연락) 시 차별성 -5 손해. 나는 사망 유지 + 보험 통합 = 차별성 +3 (보험 통합은 합법화 우회 후크) + 책임 폭탄 정직 -3 = 차별성 23 유지
- 보험 통합 v1 = 1인 빌드 +4주 = 실현성 23 → 20 (-3)
- 사망 강도 유지 = 미친 강도 +2 = 재미 18 → 20 (+2)
- 바이럴 = OFW 1000만 + 사망 카운트 후크 유지 = 15 → 17 (+2)
- **재계산: 재미 20 / 차별성 23 / 바이럴 17 / 실현성 20 = 80점**

**그러나 정직 추가 검증**:
- 보험 통합 1인 비개발자 BD = 사실 불가능 (Allianz / Sun Life와 1인 계약 무리)
- 7일 연속 reset 안 함 정신건강 호출 = 안전장치이나 카운트다운 강도 약화
- PWA 결제 어려움 (Apple 30% 강제 X = 자유) = 매각 모델 약 (SaaS 매각 X)

**정직 재평가**:
- 보험 통합 BD 불가 = 실현성 +0 → 실현성 17 (보험 빼고 1인 빌드 6주)
- 보험 없이 책임 폭탄 = 차별성 -2 → 21
- **최종: 재미 20 / 차별성 21 / 바이럴 17 / 실현성 17 = 75점**

**80점 통과? N. 75점**.

**부활 결정: NO-GO (정직)**.

**정직 이유**:
- 미친 강도 유지 시 책임 폭탄 1회 = 매각 불가 (attacker 정확)
- 보험 통합 = 1인 비개발자 BD 불가 (자가 인정)
- defender 79점 멈춤 + 나의 75점 = 둘 다 80점 못 넘김
- PWA + 보험 빼고는 "Are You Dead? 동남아 발리바얀 클론" 카테고리에 갇힘
- **defender가 안전 수렴으로 손절 = 정당. 나의 미친 강도 유지도 책임 폭탄으로 박살 = 정당. #20은 컨셉 자체가 진짜로 미친 강도 + 1인 운영 양립 불가능한 후보**

**1차 사이클 함정 #4 "GO with fixes" 회피 = 80점 도장 안 찍음. 약한 논리로 살리지 않음**.
