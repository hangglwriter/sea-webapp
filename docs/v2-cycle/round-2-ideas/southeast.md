## 후보 1: "Balikbayan Live" - 발리바얀 박스 LIVE 가족 큐레이션 + 도착 카운트다운

**카테고리 결합**: sea.md 카테고리 4 (발리바얀 박스) + viral.md 메커니즘 3(친구 한정 상한)/5(일일 알림+압박)/6(페르소나 카드) + newcat.md 패턴 3(공동 양육 책임)

**한 문단 컨셉** (5줄):
필리핀 OFW(해외 노동자 200만+)가 본국 가족에게 보내는 월 40만 상자의 발리바얀 박스. 박스 한 개당 OFW 1명 + 본국 가족 멤버 4-12명을 "박스 서클"로 묶음. 박스 서클 안에서만 "이번 달 박스 위시리스트" 가 매일 갱신됨 - 막내 조카가 Skippy 땅콩버터, 엄마가 Centrum 비타민, 아빠가 Spam 12팩 등을 매일 추가/삭제. OFW는 "이번 박스에 넣었음/못 넣었음" 체크. 박스 발송 후 LBC/Forex Cargo 트래킹 번호 입력 → 도착 D-day 카운트다운이 가족 모두 위젯에 표시. 도착 당일 가족이 박스 여는 영상/사진 자동 OFW에게 푸시. 매월 박스가 도착할 때마다 "발리바얀 영수증 카드"가 생성 (이번 박스 무게 32kg / 총 47개 아이템 / 가장 빨리 사라진 아이템: 엄마 Centrum / OFW가 보낸 사랑의 노트). 이 카드를 본인 SNS/메신저에 공유 가능.

**왜 새로운가** (3줄):
1. LBC/Forex Cargo는 단순 트래킹만, WhatsApp/Messenger는 산발적 텍스트. **"가족 위시리스트 + 박스 카운트다운 + 도착 영상 + 영수증 카드"** 통합 0건.
2. 한국에 동일 카테고리 없음 (한국은 명절 택배가 가족 향수 차원으로 안 작동). K-prefix 변형 불가능. 출처: en.wikipedia.org/wiki/Balikbayan_box, sbs.com.au/voices/.../balikbayan-box.
3. OFW는 평소 죄책감("못 가서 미안") 있음 → 박스를 가족과 LIVE로 같이 채우는 행위 자체가 죄책감 완화 = 정서 페인을 정면으로 푸는 신생 카테고리.

**왜 동남아 통하는가** (3줄):
1. 필리핀 OFW 200만+ + 본국 가족 800만 = 명확한 1000만+ 인구. 연 480만 박스 = 십억 달러 산업 (en.wikipedia.org/wiki/Balikbayan_box). 결제 가능 인구 명확 (OFW가 외화 수입 있음, 가족이 의존).
2. 인도네시아 TKI/태국 외국노동자/베트남 해외 노동자도 동일 패턴 - 사우디·말레이시아·홍콩에서 본국 가족에게 정기 배송. 변형 가능 (인니 TKI 박스, 베트남 hàng quà 박스).
3. 동남아 family-first 문화 + 효도 정서 + 거리감 페인 = 미국/유럽에 없는 디아스포라 정서 토양. WhatsApp가 동남아 메신저 1위라 박스 도착 사진/영상 흐름 자연스러움.
