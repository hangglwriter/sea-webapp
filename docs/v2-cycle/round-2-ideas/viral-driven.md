### 후보 1: "Barkada Pact" - 학교/직장 단위 친구 5명 깨면 모두에게 알림 가는 매일 약속 앱

**핵심 바이럴 메커니즘**: viral.md 메커니즘 1(원자 네트워크 침투), 3(친구 한정 + 5명 상한), 5(일일 알림 + 시간 압박), 2(자랑 그리드), 7(솔로 매각 패턴) 결합

**한 문단 컨셉** (5줄):
필리핀어 "barkada"(5명 단짝 그룹) 개념을 그대로 코드화. 가입 시 친구 4명을 초대해야 본인 계정 활성화 (Lapse 메커니즘) → 5명이 한 "Pact"가 됨. 매일 오전 7시 그룹이 함께 약속한 작은 미션 1개를 함(예: "7시 30분에 셀카 한 장 보내기", "오늘 30분 걷기 인증", "엄마한테 전화 한 통"). 한 명이 24시간 안 안 하면 → 나머지 4명에게 자동 알림 "Ana가 오늘 약속을 깼습니다" + Pact 점수 -1. 30일 안 깨면 "Diamond Pact" 배지 + 자랑 그리드 자동 생성. 깨면 영구 기록 = 친구가 평생 본다.

**원자 네트워크 단위** (어느 학교/팬덤/도시 한 곳에서 시작?):
필리핀 메트로 마닐라 "Ateneo de Manila University" 또는 "De La Salle University" 단일 캠퍼스 1곳에서 시작. 학교 안 친구 5명 단위가 이미 barkada 문화로 굳어진 곳 = Saturn/TBH/Gas와 동일한 atomic network 조건. 백투스쿨 시즌(6월) 침투. 24~48시간 안 40% 침투 목표. 침투 후 옆 캠퍼스(UP Diliman)로 도미노. sea.md 인용: 필리핀 Gen Z 47%가 "심심해서 데이팅 앱 한다" → barkada 부재가 진짜 페인. weirdo.md 인용: 필리핀 230만 OFW 자녀 외로움 + 가장 연결됨 + 가장 외로움(seasia.co).

**친구 한정 상한** (몇 명? 왜 그 숫자?):
**정확히 5명**. 이유 3가지:
- 필리핀 barkada 문화 표준 인원 = 5명 (sea-researcher 인터뷰 데이터 + 필리핀 학술 자료)
- Lapse "친구 5명 초대 강제" 출시 1개월 App Store 1위 패턴
- Dunbar's number 핵심 친밀 그룹(5명) = 인지심리적 한계
6번째 친구는 "Waitlist Pact"로 별도 분리(Bondee 50명보다 훨씬 빡빡한 한정 → 희소성 극대화). 5명이 한 명 빠지면 즉시 "Pact 위기" 알림 → 친구 관계 협상 강제.

**자랑 그리드 포맷** (이모지/색칸/숫자 결과? 어떻게 SNS 새어나가는가?):
30일 격자 + 각 칸 5개 점(친구 5명). 점 색깔 = 약속 지킴(녹색)/깸(빨강)/Pact 깬 본인은 검정. Wordle 식 이모지 변환 가능:
```
Barkada Pact Day 27 🤝
🟢🟢🟢🟢🟢
🟢🟢🟢🔴🟢
🟢🟢🟢🟢🟢
...
Pact Score: 132/135
```
이 텍스트는 카톡/Messenger/X 모든 메신저 위화감 X 붙여넣기. 색만 보고도 "오늘 친구 한 명 망함" 신호 전달. 본 사람은 "어 저게 뭐지?" → 가입 시도. **친구 4명 초대 강제 = 가입 1명마다 4명 끌어옴**.

**작동하는 7개 메커니즘 체크**:
- M1 원자 네트워크: O — 필리핀 단일 캠퍼스부터 침투, barkada 5명 = 학교 안 dense network
- M2 자랑 그리드: O — 30일 격자 색칠 이모지, 카톡 호환
- M3 친구 한정: O — 5명 상한, Lapse + Locket 패턴
- M4 익명 미스터리: X — 친구는 서로 다 안다
- M5 일일 알림 + 압박: O — 매일 오전 7시 + 깨면 친구 4명에게 즉시 알림
- M6 페르소나 카드: X — 카드 형식 X, 그리드만 (의도적)
- M7 솔로 매각 패턴: O — Saturn Dylan Diamond / Locket Matt Moss = 본인 학교/연인 위해 만듦. 민티 본업과 무관해도 "필리핀 friend group 외로움 = 진짜 페인" 출발점 확보
- **작동: 5/7**

**폭락 패턴 회피** (BeReal/NGL/Tea 처럼 폭락하지 않으려면):
- BeReal 폭락 원인 = "단일 메커니즘 의존". → Barkada Pact는 매일 알림(M5) + 친구 한정(M3) + 자랑 그리드(M2) 3중 메커니즘 동시 작동. 한 축 식어도 다른 축이 받침.
- NGL 폭락 원인 = "가짜 봇 메시지로 양 늘림 → FTC 제재". → Barkada Pact는 친구 5명 실명 + 학교 인증 = 봇 0%. FTC 리스크 X.
- Tea 폭락 원인 = "데이터 유출 + 익명 리뷰 라벨링". → Pact는 약속 텍스트만 30일 저장 후 자동 삭제. 개인정보 최소 (이름 + 학교 + 셀카 1장 24시간).
- BeReal 알림 강박 피로 회피: 매일 같은 시각(오전 7시) = 예측 가능. BeReal 랜덤 시각은 강박을 키움. 우리는 예측 가능한 일상 리듬으로.

**1차 함정 자가 검토**: 운세/사주/MBTI/타로/심리테스트/명리/관상 0점 ✓. K-prefix 0점 ✓. "민티 운영 매칭" 트리거 0점 ✓ (필리핀 barkada 출발점 = 자기 매칭 트리거 회피).

**구현 난이도**:
- 백엔드: Firebase Auth(학교 이메일 인증) + Firestore(Pact 5명 + 30일 격자) + FCM 푸시
- 프론트: 모바일 웹 PWA 또는 단순 Expo 앱
- 결제: 첫 6개월 무료, 이후 "Premium Pact" $1.99/월(Pact 2개 동시 운영, 그리드 추가 색)
- 1인 비개발자: vibe coding 가능. 단 학교 이메일 인증 부분만 까다로움(필리핀 .edu.ph 도메인 화이트리스트)
- MVP 2주 (Lovable + Firebase)

### 후보 2: "Receipt Roll" - 매일 친구 5명에게 가는 영수증 카드, 한 달 후 한 장으로 합쳐짐

**핵심 바이럴 메커니즘**: viral.md 메커니즘 6(페르소나 카드), 3(친구 한정 5명), 1(원자 네트워크), 2(자랑 그리드), 7(솔로 매각 패턴) 결합. **Receiptify + Locket Rollcall + Cal AI의 카드 미학을 직접 결합**.

**한 문단 컨셉** (5줄):
매일 한 줄 자기 활동을 텍스트로 입력("오늘 새벽 5시 일어남", "메콩 강 옆 산책", "엄마 전화 30분"). AI가 즉시 영수증 스타일 카드로 변환(Receiptify 미학). 친구 5명에게 카드 자동 전송(Locket 위젯처럼 홈스크린에 떠오름). 한 달이 끝나면 30장 영수증이 **세로 영수증 한 장**(약 1m 길이)으로 자동 합쳐짐 = "11월의 나" 영수증. 친구 그룹은 서로의 한 달치 영수증을 비교 가능. Spotify Wrapped를 매월로 짧게 + 친구 한정으로 잘게.

**원자 네트워크 단위** (어느 학교/팬덤/도시 한 곳에서 시작?):
방콕 줄라롱콘 대학교 또는 마힌돌 대학교 1곳 → 태국 도시 직장인층 확장. 이유: sea.md "Songkran/Loy Krathong 매년 단발 바이럴 슬롯" + 태국 도시 거주민이 "줄서기 1-3시간"이 일상이라 페인포인트 명확 + 태국 인스타 사용률 동남아 1위. 단일 캠퍼스 → 사회 진출한 졸업생 → 직장 동료로 자동 전파(Saturn 백투스쿨 → 직장 도미노 패턴).

**친구 한정 상한** (몇 명? 왜 그 숫자?):
**5명**. 이유:
- Locket 20명도 많다는 피드백 있음(친한 친구 = 5명 가설이 viral.md 메커니즘 3 핵심)
- 영수증을 5명에게만 보내면 = "내 영수증 받는 사람 = 진짜 친구" 사회적 신호 강화
- 6번째 친구는 "Premium $2.99/월"로 추가 가능(수익화)
- Pengu/Locket "친구 1명만 끌어와도 둘 다 잠금" 패턴 = 2x viral loop. 5명은 5x.

**자랑 그리드 포맷** (이모지/색칸/숫자 결과? 어떻게 SNS 새어나가는가?):
영수증 카드 자체가 페르소나 카드(M6). 추가로 텍스트 자랑 그리드:
```
🧾 Receipt Roll Day 23
☕ 5x morning walks
📚 12 chapters read
📞 8 family calls
💸 spent: ₿820
🏆 best streak: 14 days
Send your receipt → receiptroll.com
```
영수증 자체는 인스타 스토리 캡처용(세로 비율 9:16 정렬, 컬러). 텍스트 그리드는 메신저용. **이중 트랙 = 인스타 스토리(시각) + 카톡(텍스트) 동시 침투**. Cal AI가 "stealth promo"(자연스러운 일상 영상 중간 카드 시연)로 성공한 패턴 그대로.

**작동하는 7개 메커니즘 체크**:
- M1 원자 네트워크: O — 방콕 대학 1개부터 시작, dense student network
- M2 자랑 그리드: O — 텍스트 영수증 요약 + 시각 영수증 카드 = 이중 포맷
- M3 친구 한정: O — 5명 상한, Premium 확장 가능
- M4 익명 미스터리: X — 친구 실명
- M5 일일 알림 + 압박: △ — 매일 입력 권장이나 강제는 아님(BeReal 폭락 회피)
- M6 페르소나 카드: O — Receiptify + Cal AI 직접 차용, 매일 새 카드 + 월말 합쳐진 1m 영수증 = 수집 욕구 발동
- M7 솔로 매각 패턴: O — Michelle Liu Receiptify 1인 + 솔로 개발 검증
- **작동: 5/7** (M5는 강제 X로 의도적 약화 = 폭락 회피)

**폭락 패턴 회피** (BeReal/NGL/Tea 처럼 폭락하지 않으려면):
- BeReal 폭락 = 매일 알림 강박 → Receipt Roll은 "안 적는 날 = 빈 영수증 칸" 시각화. 강제 X. 안 적어도 친구 카드는 계속 옴(외부 자극 유지).

- 데이터 유출 회피 = 영수증은 텍스트만 저장(이미지 합성은 클라이언트 사이드). 친구 5명만 접근. 30일 후 자동 텍스트 삭제 옵션.

**1차 함정 자가 검토**: 운세/사주/MBTI/타로/심리테스트 0점 ✓. K-prefix 0점 ✓. "1인 운영 매칭" 트리거 0점 ✓.

### 후보 3: "Quiet Quitting Grid" - 직장에서 "오늘 얼마나 적게 일했는지" 자랑하는 일일 카드 (사내 5명 그룹)
