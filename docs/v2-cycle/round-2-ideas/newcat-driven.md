**한 문단 컨셉** (5줄):
Pengu는 2명 공동 펭귄. 우리는 4-8명 공동 캐릭터 = 동남아 신화 변형. 필리핀 = tikbalang (말 머리 정령) 새끼 / 인도네시아 = wayang 그림자 인형 / 베트남 = cá hêu (전설 물고기) / 태국 = nāga (용 새끼). 동남아 4-8명 친구 그룹 (barkada/geng/glăm)이 공동으로 새끼 키움 - 24시간마다 한 명이 먹이 / 목욕 / 놀이 중 하나 해야 함, 안 하면 캐릭터 시들음. 친구 전체가 매일 위젯에 캐릭터 상태 확인.
