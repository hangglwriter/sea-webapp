## 평가 근거 (5개 항목)

### 1. "카톡으로 매번 하던 짓 정식 시스템화" = 진짜 페인 = 진짜 재미 (+)

지수 페르소나 9.5/10 핵심 인용: **"친구 6명에게 '이 남자 사귈까?' 강제 판결 = 카톡으로 매번 했던 거 정식 시스템화"**.

이게 가장 중요한 시그널이다. 재미의 본질은 "원래 하던 짓을 더 쉽게/더 자랑스럽게 만든 것". Wordle도 십자말풀이를 5분으로 압축. Locket도 카톡 프로필 사진을 위젯으로 강제. Barkada Verdict는 "친구 단톡에 '나 이 남자 사귈까?' 던져놓고 답 기다리는 행위"를 24시간 카운트다운 + 이모지 그리드 + 다수결로 게임화.

이미 발생하는 행동을 게임화 = retention 강. 새 습관 만들 필요 X.

### 2. "결과 이모지 그리드 인스타 스토리 박기" = M2 도파민 직격 (+)

녹/빨/노 5칸 색칠된 그리드 = NYT Connections 33억회 (2024) + Wordle 53억회 (2024) 검증 포맷. **"GO 4 / NO 1 / WAIT 0"** 이런 그리드만 인스타 스토리에 올라가면:

- 본 친구: "어 뭐야 무슨 결정?" → DM 폭주
- 본인: 결정 내용 비공개 = 미스터리 자랑 = NGL 패턴
- 결과 자체가 광고

스포일 없는 자랑 그리드 (viral.md M2) 정확히 작동. 캡처 가능한 시각 자산 = 도파민 분명.

### 3. 24시간 카운트다운 + 다수결 결과 보기 = 매일 들어가는 메커닉 (+)

투표 던진 사람 입장: 24시간 동안 친구 6명이 어떻게 판결할지 = **계속 앱 열고 확인**. 결과 알림 = 즉시 확인. 본 사람 입장 (친구 판결 참여자): 본인도 다른 친구 카드 5-10개 매주 받음 = 매일 들어와서 판결.

평균 사용 패턴 추정:
- 본인 결정 카드 = 월 2-4회
- 친구 결정 카드 판결 = 주 3-7회
- 결과 그리드 다시 보기 = 매일 1회

매일 들어가는 메커닉 16-20점 범위 충족. **단 BeReal 폭락 패턴 의심**: 매일 강제 알림 (남의 카드 판결 요구)이 1-2개월 후 피로 누적 가능 (아래 위험 시그널 참조).

### 4. 강제성 + 30일 페널티 = "친구에게 진짜 답 들음" 카타르시스 (+)

가짜 "친구야 어떻게 생각해?" → 친구들이 진짜 답 안 함 (한국/필리핀 친구 문화 = 부드러운 답 위주).

Barkada Verdict 강제 메커닉:
- 24시간 안 답 안 하면 페널티
- 익명 (친구 누가 GO/NO 했는지 본인 못 봄) = 진짜 답 가능
- 거부 시 30일 박탈

**Linh, 지수, Ana 모두 "친구가 직접 말하기 어려운 진심을 익명으로 던짐" 라인에 강하게 반응**. 카타르시스 정서 = 재미 핵심.

### 5. 1인 결정 게이미피케이션 = 동남아 barkada 문화 디지털화 = 직격 (+/-)

필리핀 barkada (4-8명 끈끈한 친구 그룹) + 한국 친구 단톡 + 베트남 bạn thân + 인니 geng = **공통 메커닉**. Ana 페르소나가 "barkada = 우리 단어" 라며 친근감 표현. 단어 자체가 viral 후크.

## 위험 시그널

### 1주일 안 이탈 이유

1. **친구 5-7명 카드 매주 판결 의무** = 첫 주 신선했다가 둘째 주부터 "또 판결?" 피로. NGL 첫 1-2주 폭발 후 시들 패턴 답습 위험.
2. **본인이 결정 카드 던지면 친구가 무성의한 GO/NO 던질 경우** = "친구가 내 인생을 5초로 결정?" 분노 = 즉시 탈퇴. (페르소나 시뮬레이션에서 발견 안 됐지만 실제 risk.)
3. **30일 페널티 두려워서 가입 망설임** (Anh 페르소나 7.0 명시) = 첫 가입 게이트가 가입 안 함 사용자도 발생.
4. **첫 결정 카드 던졌는데 친구 4-8명 중 2-3명만 답** = 다수결 미성립 = 시스템 실패 = 즉시 이탈. Cold start 문제.

### BeReal 폭락 패턴 의심

**위험도: 중-상**.

BeReal 폭락 핵심 원인 (2024 보고서 인용):
- 매일 강제 알림 + 단일 메커니즘 (사진 1장)
- 친구 사진 보러 들어가는 의무 피로
- 결과 자랑 메커니즘 없음 (M2 자랑 그리드 X)

Barkada Verdict는:
- 매일 강제 알림 (친구 카드 판결 요구) **= BeReal와 동일 위험**
- 의무 피로 동일 (남의 카드 판결)
- **M2 자랑 그리드 있음 = BeReal보다 +** (그리드 인스타 스토리 자체 광고 = 신규 유입 지속)
- 다수결 + 24시간 카운트다운 = 게임성 + (BeReal 단순 사진 X)

**결론**: BeReal 폭락 패턴 50% 답습 가능. 단 자랑 그리드 + 게임성으로 회피 가능성 50%. defender의 "4-8명 분산" 반론은 약함 (그래도 매일 1-3개 카드 판결 의무 발생).

3개월 후 retention 검증 필수. 12개월 후 BeReal 60% 폭락 패턴 답습 시 매각 모델 약화.
