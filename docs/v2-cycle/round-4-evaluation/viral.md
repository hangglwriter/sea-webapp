## 원자 네트워크 단위 시나리오

### 필리핀 대학 1곳 (Ateneo/DLSU/UP) 40% 침투 가능?

**가능성: 30% (3 중 1 정도)**

가능 시나리오:
- DLSU 한 학과 (학부생 ~3,000명) 침투 = barkada 4-8명 단위 100개 그룹 = 600~800명
- 학과 100개 barkada 중 30개가 가입하면 학과 내 24% 침투 = 50개면 40%
- TikTok PH 학생 침투 80%+ = 토양 충분
- 필리핀 49% 청소년 이미 cyberbullying 경험 = barkada 내 private group chat 활성 (cyberbullying.org/dlsu 검증)

불가능 시나리오:
- 카드 생성 빈도: 1개 barkada에서 매주 카드 1개 안 나옴 → atomic 폭발 트리거 부족
- 자랑 그리드 자랑 강도 약 = "친구 결정 떠넘김" 자조 톤 = Wordle처럼 매일 도배 안 됨
- Saturn처럼 매일 시간표 보러 들어가는 사용성 X. Gas처럼 매시간 폴 갱신 X

### Saturn / TBH / Gas 비교

| 항목 | Saturn | TBH/Gas | Barkada Verdict |
|------|--------|---------|-----------------|
| Atomic 단위 | 학교 (1,000~5,000명) | 학교+친구 폴 (4-8명) | barkada (4-8명) |
| 일일 사용 | 매일 시간표 (필수) | 매시간 폴 갱신 | 1주 1-2회 |
| 자랑 강도 | 중 (시간표 공유) | 강 (칭찬 받음 = 인기) | 약 (결정 떠넘김 자조) |
| 학교 40% 침투 | O 검증 (30~90%) | O 검증 (40% 24h) | 가설 (검증 0건) |
| 폭락 패턴 회피 | 매일 필수 사용 | Discord 매각 후 종료 | BeReal 답습 위험 |

**결론**: Saturn/Gas 패턴과 비교 가능하나 **일일 사용 빈도 + 자랑 강도 두 축에서 약함**. atomic 자체 단위 크기는 적합하나 atomic 안의 viral loop 강도가 부족. 학교 40% 침투는 가능성 30% (Saturn 80% 이상 / Gas 40% 이상보다 약함).

## 자랑 그리드 자체 광고 작동?

**작동 여부: △ (부분 작동, 자랑 강도 약)**

작동 측면:
- Wordle 식 이모지 그리드 (녹/빨/노 5칸) = 카톡/IG 스토리에 박힘 = 본 사람 호기심 폭발 ("뭐지? 무슨 결정?")
- 호기심 → 본인 가입 → 자기도 결정 카드 올림 = viral loop 가능
- 카드 내용 익명 = 스포일 X = spoiler-free brag grid (Wordle 정확 패턴)

작동 약화 측면:
- 자랑 강도: Wordle = "3/6 맞췄음 (스마트함 자랑)". Barkada Verdict = "친구 6명이 내 결정 NO 4 / GO 2 (자조)". 본인이 자랑하고 싶은 강도 약함
- 그리드 박는 빈도: Wordle 매일 1회 = SNS 도배. Barkada Verdict = 인생 큰 결정 = 월 1-2회 정도 = SNS 침투 빈도 낮음
- 본인이 그리드 박는 동기: 비통한 결과 (NO 다수) = 박지 않을 가능성. 자랑할 만한 결과 (GO 만장일치) = 박는다 = 사용자 일부만 그리드 박음

자가증식 강도: **약~중**. 학교 단위 40% 침투 24h라는 Bier 플레이북 폭발 패턴 도달 어려움.
