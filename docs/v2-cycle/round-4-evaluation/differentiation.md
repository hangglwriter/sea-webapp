## 카테고리 자체 신생?

**아니다**. "friends-vote-on-my-life" 카테고리 자체는 **2013년 Seesaw / Loop 시작 → 2019 Lokmat ("Vote on your life") → 2025 The Game of Voting** 까지 12년+ 카테고리. Barkada Verdict가 카테고리 진입자가 아니라 카테고리 **변형자**.

**신생 메커니즘은 결합 부분만**:
1. 4-8명 강제 인원 한도 (글로벌 친구 폴은 무제한 또는 다수)
2. 24시간 강제 카운트다운 (Tiinkk는 5분-30일 사용자 선택, Lokmat은 즉시)
3. 거부 시 30일 페널티 (다른 앱 0건 발견)
4. 이모지 그리드 SNS 자랑 (Wordle 형식 이식)

→ 결합은 신생 / 본체는 12년 묵음.

## 캔바+ChatGPT 5분 컷 검증

**부분 가능 / 부분 불가**.

### 캔바 + ChatGPT + 노션/구글폼/카카오톡으로 가능한 것:
- ChatGPT에 "내 인생 결정을 친구 5명에게 카톡 단톡으로 보낼 카드 작성" = 1분
- 구글폼에 "GO / NO / WAIT" 3개 옵션 만들기 + 친구 5명에게 단톡으로 링크 보내기 = 3분
- 캔바에 이모지 그리드 결과 카드 합성 = 5분
- 카카오톡 단톡방 다중 투표 기능 = 30초 (기본 기능)

→ **단순 친구 다수결 + 결과 카드 = 캔바+ChatGPT+노션 10분 컷 가능**.

### 캔바+ChatGPT로 절대 불가:
- 4-8명 정확한 인원 강제 (노션/카톡은 인원 제한 X)
- 24시간 카운트다운 + 자동 마감 (구글폼은 시간 제한 X)
- **거부 시 30일 페널티 시스템 + 다른 사람 판결 참여 차단** (이게 진짜 차별화)
- 이모지 그리드 자동 생성 (캔바는 수동, 자동 X)
- 친구 신뢰 그래프 누적 (Bondee/Locket 식 친구 한정)

→ **30일 페널티 + 자동 이모지 그리드 = 캔바 절대 X**

**정직 평가**: 차별화 후크 50%는 캔바+ChatGPT 10분 컷, 50%는 진짜 차별화. 절반만 차별화 강 = 차별성 점수 -2.

## NGL/Locket/BeReal 변형?

- **NGL** (익명 메시지) → Barkada Verdict 익명 판결과 메커니즘 일부 겹침. 단 NGL = 1대1 익명 / Barkada Verdict = 4-8명 한정 익명 다수결. **NGL 변형 아님**.
- **Locket** (친구 20명 한정 사진 위젯) → Barkada Verdict 4-8명 한정 친구 그룹 = **인원 상한 메커니즘 직접 차용**. Locket 변형 부분 인정 (글로벌 클론 위험).
- **BeReal** (매일 강제 알림 2분 마감) → Barkada Verdict 24시간 카운트다운 = **시간 압박 메커니즘 직접 차용**. BeReal 변형 부분 인정.
- **Wordle / NYT Connections** (이모지 그리드 33억회 검증) → Barkada Verdict 이모지 그리드 = **직접 차용**.
- 출처: https://en.wikipedia.org/wiki/NGL_(app)
- 출처: https://techcrunch.com/2025/11/03/lockets-social-app-is-picking-up-steam-with-gen-alpha/

**의미**: Barkada Verdict = 글로벌 viral 4개 앱(Locket+BeReal+NGL+Wordle) 메커니즘 결합. **카테고리 신생 X, 메커니즘 결합 신생**. 정확히 viral.md M1+M2+M3+M4+M5 메커니즘 5개 동시 작동 검증.

→ Locket/BeReal/Wordle 변형 인정 + 차별화 후크 50%만 진짜 신생 = 차별성 -1.
