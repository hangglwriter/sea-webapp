## 1. Linh 페르소나 시뮬레이션 (베트남 22세, K-드라마 팬)

### 시나리오: 인스타 스토리 매일 1장 운세 카드 워크플로

**1단계: 인지 - 어떻게 도달하나?**
- PRD 9장 "동남아 인플루언서 협업"이 후크인데 v1은 한국어만이라 베트남 인플루언서가 자기 팬덤에 공유할 이유가 없음. 자기가 한국어 UI 캡처해서 올려도 팔로워는 "이거 뭐임" 반응 우려
- Saju World가 베트남어로 진출했다는 게 IDEA.md 핵심 근거인데, 그건 베트남어 UI였기 때문임. 한국어 UI인 우리 v1을 Linh가 발견할 자연 경로 부족

**2단계: 첫 사용 - 입력 페이지**
- "이름과 생일만 알려주세요" 한국어로 적혀 있음. Linh는 한국어 학습 중이지만 22세 K-팝 팬 평균 한국어 능력으로는 "생년월일", "생시", "자시" 같은 단어 모름
- 이름 입력에 "Linh"라고 영어로 쳐야 하는지, 한글로 "린"으로 쳐야 하는지 안내 없음. AI 프롬프트는 받은 이름을 그대로 컨텍스트에 넣지만, 카드 출력 영역(card-template.svg 110번 줄)에는 "민티님의 하루"처럼 한글 "님"이 강제됨. "Linh님의 하루"가 어색할 수 있음
- 생시 선택 "자시" 기본값을 베트남인이 이해할 수 없음

**3단계: 결과 카드**
- 운세 한 줄 "오늘은 작은 시작이 큰 변화를 만듭니다" - Linh는 무슨 뜻인지 추측만 가능. K-드라마 자막으로 익숙한 단어가 아님
- 행운 컬러 + 숫자 + 키워드는 시각 위주라 OK (PRD 차별점 #2 "K-감성"이 여기서 작동)
- 워터마크 "오늘의 K-운세 / kfortune.pages.dev" - 한국어임. Linh 팬덤 입장에서는 "어디서 뭐 받는 건지" 인지 어려움

**4단계: 인스타 공유 후 바이럴 루프**
- Linh가 자기 스토리에 올림 → 팔로워들이 보고 "이거 어디서 받았어?" 묻는 게 PRD 13장 성공 지표
- 그런데 워터마크가 한국어라서 베트남어권 팬들이 URL 인지 → 방문 → 한국어 UI에 또 막힘. **바이럴 루프가 첫 단계에서 차단됨**

**5단계: 재방문**
- 한국어 운세를 추측만 가능한 상태에서 매일 재방문할 동기 없음. "예쁜 카드" 매력 외에 콘텐츠 의미 가치 0

### Linh 시뮬레이션 결론

**v1은 Linh에게 작동하지 않는다.** PRD 페르소나 1로 Linh를 잡았지만 MVP 스코프(한국어 only)와 모순됨. PRD 12장 "한국어 UI 동남아 진입 마찰" 위험을 "중" 으로 평가했는데, 실제로는 "높음"이고 v1 출시 전에 정직하게 정정해야 함. v2 i18n 약속은 동남아 검증 없이 가설 단계.

## 2. 지수 페르소나 시뮬레이션 (서울 28세, 디자이너)

### 시나리오: 매일 출근길 사주 앱 대체 → 인스타 스토리 콘텐츠

**1단계: 인지**
- 지수는 Saju World 유료 결제자. PRD 페르소나 정의는 "텍스트 길어서 캡처용으로 부적합" "디자인 촌스러움"이 페인포인트라고 함. 합리적
- 행글라이터 채널 시청자라면 도달은 가능

**2단계: 첫 사용 - 입력**
- 한국어 모국어니 입력 마찰 없음. 30초 안에 결과 도달 ✓ (이 부분은 진짜 작동)

**3단계: 첫 결과 카드**
- card-template.svg 시안 보면 "민티님의 하루 / 2026년 5월 16일 / 오늘은 작은 시작이 큰 변화를 만듭니다 / 더스티 핑크 + 세이지 그린 + 머스타드 옐로우 / 7 / 용기"
- 디자이너 눈에 카드 디자인 자체는 평균 이상. 파스텔 톤, 손글씨 폰트, 일러스트 배치 깔끔. PRD 차별점 #2 작동
- **다만**: Saju World의 일주/월주/년주 기반 정통 사주 vs 우리는 Plan B로 띠+별자리만 사용. 지수가 "이거 그냥 별자리 운세잖아?"라고 느낄 수 있음. 정통파 사주 결제자가 무료 별자리 운세로 이동할 동기 약함

**4단계: 7일째 재방문**
- localStorage 7일 그리드는 "지난 7일 봤다" 시각화일 뿐, 매일 돌아올 이유 안 됨
- fortunePool.js 운세 25개 + 컬러 20개 + 키워드 30개 + 숫자 9개. 시드 조합으로 매일 다른 결과 나오긴 하지만, 같은 사용자가 한 달 쓰면 운세 한 줄이 4번 정도 반복됨 (25개 풀에서 30일이니까 5/6 확률로 중복 발생)
- 지수는 디자이너 = 패턴 인식 빠름. 3주 안에 "어 이거 본 적 있는 운세 같은데?" 감지 가능

**5단계: Saju World 결제자가 이동할 동기?**
- 사주 정확도: 떨어짐 (Plan B). Saju World가 우위
- 디자인: 우리가 우위. 카드 한 장 캡처 동기는 충족
- 가격: 우리 무료. Saju World 유료. 가격 우위
- **이동 vs 병행?**: Saju World 그대로 두고 우리는 캡처용으로만 병행할 가능성. 즉 지수의 "주력 사주 앱"이 되진 못함

### 지수 시뮬레이션 결론

**부분적으로 작동.** 인스타 캡처용 보조 도구로는 가치 있음. 단 PRD가 명시한 "Saju World 대체"는 과한 기대. 재방문률 5% 목표(PRD 13장)는 운세 풀 25개로는 4주차에 패턴 노출되면서 떨어질 가능성.

## 3. 5개 영역 비판

### 3.1 차별성 - 캔바 + ChatGPT로 같은 결과 만들 수 있나?

**솔직한 답: 거의 같이 만들 수 있다.**

- 캔바: 운세 카드 템플릿 검색 → 한국어 손글씨 폰트 + 파스텔 배경 + 컬러 칩 배치한 템플릿 이미 존재
- ChatGPT/Claude 앱: "내 사주 보고 오늘 운세 한 줄 + 행운 컬러 3개 + 숫자 + 키워드 JSON으로 줘" 30초
- 캔바 템플릿에 값만 갈아끼우면 동일한 카드 5분 안에 완성

**우리의 진짜 후크**: "30초 안에" + "별도 작업 0" 가 유일한 차별점. 캔바+ChatGPT는 5분 + 손작업이 필요하니까. **그런데 이 후크는 "사용자가 매일 5분을 아끼려고 우리 사이트에 들어올 만큼 절박한가?"에 답이 약함.**

PRD 12장이 "캔바와의 차별성 부족" 위험을 "중"으로 평가했는데, 실제는 "높음". 완화 전략 "30초 자동 + AI 윤문 + 사주 컨텍스트"가 약한 이유:
- "30초 자동" = 캔바 템플릿도 거의 같은 시간
- "AI 윤문" = ChatGPT 무료 플랜으로도 됨
- "사주 컨텍스트" = Plan B(띠/별자리)면 사주가 아니라 그냥 별자리 운세

### 3.2 재방문 동기 - localStorage 7일 그리드만으로 매일 돌아올까?

**솔직한 답: 안 돌아온다.**

- 운세 앱 카테고리의 재방문 트리거 = "어제 내가 뭘 봤지?" 호기심 + "오늘은 어떨까?" 확인 욕구
- localStorage 7일 그리드는 후자만 약하게 충족. **푸시 알림 0, 이메일 0, SMS 0**이라 사용자가 능동적으로 URL 입력해야 함
- Saju World가 유료 모델로 돌아가는 이유는 푸시 + 매일 다른 카테고리(연애/금전/건강) + 월별 종합 등 컨텐츠 깊이가 있어서임. 우리는 한 줄 + 컬러 + 숫자 + 키워드. **컨텐츠 빈약함이 7일 안에 노출됨**

**제안**: PWA로 만들어서 홈 화면 추가 + 일일 푸시 알림 가능하게 하거나, 카카오톡 채널 연동(국내) / Telegram bot(동남아)으로 푸시 푸쉬 채널 만들기. 안 그러면 "주 1-2회 들어옴" 이 현실적

### 3.3 바이럴 가능성 - 인스타 공유 카드가 진짜 공유될 수준?

**솔직한 답: 카드 디자인 자체는 공유 가능 수준 + URL 유입은 약함.**

긍정:
- card-template.svg 디자인 시안 보면 인스타 스토리에 올려도 안 부끄러운 수준. K-인스타 미감 ✓
- 9:16 비율, 한국 손글씨 폰트, 파스텔 톤 = MZ 인스타에서 자주 보이는 톤

부정:
- 워터마크 위치(1830-1862 y좌표, 22-18px 글씨)가 너무 작고 하단에 묻힘. 스토리에서 캡션 가리면 안 보임
- URL이 "kfortune.pages.dev" - 외우기 어려움. 도메인 짧고 외우기 쉬운 거 필요 (예: koru.fun, kday.app 등)
- 인스타 스토리는 16-24시간 안에 사라짐. 영구 컨텐츠가 아니라 "올렸다가 잊혀짐" 채널. 진짜 바이럴은 릴스/틱톡인데 우리는 정적 이미지

**제안**: 카드 영상화(3초 페이드인) 또는 GIF로 export 옵션 추가하면 릴스 업로드 가능. 정적 PNG만으로는 바이럴 폭발력 약함

### 3.4 신뢰 - 매일 다른 결과 + 5번 쓰면 패턴 들킬까?

**Plan B(fortunePool.js) 정량 분석**:

fortunePool.js 코드 분석:
```
seed % 25 (운세 한 줄)
(seed >> 3) % 20 (컬러 조합)
seed % 9 + 1 (숫자, 1-9)
(seed >> 5) % 30 (키워드)
```

- 같은 사용자(같은 이름+생일), 매일 시드는 날짜로 변하므로 매일 다른 결과 ✓
- 그러나 운세 풀 25개 → 한 달(30일) 사용 시 5번 정도 운세 한 줄 반복 발생 가능성 높음
- 더 큰 문제: 모든 사용자가 **같은 풀에서 뽑음**. Linh와 지수가 같은 날 같은 운세 받는 사건 발생 가능 (이름이 시드에 어떻게 반영되냐에 따라). main.js를 못 봤으니 정확한 시드 함수는 모르지만, 친구들끼리 운세 비교했는데 같은 한 줄이면 신뢰 즉시 붕괴

Claude API 사용 시:
- api.js의 프롬프트는 "시드 값이 같으면 같은 결과" 조건 명시했는데 LLM은 결정론 보장 없음. 같은 시드로 두 번 호출해도 다른 결과 나올 수 있음. localStorage 캐시로 회피하지만, 캐시 지워지면 같은 날 다른 결과 나옴 → 신뢰 깨짐
- Claude API 환각 위험: 운세는 사실 검증 불가 영역이라 환각 자체는 문제 안 됨. 단 "사주 컨텍스트에 안 맞는 결과" 나올 가능성 (예: 양띠인데 "음의 기운이 강한 날" 식 모순)

**제안**:
- 운세 풀 25개 → 최소 100개로 늘려야 한 달 사용해도 중복 노출 안 됨
- 시드에 이름이 강하게 반영되도록 (이름 해시 결합)
- "재미용입니다" 디스클레이머가 PRD 12장에 있는데 실제 UI 어디에 들어가는지 확인 필요

### 3.5 현지화 미흡 - v2 i18n 약속이 진짜 가능한가?

**솔직한 답: i18n 자체는 기술적으로 쉬움. 문제는 컨텐츠 현지화임.**

- UI 텍스트 i18n = 1-2시간. Pretendard는 라틴/베트남어 글리프 일부 지원. 가능
- 운세 풀 25개를 베트남어/인니어/태국어로 번역 = 단순 번역 X
- "오늘은 작은 시작이 큰 변화를 만듭니다" 같은 한국어 운세는 베트남 정서에서 어색할 수 있음. **현지 카피라이터 필요** = 비용+시간 큼
- Claude API로 베트남어 운세 직접 생성하는 게 더 자연스럽지만, 베트남어 K-감성 톤 학습 데이터 부족할 가능성
- 동남아 시장 진입 = K-드라마 자막 톤을 그대로 운세에 가져와야 진짜 K-팬덤에 꽂힘. 이건 단순 번역으로 안 됨

**v2 i18n 로드맵은 "기술 작업"이 아니라 "현지 마케팅+카피 작업"으로 다시 정의해야 함.** PRD 11장은 v2를 "i18n 토글"로 가볍게 잡았는데, 실제는 큰 사업 영역.

## 4. 개선 제안 (P0/P1/P2)

### P0 (배포 전 반드시 수정)

**P0-1: 카드 워터마크 강화 + 도메인 단축**
- 현재 22px 한국어로 카드 맨 하단. 인스타 캡션에 가려지면 0 효과
- 변경: 워터마크를 카드 위 우상단 코너에 영문 + 한글 병기로 키우기. 도메인은 "kfortune.pages.dev" → 짧고 영어권도 외울 수 있는 도메인 검토 (예: kday.fun, koru.app)
- 이유: 바이럴 루프 1번 단계에서 차단되는 걸 막아야 함

**P0-2: 운세 풀 25개 → 60개 이상으로 확장 (Plan B 가동 시)**
- 25개로는 한 달 사용 시 5번 반복 발생. 신뢰 즉시 붕괴
- 민티 위너책쓰기/dailybook 자산에서 운세 톤 짧은 문장 가져오기 가능
- 이유: 재방문 6주차에 패턴 들켜서 이탈

**P0-3: 한국어 UI에 "재미용" 디스클레이머 + 정통 사주 vs Plan B 명시**
- 사용자가 "이거 진짜 사주야?"라고 물을 때 답 명확해야 함
- PRD 12장 위험 완화로 명시되어 있는데 실제 카드 UI/입력 페이지 어디 들어갈지 확정 필요
- 이유: Saju World 사용자가 우리 보고 "사기인가?" 느끼지 않도록

### P1 (배포 직후 1주 안)

**P1-1: PWA 전환 + 일일 푸시 알림**
- Service Worker로 매일 아침 8시 푸시 ("오늘의 K-운세가 도착했어요")
- 재방문률 5% 목표 달성에 필수. localStorage 그리드만으로 안 됨
- 이유: 운세 카테고리는 푸시 없으면 죽는다

**P1-2: 영어 i18n 1차 (베트남어/인니어 전에 영어)**
- 영어가 글로벌 공통어이자 동남아 인플루언서 1차 언어
- 카드 워터마크/입력 폼/버튼 텍스트만 영어 토글
- 운세 한 줄은 한국어 + 영어 의역 병기 (예: "오늘은 작은 시작이 큰 변화를 만듭니다 / Small steps, big changes today")
- 이유: Linh 페르소나 시뮬레이션 실패 회피 + 글로벌 시드 마케팅 가능

**P1-3: 친구 비교 URL 공유 (PRD N2)**
- 이미 nice-to-have로 정의되어 있는데 P1으로 끌어올려야 함
- 커플/BFF 후크가 바이럴 핵심. PRD 4장 N2가 "시간 남으면"인데, 이게 빠지면 단독 카드만 남고 공유 동기 약함
- 이유: PRD 9장 콘텐츠 마케팅 후크 + 인스타 시리즈 강화

### P2 (v2)

**P2-1: 베트남어/인니어 i18n + 현지 카피라이터 협업**
- 단순 번역 X. K-드라마 자막 톤을 살린 현지 운세 풀 재작성
- 동남아 인플루언서 1-2명에게 1개월 베타 + 피드백
- 이유: 진짜 동남아 진출은 현지 컨텐츠가 본체

**P2-2: 영상/GIF export 옵션**
- 정적 PNG로는 릴스/틱톡 안 통함
- 3-5초 페이드인 GIF로 export → 릴스 업로드 가능
- 이유: 인스타 알고리즘은 이미 정적 이미지보다 영상에 도달 가중치

**P2-3: 카카오톡 채널 (국내) + Telegram bot (동남아) 푸시**
- PWA 푸시는 권한 거절률 70%+. 카톡/Telegram이 동남아에서 도달률 우위
- 이유: 푸시 채널 분산이 운세 카테고리 재방문 보장

## 6. 민티 마케팅 후크 평가 (PRD 9장)

**PRD 9장 후크 4개 솔직 평가**:

### 6.1 "행글라이터 채널 영상: AI로 30초 만에 한국 사주 카드 만드는 법" (W22-23 후보)
- **평가: 약함**. 행글라이터 채널은 "AI 도구 리뷰/튜토리얼" 톤. 자기가 만든 사이트 홍보 영상은 시청자가 "광고잖아" 인식 가능성
- **대안**: "1인 개발자가 2-3시간 만에 K-운세 사이트 만든 비하인드" 형식으로 메이킹 스토리 콘텐츠로 가는 게 행글라이터 톤에 맞음. 사이트 자체 홍보보다 "Claude로 어떻게 만들었나" 과정 공개가 행글라이터 IP에 적합
- W22 영상 시리즈는 이미 "무료 AI 영상툴" 0순위로 잡혀 있음 (CLAUDE.md). 사주 사이트 영상이 W22-23 우선순위 충돌 위험

### 6.2 "인스타 시리즈: 매일 운세 카드 자동 업로드"
- **평가: 강함**. 민티 일일 콘텐츠 자동화에 진짜 작동. 본인이 자기 운세 카드 매일 스토리에 올리면 = 일일 콘텐츠 + 사이트 노출 + 본인 신뢰성 (자기 도구 직접 씀)
- **단**: 매일 똑같은 형식 카드를 30일 올리면 팔로워 피로감. 형식 변주 필요 (운세 카드 + 코멘트 한 줄, 또는 카드 + 본인 일상 사진 콜라주)

### 6.3 "위너책쓰기 코칭: 오늘의 운세 → 일일 저널 한 줄 워크플로"
- **평가: 약함**. 위너책쓰기 학습자 입장에서 "운세 → 저널"이 글쓰기 학습 도구로 직결되지 않음. 무리한 연결
- **대안**: 위너책쓰기는 그대로 두고, 별도 도메인(자기성장 콘텐츠)에서 후크 활용

### 6.4 "동남아 진출 후크: 베트남어/인니어 i18n + 현지 인플루언서 시드"
- **평가: 가설 단계. 검증 0**. IDEA.md 자체에 "동남아 사용자가 매일 재방문 = 추정"이라고 정직하게 적혀 있음. PRD 9장이 이 가설을 마치 사실인 것처럼 후크에 포함시킨 게 문제
- **현실**: v1 한국어 only로 출시 → 한국 트래픽 데이터만 나옴 → 동남아 가설 검증 X. 검증 없이 v2 i18n 투자하면 시간/비용 손실 가능
- **대안**: v1.5에서 영어 i18n + 글로벌 시드 마케팅(영어권 K-팝 팬덤) 먼저 실험. 동남아는 v2에서 영어 데이터 보고 결정

### 6.5 종합

**작동하는 후크: 6.2 인스타 시리즈 (1개).** 나머지 3개는 약하거나 가설.

**민티에게 솔직히**: 이 사이트는 "본인의 일일 인스타 콘텐츠 자동화 도구"가 1차 가치. 동남아 진출/위너책쓰기 연결/행글라이터 튜토리얼화는 부차적이고 v1 출시 직후 데이터 보고 결정해야 할 영역. PRD 9장처럼 4개 후크 다 잡으면 어느 하나 깊이 못 함.
