# 한국어 UI 적합 도메인 (C)

**작성**: 시장조사 에이전트 C
**작성일**: 2026-05-16
**관점**: 한국어 UI로 시작해도 글로벌(특히 동남아)로 통할 수 있는 도메인 발굴
**운영자 매칭**: 민티 (1인 콘텐츠 크리에이터, AI/글쓰기/콘텐츠 마케팅 전문)

---

## 핵심 가설

> "한국어 UI = 약점"이 아니라 "K-브랜드 매력 = 강점"이 되는 도메인이 존재한다.

근거:
1. 동남아 6개국에서 K-콘텐츠(드라마/K-pop/뷰티) 팬덤은 한국어 자체에 호감과 동경
2. 시각/숫자/이미지 위주 인터페이스는 텍스트 비중이 낮아 한국어여도 사용 마찰 적음
3. 한국 발 점술/MBTI/심리테스트는 이미 동남아 SNS에서 K-콘텐츠 부속 문화로 확산 중
4. 한국풍 UI 자체가 "트렌디한 아시아 디자인"으로 인식 (busy + cute illustration + 빠른 피드백)

---

## 1. 언어 의존도 낮은 도메인 5개 (시각/숫자/이미지 위주)

### 1-1. 컬러 팔레트 + 이름/생일 운세 결합기
- **컨셉**: 이름·생일 입력 → 오늘의 행운 컬러 팔레트 5색 + 폰 배경화면 생성
- **언어 의존도**: 매우 낮음 (입력 = 이름/숫자, 출력 = 색상 칩)
- **글로벌 통할 이유**: Coolors·ColorMagic 같은 도구가 영어권에서 인기지만 "운세 + 색"의 결합은 동양/한국풍이 강점. 색은 만국 공용어
- **민티 매칭**: 콘텐츠 마케팅 강점 → 인스타용 "오늘의 컬러" 자동 생성 마케팅 가능

### 1-2. 비주얼 습관 트래커 (Done 스타일)
- **컨셉**: 습관을 카드 + 색상으로만 표현. 탭하면 칸이 색으로 채워짐. 텍스트 최소
- **언어 의존도**: 낮음 (아이콘 + 색 + 숫자 카운트)
- **글로벌 통할 이유**: Habi, Done이 영어권 1위지만 한국식 cute illustration + 잔디밭 UI는 차별화
- **민티 매칭**: 자기성장 콘텐츠 채널(행글라이터)과 직결. "물고기 잡는 법" 톤

### 1-3. 미니멀 포모도로 + 통계 카드
- **컨셉**: 25분 타이머 + 끝나면 자동으로 인스타용 통계 카드 생성 ("오늘 4시간 집중했다")
- **언어 의존도**: 매우 낮음 (숫자 + 그래프 + 이모지)
- **글로벌 통할 이유**: 학생/원격 워커 글로벌 보편. 통계 카드 = SNS 자동 마케팅
- **민티 매칭**: 콘텐츠 자동 생성 = 마케팅과 결합

### 1-4. AI 얼굴 분석 (관상 라이트 버전)
- **컨셉**: 셀카 업로드 → 얼굴 비율 + 5가지 성격 키워드 시각화
- **언어 의존도**: 낮음 (이미지 + 키워드 5개)
- **글로벌 통할 이유**: 한국 관상 = K-콘텐츠 부속 문화. "한국 의사가 본 내 얼굴" 톤이 동남아에서 통함
- **위험**: AI 윤리/외모 평가 우려 → "긍정 키워드만" 정책 필요
- **민티 매칭**: 콘텐츠 마케팅 가능 (튜토리얼 영상)

### 1-5. 무드보드 메이커 (K-aesthetic 템플릿)
- **컨셉**: 사진 4-9장 업로드 → 한국 인스타 감성(파스텔/필름톤) 콜라주 자동 생성
- **언어 의존도**: 거의 없음 (이미지만)
- **글로벌 통할 이유**: Pinterest 2026 트렌드 = "intentional curation". 한국 인스타 미감은 글로벌 Gen Z가 모방 중
- **민티 매칭**: 출판/콘텐츠 마케팅 강점과 직결

## 2. K-콘텐츠 팬층 매력 도메인 5개 (사주/MBTI/타로 등)

### 2-1. K-사주 미니 (이름·생일 → 30초 카드)
- **컨셉**: 정통 사주 풀이는 무거우니 "오늘의 한 줄 + 행운 색 + 행운 숫자" 카드 한 장
- **K-매력**: Saju World가 이미 베트남어 번역 추가했고 적극 확장 중. 동남아에서 호기심 수요 검증됨
- **차별점**: 정통 사주 앱은 텍스트가 많음 → 한 장 카드형으로 차별
- **언어 의존도**: 중 (한 줄 메시지는 번역 어려움 → AI 자동 번역으로 v2 대응)

### 2-2. K-스타일 MBTI 변형 테스트 (8문항 짧은 버전)
- **컨셉**: 일반 16personalities 대신 "K-드라마 캐릭터로 보는 내 MBTI" 같은 변형
- **K-매력**: 동남아 K-드라마 팬층 직접 타깃
- **언어 의존도**: 중 (문항 8개만 번역하면 됨. v1은 한국어로 시작)
- **확장**: 결과 카드를 인스타 스토리에 공유 가능하게 디자인

### 2-3. K-타로 (3장 뽑기 + 한국 일러스트)
- **컨셉**: 한국 작가 일러스트 타로 카드 22장. 질문 입력 → 3장 자동 뽑기
- **K-매력**: 동남아 타로 콘텐츠 폭증 + 한국 일러스트 미감 결합
- **언어 의존도**: 중 (해석 텍스트 짧게 운영하면 가능)
- **민티 매칭**: 콘텐츠 마케팅 강함. "오늘의 타로" 인스타 시리즈

### 2-4. 이름 궁합 (한국식 작명 풀이)
- **컨셉**: 두 이름 입력 → 백분율 + 행운 컬러 + 한 줄 코멘트
- **K-매력**: 한국식 작명 풀이는 동남아에 잘 알려지지 않음 → 신선함
- **언어 의존도**: 낮음 (이름 두 개 + 숫자 결과 + 색)
- **마케팅**: K-드라마 캐릭터 + 사용자 이름 궁합 = 바이럴 가능

### 2-5. 별자리 X K-pop 멤버 매칭
- **컨셉**: 생일 입력 → "당신과 가장 비슷한 K-pop 멤버 5명" 결과
- **K-매력**: K-pop 팬덤 동남아 최강. 직접 타깃
- **언어 의존도**: 낮음 (멤버 이름 + 이미지)
- **위험**: 아티스트 IP 저작권 → 일러스트 또는 이니셜+팀명만 표기로 우회 가능
- **민티 매칭**: 채널 슬로건 "AI & 글쓰기"와는 멀음 → 추천 우선순위 낮음

## 3. 민티 능력 + AI 콘텐츠 결합 가능 도메인 5개

### 3-1. AI 자기소개 카드 생성기 (K-스타일 미니 프로필)
- **컨셉**: 5개 질문 답변 → AI가 한국 인스타 감성 자기소개 카드 1장 자동 생성
- **민티 매칭**: AI + 글쓰기 + 콘텐츠 마케팅 3박자 모두 매칭
- **글로벌 통할 이유**: 인스타 프로필 카드 = 글로벌 보편 수요. 한국 톤이 차별
- **마케팅**: 행글라이터 채널에서 "AI로 1분만에 인스타 프로필 카드" 튜토리얼 영상

### 3-2. AI 일기 → 짧은 자서전 변환기
- **컨셉**: 매일 한 줄 일기 → 한 달 모으면 AI가 "이번달의 나" 짧은 에세이 생성
- **민티 매칭**: dailybook(자서전 100질문) 프로젝트와 직결. 위너책쓰기 코칭과 시너지
- **언어 의존도**: 높음 → 단점. v1 한국어 → v2 다국어로 점진 확장
- **확장**: 1년치 모으면 전자책 PDF 자동 출력 → 위너책쓰기 코칭으로 연결

### 3-3. AI 책 추천 (생일 + 관심사 → 한국 책 5권)
- **컨셉**: 생일 + 키워드 3개 → 한국 베스트셀러 + 행글라이터 큐레이션 5권
- **민티 매칭**: 출판사 운영자 + 책쓰기 코치 = 강점 직결
- **언어 의존도**: 중 (책 제목/저자 표기. 표지 이미지 + 한 줄 설명)
- **글로벌 통할 이유**: K-콘텐츠 책 번역서 동남아 진출 활발

### 3-4. AI 콘텐츠 아이디어 룰렛
- **컨셉**: 닉네임 + 주제 입력 → AI가 인스타/유튜브 콘텐츠 아이디어 7개 카드 생성
- **민티 매칭**: AI + 콘텐츠 마케팅 핵심 강점. 강의 수강생 도구로 활용 가능
- **글로벌 통할 이유**: 1인 크리에이터 글로벌 폭증. 한국식 톤이 차별
- **확장**: 강의 자료 + 위너책쓰기 코칭 도구로 묶기

### 3-5. AI 프롬프트 변환기 (한국어 → 영어 이미지 프롬프트)
- **컨셉**: 한국어 한 줄 → Midjourney/DALL-E용 영어 프롬프트 + 추천 스타일 태그
- **민티 매칭**: 행글라이터 채널 AI 영상 시리즈와 직결. 프롬키트(이미 배포)와 시너지
- **글로벌 통할 이유**: 비영어권 글로벌 공통 페인포인트
- **주의**: 프롬키트와 카니발리제이션 위험 → 차별 포인트 필요

## 4. 한국풍 디자인이 매력인 도메인 (K-스타일 컬러/타이포)

### 4-1. 인스타 카드뉴스 템플릿 (K-감성)
- **K-스타일 요소**: 파스텔 + 손글씨 + 미니 일러스트 + 그리드형 카드뉴스 (한국 출판/마케팅 표준 디자인)
- **글로벌 통할 이유**: Pinterest 2026 트렌드 = 큐레이션 미감. 한국 카드뉴스 포맷 동남아 마케터 모방 시작
- **민티 매칭**: 콘텐츠 마케팅 강점 + 강의 자료로 활용

### 4-2. 미니홈피 부활 (싸이월드 감성 프로필)
- **K-스타일 요소**: 2000년대 한국 미니홈피 미감(BGM + 다이어리 + 게스트북) + 모던 리메이크
- **글로벌 통할 이유**: 2026 Gen Z 노스탤지어 트렌드 (Pinterest 예측 포함). Y2K 아시안 감성
- **언어 의존도**: 낮음 (이모지 + 사진 + 짧은 코멘트)
- **차별**: 글로벌엔 없는 카테고리. 한국 정체성 자체가 강점

### 4-3. 다꾸/캘리그라피 디지털 다이어리
- **K-스타일 요소**: 다이어리 꾸미기 문화는 한국 발 (모트모트, 폰트북). 손글씨 폰트 + 마스킹테이프 일러스트
- **글로벌 통할 이유**: 일본 bullet journal과 차별 (한국형 = 더 캐주얼·귀여움)
- **언어 의존도**: 낮음 (스티커 + 이미지 + 짧은 글)

### 4-4. K-style 명함/링크 페이지 (Linktree 한국식)
- **K-스타일 요소**: 한국 인스타 셀럽 인링크 디자인(둥근 카드 + 그라데이션 + cute illustration)
- **글로벌 통할 이유**: Linktree 글로벌 표준이지만 한국풍 미감은 차별
- **민티 매칭**: 콘텐츠 크리에이터 도구 = 본인 페르소나 직결

## 5. 종합 추천: 가장 강한 5개 도메인

**평가 기준** (각 5점):
- A: 한국어 UI 적합도 (텍스트 적을수록 높음)
- B: K-매력 (한국 발이라는 게 강점)
- C: 민티 능력 매칭
- D: 동남아 수요 가능성
- E: 2-3시간 MVP 실현성

| 순위 | 도메인 | A | B | C | D | E | 합계 |
|------|--------|---|---|---|---|---|------|
| 1 | **K-사주 미니 (1장 카드)** | 4 | 5 | 4 | 5 | 5 | 23 |
| 2 | **이름 궁합 (K-작명 + 컬러)** | 5 | 4 | 4 | 4 | 5 | 22 |
| 3 | **AI 콘텐츠 아이디어 룰렛** | 3 | 3 | 5 | 5 | 5 | 21 |
| 4 | **컬러 팔레트 + 행운 운세** | 5 | 4 | 4 | 4 | 4 | 21 |
| 5 | **인스타 카드뉴스 템플릿 (K감성)** | 4 | 5 | 5 | 4 | 3 | 21 |

### 1위. K-사주 미니 (이름·생일 → 30초 카드)
- **이유**: Saju World가 베트남어 추가하며 검증한 수요 + 1장 카드형으로 차별 + 한국어 텍스트 최소화 가능
- **1인 운영 가능**: O. AI가 사주 풀이 → 카드 템플릿 자동 생성. 콘텐츠 인스타 시리즈로 확장 가능
- **2-3시간 MVP**: 입력 폼 + 사주 계산 라이브러리 + 카드 출력 SVG. 충분

### 2위. 이름 궁합 (K-작명 + 행운 컬러)
- **이유**: 두 이름 입력 = 언어 무관. 동남아엔 K-작명 풀이 거의 없음. 인스타 공유 바이럴 가능
- **1인 운영 가능**: O. 알고리즘 단순(이름 획수 + 색상 매핑). 콘텐츠 자동 생성 마케팅 강함
- **2-3시간 MVP**: 더 단순한 스코프. 1순위와 결합 가능 ("연인 사주" 통합 앱)

### 3위. AI 콘텐츠 아이디어 룰렛
- **이유**: 민티 핵심 강점 매칭 1등. 강의 수강생 + 위너책쓰기 코칭 도구로 즉시 활용
- **1인 운영 가능**: O. AI API 호출 + 카드 출력. 추후 유료 SaaS화 가능
- **약점**: K-매력 약함. 글로벌 보편 도구 (단순 한국어 UI일 뿐)

### 4위. 컬러 팔레트 + 행운 운세
- **이유**: 색은 만국 공용어. Coolors 글로벌 검증된 카테고리에 K-운세 차별 추가
- **1인 운영 가능**: O. 색상 알고리즘 + 인스타 공유 카드. 매우 단순
- **확장**: "오늘의 컬러" 인스타 시리즈로 행글라이터 채널 콜라보

### 5위. 인스타 카드뉴스 템플릿 (K감성)
- **이유**: 민티 능력 매칭 만점. 콘텐츠 마케팅 강점 직결. 강의 자료로도 활용
- **1인 운영 가능**: O. 템플릿 디자인은 민티 본인 강점
- **약점**: 2-3시간 MVP 스코프 약간 무거움 (템플릿 디자인 시간 필요)
