## 동남아·한국 우회 가능 후보 (글로벌 화제 but 동남아·한국 미진출) 5개

선정 기준: ① 글로벌에서 검증된 카테고리, ② 베트남어·인니어·태국어 native 지원 부재 또는 약함, ③ 단순 MVP 2-3시간 가능, ④ 민티 능력(AI×글쓰기×콘텐츠)과 연결.

### 1. **AI 저널링 (동남아 언어 native)** ⭐ 최우선 추천
- **글로벌 화제도**: $6.34B 시장, Headspace/Mindvalley 진입, PH **Joodle** 연간 8위
- **동남아 갭**: 베트남어·인니어·태국어 native 프롬프트 + 문화 맥락(가족 중심, 종교 반영) 거의 없음
- **민티 연결**: 자기 스토리 → 콘텐츠화 = 위너책쓰기와 동일 철학
- **MVP**: localStorage + 한국어/영어/베트남어/인니어 토글 + GPT 프롬프트 5종

### 2. **회의/음성 → 소셜 콘텐츠 변환 (동남아 언어 1차 출력)**
- **글로벌 화제도**: ProdShort (PH 4월 738 votes), Fathom 3.0 (790 votes)
- **동남아 갭**: 영어 회의는 잘 인식하지만 베트남어·인니어 회의 → 인니어 LinkedIn/TikTok 캡션 자동 생성 도구 부재. **Vozo Visual Translate**가 가까우나 영상에 한정
- **민티 연결**: 콘텐츠 마케팅 본업
- **MVP**: 텍스트 입력 → 5개 플랫폼 캡션 동시 생성 (Whisper API는 nice-to-have, MVP는 텍스트로 충분)

### 3. **구글맵 리뷰 → 1페이지 자영업 사이트 (Brila의 동남아 버전)**
- **글로벌 화제도**: Brila PH 4월 1위 1334 votes
- **동남아 갭**: 베트남·인니·태국 자영업은 페이스북 페이지에 의존하지만 정식 사이트 없음. Brila는 영어 리뷰 위주
- **민티 연결**: 콘텐츠 마케팅 대행(인테리어 회사) 노하우 응용
- **MVP**: Google Place ID 입력 → 리뷰 fetch → 1페이지 HTML 생성 (단, Maps API 키 필요는 v2)

### 4. **자기 스토리·자서전 100질문 (동남아 언어판)**
- **글로벌 화제도**: dailybook(민티 본인 책), Joodle 사례 + 저널링 카테고리 일반 성장세
- **동남아 갭**: 베트남·인니에서 자서전 코칭 콘텐츠 부족. 12M Indonesian creators (Observer ID) → 자기 스토리 콘텐츠화 수요 큼
- **민티 연결**: dailybook 콘텐츠 자산 그대로 이식 가능
- **MVP**: 한국어 100질문 → 베트남어/인니어 1차 번역 → 답변 저장 + AI 정리

### 5. **AI 헤드샷·프로필 사진 (Indonesian/Vietnamese face dataset 강화)**
- **글로벌 화제도**: HeadshotPro $3.6M ARR 1인 운영 ([source](https://greyjournal.net/hustle/grow/solo-founders-million-dollar-ai-businesses-2026/))
- **동남아 갭**: 글로벌 헤드샷 도구는 백인·동아시아 얼굴 위주. 동남아 6국 페이스 underrepresented
- **민티 연결**: 약함 (단, 콘텐츠 마케팅용 프로필 사진은 1인 크리에이터 자주 필요)
- **MVP**: 2-3시간 무리. **이 카테고리는 v2 후보 권장**
