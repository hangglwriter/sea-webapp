## 아이디어 #1: "내 책의 가상 독자 5명이 자기들끼리 단톡방에서 욕한다" - 출간 전 독자 시뮬레이터

- **타깃 1차 사용자**: 위너책쓰기 7주 졸업 직전 + 출간 준비 작가 + 자서전 쓰는 50-60대. 민티 본인 = 도그푸딩 (위너책쓰기 7주차 "독자 피드백" 회차 즉시 사용)
- **흥미 시그널**: 자기 원고 1챕터 업로드 → AI가 가상 독자 5명 자동 생성 (예: "30대 직장맘 / 50대 자영업자 / 20대 취준생 / 70대 어머니 / 40대 동종업계 라이벌") → 5명이 **자기들끼리 단톡방에서** 그 챕터 진짜처럼 욕하고 토론. 사용자는 관전. 끼어들기 가능. **wow moment 5분 이내**: 첫 챕터 업로드 → 30초 만에 단톡방 알림 "30대 직장맘: 솔직히 3페이지부터 졸림 ㅋㅋ" → "70대 어머니: 무슨 소리야 나는 너무 좋던데". 내 글이 "살아 움직이는" 첫 감각
- **핵심 플로우 5단계**:
  1. 원고 1챕터 (PDF/한글/워드/텍스트) 업로드 또는 붙여넣기
  2. 페르소나 5명 자동 추천 (책 장르 인식 후) + 사용자가 1명 커스텀 가능 ("우리 시어머니 추가")
  3. 30초 카운트다운 → 단톡방 알림 화면 (1명씩 메시지 등장, 카톡 UI 클론)
  4. 5명이 자기들끼리 토론 (10-15턴, 진짜 카톡처럼 시간차 + 이모지 + 동의/반박)
  5. 사용자가 "@30대 직장맘" 호명 → 직접 질문 가능. 마지막에 "이 챕터 개선 포인트 TOP 3" 자동 요약 + PDF 출력
- **바이럴 시그널**: "내 자서전 보고 '70대 어머니' AI가 운 단톡방" 캡처 인스타. 행글라이터 영상 "AI 가상 독자 5명한테 내 책 욕먹기" 1편 = 위너책쓰기 영업 직격. 위너책쓰기 졸업생이 자기 단톡방 캡처 자랑하면 **다음 기수 신청 트리거**
- **수익 모델**: 무료 = 챕터 1개 / 페르소나 3명 / 단톡방 1회. **유료 월 2.9만원** = 챕터 무제한 + 페르소나 10명 (시어머니/회사 부장 커스텀) + 단톡방 PDF 리포트 + 위너책쓰기 코치 모드 (코치가 수강생 단톡방 관전). 결제 = Toss Payments 정기결제 / Stripe. **위너책쓰기 19.9만원 7주 패키지 부가 도구로 묶으면 수강생 추가 결제 0원 (코치 결제 = B2B)**
- **시장 규모 추정**: 위너책쓰기 졸업생 누적 50-100명 / 매년 신규 50-100명 = 즉시 풀. 행글라이터 구독자 중 책 쓰는 사람 100-300명 추정. 한국 자가출판 시장 2028년 2조 추정 = 외부 확장 충분. B2B 1인 책쓰기 코치 (한책협 등) 50명 = 월 5만원 × 50 = 월 250만원 추가
- **차별성 한 줄**: "내 원고를 페르소나 5명이 **자기들끼리** 카톡 토론하게 만든다. Character.AI는 1대1, AI Book Club은 정적 분석. 캔바+ChatGPT 5분에 단톡방 시뮬레이션 절대 불가"
- **빌드 복잡도**: ★★ (중상). 정적 HTML + Anthropic API + 카톡 UI 클론(CSS) = 90-120분 가능. 단 페르소나 5명 동시 대화 = Claude API multi-turn 설계 필요. R7 빌드 시 페르소나 3명으로 MVP 축소 가능
- **R1 출처**: fresh.md #1 (AI Book Club Persona Reader) + pain.md #1 (출간 후 마케팅 절벽) + pain.md #2 (7주 책쓰기 완주 실패)

## 아이디어 #2: "내 썸네일 5개를 AI 100명 청중이 클릭률로 투표하는 사전 테스트소" - 콘텐츠 발사 전 시뮬레이터

## 아이디어 #3: "70대 어머니 / 회사 차장님 / 라이벌 친구가 내 글을 진짜로 욕하는 잔혹 비평가" - 글쓰기 슬럼프 박살기

## 아이디어 #4: "7주 책쓰기 incremental 클리커 게임" - 위너책쓰기 리드 마그넷 + 게임화

- **타깃 1차 사용자**: 위너책쓰기 잠재 리드 (책 쓰고 싶다고 검색하는 한국인) + 위너책쓰기 졸업생 (자가복습) + 자서전 쓰려는 50-60대 + 민티 본인 (책 챕터04 게임화 도그푸딩)
- **흥미 시그널**: Universal Paperclips 메카닉 + 책쓰기. 매일 들어와서 시드 한 줄 입력 → AI가 챕터 1단락 자동 생성 + 분량 +100자 + 가상 독자 만족도 +5 + 가상 팔로워 +3. **자원 5개 게이지**(분량 / 캐릭터 깊이 / 플롯 강도 / 독자 공감 / 잠재 팔로워)가 실시간 차오름. 7주 후 책 한 권 + 잠재독자 300명 게이지 완성. **"공부 안 하면 죽는 게임처럼, 안 쓰면 진척도 멈춘다"** 도파민. wow moment 3분 이내: 첫 진입 → 시드 한 줄 → AI 1단락 + 게이지 5개 차오름 애니메이션
- **핵심 플로우 5단계**:
  1. 첫 진입: 책 컨셉 한 줄 입력 ("내 30대 자서전" 등) + 7주 게이지 시작
  2. 매일 1회 무료 클릭: 오늘의 시드 받기 → AI가 한 단락 자동 생성 → 사용자가 1-2줄 수정 → 저장
  3. 게이지 5개 실시간 차오름 (분량 / 캐릭터 / 플롯 / 공감 / 팔로워)
  4. 매주 끝나면 "1주차 클리어!" 인증 카드 자동 생성 + 인스타 공유 버튼

## 아이디어 #5: "AI 직원 5명이 매일 9시 출근해서 자기들끼리 단톡방 회의하는 1인 회사" - 콘텐츠 자가증식 OS

- **타깃 1차 사용자**: 행글라이터 구독자 중 1인 사업자 + 위너책쓰기 운영자 (민티 본인) + 콘텐츠 마케팅 대행 클라이언트 (인테리어 회사 사장 = B2B). 민티 본인이 매일 일과 1:1 일치 = **도그푸딩 최강**
- **흥미 시그널**: 매일 오전 9시 알림 → "AI 직원 5명 출근" 단톡방 화면. 기획 직원 / 디자인 직원 / 작가 직원 / 영업 직원 / 분석 직원이 **자기들끼리 어제 결과 보고 + 오늘 계획 토론**. 사용자는 CEO로 결재만. **wow moment 5분 이내**: 첫 진입 → 사업 정보 한 줄 입력 ("행글라이터 유튜브 + AI/글쓰기 강의") → AI 직원 5명 자기소개 + 30초 후 "분석 직원: 어제 영상 조회수 X, 이상점 발견" → "기획 직원: 오늘 영상 주제 3개 제안" → "작가 직원: 1번이 좋은데 후킹 카피 수정 필요" → 사용자가 결재 한 번
- **핵심 플로우 5단계**:
  1. 첫 진입: 사업 한 줄 + 채널 정보 (선택: 유튜브 URL / 인스타 ID / 블로그) 입력
  2. AI 직원 5명 자동 채용 (페르소나 5명 + 어투 + 역할). 사용자가 1명 커스텀 가능 ("우리 막내 직원 추가")
  3. 매일 9시 (또는 사용자 설정 시간) 단톡방 알림 = 자율 회의 시작

  5. CEO 결재 화면 = 오늘의 결정 3개 + "승인" 한 클릭 → 콘텐츠 생성 자동 시작 (영상 대본 / 카드뉴스 / 캡션 / 블로그 자동 생성)

- **시장 규모 추정**: 행글라이터 구독자 중 1인 사업자 = 다수 (정확 수치 X). 한국 1인 사업자 수십만 명 = 외부 확장. 콘텐츠 마케팅 대행사 시장 = B2B 진입 즉시. **MY AI Agent / Influcio / Agent-Sin 글로벌만 있고 한국 빈자리**
