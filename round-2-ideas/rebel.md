## 아이디어 #1: "유령 회사" - 사용자가 자는 동안 AI 직원 5명이 자율 야간 근무 + 아침 6시 보고서

**한 줄 핵심 가치**: 1인 크리에이터가 출근하면 "AI 직원들이 밤새 일한 8시간 결과물"이 책상에 쌓여있다.

- **타깃 1차 사용자**: 민티 본인 (행글라이터 + 위너책쓰기 + 인테리어 대행 동시 운영자), 행글라이터 구독자 중 본인 채널/사업 운영하는 100-300명 추정.

- **대담 시그널**: 다른 ideator는 "AI 도구를 사용자가 적극 호출" 패턴만 떠올림. **반대로 사용자가 "잠자고 일어나면 결과물이 있는" 비동기 자율 패턴**은 ChatGPT GUI 발상에서 차단됨. R1 fresh #8 "AI Crew Solo Company"가 비슷하나 그건 "출근해서 단톡방 관전". 이건 **사용자가 자는 동안 새벽 1시-6시 cron 자율 실행 + 아침 6시 카톡 알림 "오늘 영상 대본 / 인스타 캡션 3개 / 이메일 답장 7건 / 위너책쓰기 단톡방 응답 12건 완료. 결재 필요한 결정 3건"**. ChatGPT/Claude 사용 경험 자체와 다른 발상.

- **핵심 플로우 3-5단계**:
  1. 사용자가 "오늘 회의록 / 어제 데이터 / 이번주 일정" 한 번 저녁에 던짐 (10초)

  4. 아침 6시 카톡으로 "어젯밤 결과물 + 결재 필요 3건" 알림
  5. 사용자가 출근길 카톡에서 결재 → 직원이 자동 실행

## 아이디어 #2: "살아 움직이는 책" - 출간 후 매일 한 문장씩 자가 증식하는 자서전 + 독자가 다음 문장을 결정

**한 줄 핵심 가치**: 자서전을 "완성된 한 권"이 아니라 "독자와 함께 매일 자라는 살아있는 식물"로 만든다. 출간 후 6개월간 매일 새 문단 자동 추가 + 독자가 다음 분기 선택 투표.

- **타깃 1차 사용자**: 위너책쓰기 졸업생 중 자서전 쓴 50-60대 + 민티 어머니 책 "칠십 비로소" 프로젝트 + 행글라이터 구독자 중 글 쓰는 사람들.

- **대담 시그널**: 다른 ideator는 "책 = 정적 PDF/EPUB" 전제. **반대로 출간 시점이 끝이 아니라 시작**. 책이 살아 움직이고 독자가 식물 가꾸듯 매일 들어옴 = "재방문률 = 다음 책 마케팅" 페인 #1 완전 반전. fresh #4 (분기 소설)와 다름: 분기 소설은 사용자가 능동 분기. 이건 **저자 페르소나가 매일 자가 증식 + 독자 reaction이 다음 문장 시드**.

- **핵심 플로우 3-5단계**:
  1. 저자가 자서전 본문 + 본인 어투/관점 학습 데이터 업로드 (위너책쓰기 7주 졸업 시점)
  2. AI가 저자 분신 생성 + 책에 "성장 모드" 활성화
  3. 매일 아침 7시 분신이 한 문단 자동 작성 ("어제 댓글 / 오늘 날씨 / 독자 질문 #14"를 시드로 새 일기 한 편)
  4. 독자가 "오늘 문단 → 다음에 어떤 이야기?" 3개 선택지 투표 (이모지 1초)
  5. 다음 날 새 문단이 투표 기반으로 작성 + 카톡 채널 알림 "오늘 분신이 한 문장 더 자랐어요"
  6. 6개월 = 180 문단 = 책 2배 분량 자가 증식. EPUB 자동 재출간.

- **클론 검증** (WebSearch 5회+ 결과):
  - **글로벌**: AI 디지털 교과서 (학생 데이터 기반 customization). Korea Times "AI 1년 9000권 자가출판" - 모두 "한 번 생성 후 끝". **출간 후 매일 자가 증식 + 독자 reaction 학습 + 한국어 자서전** 0건 확인.
  - **한국**: 생성형 AI 사피엔스 / 만들면서 배우는 생성 AI 등 도구 소개 책. "매일 자라는 책" 자체 형식 0건. fresh #4 분기 소설은 사용자 능동 분기지 자율 증식 X.
  - **솔직 약점**: AI 작성 분량이 진짜 작가의 가치를 희석할 우려 → 도덕성 / 독자 신뢰 페인. **저자 사후/병환 시 분신이 마지막 책 완결** 시나리오로 정당화 가능.
  - **URL**: [9000권 AI 출판 Korea Times](https://www.koreatimes.co.kr/lifestyle/books/20260226/1-year-1-publisher-9000-books-ai-generated-titles-flood-korean-shelves) / [Customizable AI Textbooks](https://www.gettingsmart.com/2024/10/07/customizable-ai-powered-textbooks-reshape-learning/) / [AI Book Boom Quality Reckoning](https://completeaitraining.com/news/fifty-pages-in-an-hour-ais-book-boom-in-korea-faces-a/)

- **수익 모델**: 무료 = 7일 미리보기. 유료 9.9만원 (1회권, 6개월 자가 증식) + 위너책쓰기 7주 + 9.9만원 패키지 = 위너책쓰기 가격 인상 정당화. EPUB 매 갱신 시 자동 재출간 = 출간 후 매출 발생 (페인 #1 직격).

- **시장 규모 추정**: 위너책쓰기 졸업생 매년 50-100명 × 50% 가입 = 25-50명 × 9.9만원 = 연 250-500만원 (1차). 글로벌 자서전 시장 (Memoir industry) 영문 확장 시 10배. 한국 50-60대 자서전 출판 시장 = 매년 수천 권 추정.

- **차별성 한 줄**: "책 = 정적 PDF"가 아닌 "매일 자라는 식물 + 독자 투표 분기" 패턴. 글로벌 AI 디지털 교과서는 학생 학습용 / 한국 자가출판 AI 책은 1회 생성. "출간 후 6개월 자가 증식 + 한국어 자서전" 클론 0건.

- **빌드 복잡도** (단일 정적 HTML + Anthropic API 90-120분?):
  - **MVP 90-120분 가능**: 정적 HTML + Claude API + 시간 시뮬레이션 (6개월 → 6초 가속 데모). 자서전 1챕터 업로드 → "이 책이 6개월 후 이렇게 자란다" 시연. 진짜 cron + 독자 투표는 Phase 2 (Cloudflare Workers).

- **R1 출처**: pain #1 (출간 후 마케팅 절벽 6개월), pain #8 (작가 이메일 리스트 0→1000), utility #2 (출간 후 6개월 마케팅 엔진), fresh #4 (분기 소설 - 반전: 사용자 분기 X, 자율 증식 + 독자 reaction)

## 아이디어 #3: "예측이 틀린 만큼 학습" - 가상 청중 100명이 행글라이터 영상 결과를 미리 예측 + 실제 결과와 차이만큼 자가 페르소나 보정

**한 줄 핵심 가치**: AI 청중 100명이 "이 썸네일 클릭률 12.3%"라고 예측 → 진짜 게시 후 실제 8.7% → 차이 3.6%만큼 100명 페르소나가 자기들끼리 "우리가 뭘 잘못 봤지?" 자가 디버그. 페르소나가 매주 진짜 똑똑해진다.

- **타깃 1차 사용자**: 민티 본인 (행글라이터 주간 리포트 Method C v3 메타화), 행글라이터 구독자 중 자기 채널 운영자 1500+, 콘텐츠 마케팅 대행 인테리어 클라이언트.

- **대담 시그널**: 다른 ideator는 "AI 청중 시뮬레이터"만 떠올림 (fresh #2 답습). **반전: AI 청중이 틀린 것을 진짜 데이터로 자가 학습 + 채널주 본인 청중 점점 일치하는 디지털 청중 보유**. 6개월 후 "민티 행글라이터 채널 전용 청중 100명"이 존재 + 다른 채널주는 못 베낌 = 진짜 자산. Ask Rally + Thumblytics에 없는 "예측-실제 caliberation feedback loop".

- **핵심 플로우 3-5단계**:
  1. 사용자가 자기 채널 1주 영상 데이터 (썸네일/제목/CTR/시청시간) 업로드
  2. AI 청중 100명 생성 (20대 여대생 / 30대 워킹맘 / 자영업자 등 페르소나)
  3. 새 영상 시안 (썸네일 5종 + 제목 3종) → 청중 100명이 "내가 클릭할지 / 왜" 예측 + 한 줄 답변
  4. 사용자가 진짜 게시 후 1주 뒤 실제 데이터 입력 (또는 YouTube Analytics 자동 import)
  5. 차이만큼 청중 100명이 "우리가 뭘 잘못 봤지" 자가 디버그 + 페르소나 가중치 보정
  6. 6개월 후 = 채널주 전용 청중. 다음 영상 예측 정확도 점점 상승.

- **클론 검증** (WebSearch 5회+ 결과):
  - **글로벌**: Thumblytics ("진짜 사람 패널 사전 클릭 데이터"), TubeBuddy Thumbnail Analyzer (AI 점수 + 히트맵 + 실제 테스트), Ask Rally ($99+/월, B2B). YouTube 자체 multi-thumbnail A/B 기능 출시. ReelMind AI 예측. **모두 1회성 예측 또는 1회성 진짜 사람 테스트. "예측-실제 차이로 페르소나 자가 보정 + 채널주 전용 청중 자산 축적" 0건 확인.**
  - **한국**: ReelMind/Thumblytics 한국 클론 0건. 한국 유튜버 1만+ 채널 수만 개. ChatGPT로 썸네일 평가는 1회성.
  - **솔직 약점**: 100명 페르소나 시뮬 = 토큰 비용 큼. 1회 시뮬 = $0.5-1 추정. 보정 학습 = batch / 주말 = 비용 통제 가능.
  - **URL**: [Thumblytics](https://skywork.ai/skypage/en/Thumblytics-Deep-Dive-The-Ultimate-Thumbnail-Preview-Testing-Guide-(2025)/1974520585785503744) / [TubeBuddy Analyzer](https://www.tubebuddy.com/tools/thumbnail-analyzer/) / [ReelMind AI Prediction](https://reelmind.ai/blog/youtube-thumbnail-analysis-hitting-the-sweet-spot-with-ai-prediction) / [Engagement Dynamics arxiv](https://arxiv.org/pdf/1611.00687)
