## 아이디어 #1: "출간 D+1부터 D+180까지 자동으로 마케팅 콘텐츠 토해내는 작가 마케팅 OS"

원고 EPUB/PDF/Docx 1번 업로드 → AI가 챕터별 인용구 100개 + 카드뉴스 30장 + 쇼츠 대본 14개 + 인스타 캡션 90개 + 뉴스레터 시퀀스 12편 + 알라딘/yes24 상세페이지 SEO 키워드 + 180일 캘린더(Stibee/카톡채널 발송 예약 시트 자동 생성). 작가는 매일 "오늘 발행 콘텐츠 보기" 한 화면.

- **타깃 1차 사용자**: 위너책쓰기 졸업생 (매년 50-100명 누적, 출간 후 마케팅 절벽 = 페인 #1 정확히) + 민티 본인(자가출판사 운영) + 1인 자가출판 작가 (KDP·부크크·유페이퍼)
- **핵심 플로우 3-5단계**:
  1. 원고 + 책 표지 + 알라딘/yes24 등록 URL 업로드 (5분)
  2. AI가 "내 책 톤 학습" + "타겟 독자 페르소나 3종 추출" 자동 (3분 대기)
  3. 180일 콘텐츠 캘린더 자동 생성 (D+1 쇼츠 대본 / D+3 인스타 카드뉴스 5장 / D+7 뉴스레터 1편 / D+14 블로그 후기 유도 글...)
  4. 매일 아침 카톡 알림 → "오늘 발행할 거 3개, 클릭해서 복사+캔바 디자인 시안 자동 적용 링크"
  5. D+30/D+90/D+180 회고 리포트 (어느 채널 ROI 좋았는지 → 다음 책 마케팅 반영)
- **수익 모델**:
  - 무료: 책 1권 등록 + 30일 캘린더 (D+30까지 무료) → 30일 후 "다음 60일 잠금" 페이월
  - 유료 개인 작가 플랜: **월 2.9만원** (책 3권까지 + 180일 캘린더 무제한)
  - 유료 1인 출판사 플랜: **월 9.9만원** (책 20권까지 + 화이트라벨 리포트)
  - B2B 출판사 플랜: **월 39만원** (책 100권 + 마케터 협업 모드)
  - 결제 방식: 토스페이먼츠 정기결제 + 부가세 별도 (B2B는 세금계산서)
- **시장 규모 추정**:
  - 1차 자산 풀: 위너책쓰기 졸업생 100명 + 행글라이터 구독자 중 출간 경험자 200명 = **300명**
  - 결제율 15% (출간 후 마케팅 페인 강도 만성 우울 수준 = 페인 #1) = **월 45명 × 2.9만원 = 월 130만원** (Year 1 ARR 1560만원)
  - Year 2 확장: 한국 KDP/부크크 자가출판 작가 추정 **연 3000명+** 침투 5% = 150명 × 2.9만원 = 월 435만원
  - 1인 출판사 침투 (한국 1인 출판사 = 출협 등록 6000개+, 활성 추정 1500개) 1% = 15개 × 9.9만원 = 월 148만원
  - **Year 2 합계 추정: 월 700-1000만원 (ARR 1억+)**
- **차별성 한 줄**: "내 책 원고를 통째로 학습한 AI만 가능한 챕터별 인용구 100개 + 180일 캘린더 자동 생성. 캔바+ChatGPT로는 한 권 분량 캘린더 만드는 데 50시간 걸린다."
- **빌드 복잡도**:
  - V4 R7 MVP (90-120분): 단일 정적 HTML + Tailwind CDN + Anthropic API. 원고 텍스트 paste → 인용구 50개 + D+7/D+30 콘텐츠 시안 출력 (DB X, 결제 X, 발송 자동화 X)
  - Phase 2 (R6 PRD): 토스페이먼츠 + Supabase 사용자 DB + Stibee/카톡채널 API 연동 + 캘린더 발송 예약
- **R1 출처**: pain.md #1 (전자책 출간 후 마케팅 절벽 - 출간 첫 1-2주 후 우울증 수준) + pain.md #8 (작가 이메일 리스트 0→1000명) + utility.md #2 (출간 후 6개월 마케팅 자가증식 엔진)

## 아이디어 #2: "1인 책쓰기·강의 코치 전용 7주 코칭 운영 OS (위너책쓰기 도그푸딩 베이스)"

코치가 새 기수 열기 → 수강생 명단 카톡 ID/이메일 등록 → 7주 단계별 산출물 템플릿(기획→목차→1주차 원고→탈고→KDP 업로드) 자동 발송 + 수강생 제출물 자동 수집 + 코치 대시보드("이번 주 누가 어디서 막혔는지" 한 화면) + AI 1차 피드백 자동 생성 → 코치는 최종 코멘트만.

- **타깃 1차 사용자**: 민티 본인(위너책쓰기 7주 운영) + 한책협·MKYU·홍순성 등 책쓰기 코치 100명+ + 1인 AI/글쓰기 강사(지피터스·탈잉 등) 수백명
- **핵심 플로우 3-5단계**:
  1. 코치가 기수 생성 → 수강생 카톡 ID/이메일 명단 입력 (10분)
  2. 7주 단계 템플릿 선택 또는 커스텀(기획서 양식 / 목차 양식 / 주간 원고 분량) 설정 (15분)
  3. 매주 일요일 22시 카톡 알림톡 자동 발송("이번 주 과제는 X, 제출 마감 일요일 23시") → 수강생 제출 링크 클릭 → 폼 제출
  4. 코치 대시보드: 수강생 10명 진도 한 화면 ("3명 완료 / 5명 진행중 / 2명 1주 미제출") + 미제출자 자동 리마인드 카톡
  5. 제출물에 AI 1차 피드백 자동 생성("기획 1챕터 분량 부족 + 어조 일관성 OK") → 코치가 최종 코멘트 한 줄 추가 후 발송
- **수익 모델**:
  - 무료: 1기수 5명까지 (베타)
  - 코치 스타터: **월 3.9만원** (수강생 10명까지, 카톡 알림톡 500건 포함)
  - 코치 액티브: **월 9.9만원** (수강생 30명, 카톡 1500건, AI 피드백 무제한)
  - 코칭 기관 B2B: **월 29만원** (수강생 100명, 강사 5인 협업, 화이트라벨)
  - 결제: 토스페이먼츠 + 카카오비즈니스 알림톡 발송비 별도 정산(건당 9-15원, 마진 4-6원)
- **시장 규모 추정**:
  - 1차 자산: 민티 본인 즉시 결제 + 위너책쓰기 졸업생 중 코치 전환자 5-10명 + 행글라이터 구독자 중 책쓰기/AI 코치 10명 = **20명**
  - Year 1 결제율 60%(민티 보장) = 12명 × 평균 6만원 = **월 72만원** (ARR 864만원)
  - Year 2: 한국 1인 책쓰기 코치 + 1인 AI 강사 = 추정 **1000명** 침투 5% = 50명 × 6만원 = 월 300만원
  - 기관 B2B (한책협 같은) 2-3개 × 29만원 = 월 60-90만원
  - **Year 2 합계 추정: 월 400-500만원 (ARR 5000만+) + 알림톡 마진 별도**
- **차별성 한 줄**: "책쓰기 7주 단계별 산출물(기획→목차→탈고→KDP) 특화 템플릿 + 한국 카톡 알림톡 + AI 1차 피드백 통합. Notion DB + Disco/UpCoach + Zapier 조합으로도 비개발자 불가능."
- **빌드 복잡도**:
  - V4 R7 MVP: 단일 정적 HTML 데모 (코치 입장 시뮬레이션 화면 + 수강생 진도 카드 + AI 피드백 샘플 출력 - 실제 발송 X)
  - Phase 2: 카카오비즈니스 알림톡 API + Supabase + 토스페이먼츠 (1-2개월)
  - Phase 3: AI 피드백 학습(코치 본인 어조)

## 아이디어 #3: "유튜브 채널 1개 = 책 1권 자동 변환 + 출간 백오피스 (영상→책 컨버터)"

유튜버가 자기 채널 URL 또는 영상 50편 파일 업로드 → AI가 자막 추출 → 주제별 클러스터링(목차 자동) → 챕터별 원고 정리(말투 → 문체 변환) → 표지 시안 5종 + EPUB/KDP 업로드 패키지 + 책 마케팅 콘텐츠(아이디어 #1과 연동 가능) 생성. 유튜버는 50편 영상 자산을 책 1권 + 인세 + 강의 부가 매출로 전환.

- **타깃 1차 사용자**: 행글라이터 채널 본인(영상 100편+ 누적, 책 변환 가능) + 위너책쓰기 졸업생 중 유튜브 운영자(다수) + AI/글쓰기/콘텐츠 유튜버 (한국 1만+ 추정)
- **핵심 플로우 3-5단계**:
  1. 채널 URL 또는 영상 50편 자막 파일(.srt/.txt) 업로드 (10분)
  2. AI가 자막 통합 → 주제 클러스터링 자동(목차 12-15장 도출) + 사용자 검토/수정 (20분)
  3. 챕터별 원고 자동 생성(말투 보존 + 문체 다듬기 + 챕터당 5000-8000자) → 사용자가 챕터별 수정 (1-2주 작업 - AI가 80% 초안)
  4. 표지 시안 5종 + 책 메타 정보(부제 / 책 소개 / 저자 소개) 자동 + EPUB 변환 + KDP 업로드 가이드
  5. (연동) 아이디어 #1 작가 마케팅 OS로 자동 연결 → 출간 후 180일 캘린더 시작
- **수익 모델**:
  - 무료: 영상 10편 변환 + 챕터 3개 미리보기(워터마크) → 결제 시 잠금 해제
  - 1회권: **9.9만원** (영상 50편까지 + EPUB 1권 + 표지 시안 5종)
  - 작가 연간권: **월 1.9만원** (책 무제한 + 영상 무제한 + 표지 무제한)
  - 출판사 B2B: **책당 50-100만원** (인기 유튜버 책 출간 대행 - 출판사가 유튜버 영입 + 도구 사용)
- **시장 규모 추정**:
  - 1차 자산: 민티 본인(즉시 9.9만원 + 사례 콘텐츠) + 위너책쓰기 졸업생 중 유튜버 30명 + 행글라이터 구독자 중 콘텐츠 누적 채널 200명 = **230명**
  - 1회권 결제율 8%(높은 단가) = 18명 × 9.9만원 = **첫 분기 매출 178만원**
  - Year 1 누적: 분기당 18명 × 4 = 72명 = 712만원 (1회권만)
  - 연간권 전환 30% = 22명 × 12개월 × 1.9만원 = 500만원/년 (continuing)
  - Year 2: 한국 유튜브 1만+ 구독 채널 추정 5000개, 침투 0.5% = 25개 × 9.9만원 = 247만원/분기
  - 출판사 B2B 시즌 5-10건/년 × 70만원 = 350-700만원
  - **Year 2 합계 추정: ARR 3000-5000만원**
- **차별성 한 줄**: "유튜브 자막 50편 → 책 1권 + KDP 업로드 + 출간 후 마케팅 자동 연결을 한 도구가. Transkriptor는 자막만, Inkfluence는 프롬프트만, Whisper+ChatGPT 조합은 비개발자 불가."
- **빌드 복잡도**:
  - V4 R7 MVP: 자막 .srt 텍스트 5-10편 paste → AI가 목차 자동 + 챕터 1-2개 샘플 원고 출력(단일 HTML + Anthropic API)
  - Phase 2: 유튜브 자막 API 자동 가져오기 + EPUB 출력 + KDP 가이드(2-3개월)
  - Phase 3: 표지 시안 AI 생성(Recraft/Ideogram API) + 아이디어 #1 연동
- **R1 출처**: pain.md #1 (출간 후 마케팅) 페어 + pain.md #7 (콘텐츠 아이디어 고갈 - 영상 100편이 이미 답) + utility.md #8 (유튜브 영상 → 전자책 원고) + fresh.md #3 (AI Ghostwriter Cognitive Mirror)

## 아이디어 #4: "1인 콘텐츠 마케팅 대행 자동 리포팅 + 영업자료 OS (B2B 대행사 풀스택)"

1인 대행이 클라이언트 인스타/유튜브/네이버 블로그 채널 연결 → 매월 1일 자동 데이터 수집(도달/저장/DM/유입) → 한국어 자연어 인사이트 자동 작성("이번 달 인스타 도달 +32%, 그 중 카드뉴스 5편이 73% 기여") → 클라이언트 브랜딩 PDF 리포트 자동 생성 → 카톡/메일 자동 발송. **추가**: 신규 영업 시 "타겟 회사 인스타 분석 + 경쟁사 비교 + 운영 시 6개월 예측" 영업 PPT 1클릭 생성.

- **타깃 1차 사용자**: 민티 본인(우리집인테리어디자인 대행 운영) + 1인 콘텐츠 마케팅 프리랜서 + 소규모 콘텐츠 에이전시(2-5인) + 인테리어 회사 본인 마케팅 운영자
- **핵심 플로우 3-5단계**:
  1. 클라이언트 등록 → 인스타/유튜브/네이버 블로그 채널 연결(OAuth - 메인 Claude가 설정 가이드 영상 제공)
  2. 매주 자동 데이터 수집(인스타 그래프 API + 유튜브 데이터 API + 네이버 블로그 RSS)
  3. 매월 1일 한국어 인사이트 자동 작성 + 클라이언트 브랜딩 PDF 생성(로고/색상 자동 적용) → 카톡/메일 자동 발송
  4. (영업 자료 모드) 신규 클라이언트 후보 회사 인스타 ID + 업종 입력 → 경쟁사 5개 자동 분석 + 6개월 운영 시 예측 KPI + 영업 PPT 20장 1클릭 생성

## 아이디어 #5: "강사 PPT + 워크북 + 강의 후 복습 자료 + Q&A FAQ를 강의 1회당 1클릭 묶음 생성 (강사 부교재 OS)"
