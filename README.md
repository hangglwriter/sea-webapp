# 💬 카톡방 정치 시뮬레이터

> **보내기 전, 4명이 어떻게 답할지 미리 보세요.**

시댁어머니·직장상사·학부모회·베프 4명이 그 카톡을 받았을 때 어떻게 답할지 동시에 시뮬레이션합니다. 카톡 말풍선 그대로 캡처돼서 인스타 스토리에 바로 박을 수 있어요.

- 라이브: https://sea-webapp.pages.dev

## 차별화 한 줄

**카카오 카나나**는 받은 톡에 1대1 답장 추천. 카톡 안에서만 작동, 자체 광고 X.
**ChatGPT**는 1명의 GPT가 답. 4명 동시 X, 카톡 말풍선 X, 스샷 자체 광고 X.
**이 앱**은 **보내기 전** 4명 동시 시뮬. **카톡 밖**에서 작동 (스샷 → 인스타/단톡 = 자체 광고).

## 사용법

### 1. API 키 발급 (1회만)
1. [Anthropic Console](https://console.anthropic.com/settings/keys) 접속 → "Create Key"
2. `sk-ant-...` 형태 키 복사
3. 사이트 우상단 `⚙ API` 버튼 → 붙여넣고 저장 (브라우저 localStorage만, 운영자 X)

> API 키는 운영자가 보거나 저장하지 않습니다. 100% 본인 브라우저에만 저장됩니다.

### 2. 시뮬 실행
1. 답장 받고 싶은 4명 선택 (시댁어머니/직장상사/학부모회/베프/남친·여친/가족 단톡장 중)
2. 보내려는 카톡 메시지 입력 (1-3 문장)
3. **🚀 시뮬 시작**
4. 4명 답장이 카톡 말풍선으로 동시 출력

### 3. 공유
- **📥 이미지 저장**: 결과 PNG 다운로드
- **📱 인스타 스토리용 (9:16)**: 스토리 비율로 다운로드
- **📋 텍스트 복사**: 단톡에 붙여넣기

## 정신건강 가드레일

- 자해/혐오 키워드 자동 차단
- 입력 텍스트 24시간 후 자동 삭제 (localStorage)
- 성인 18+ 전용
- 운영자는 사용자 메시지/응답을 받지 않습니다 (서버 0대, 100% 브라우저)
- 위기 상담: **1393 (자살예방상담)**

## 기술 스택

- 정적 HTML + Vanilla JS (빌드 X)
- Tailwind CSS (CDN)
- html2canvas (이미지 다운로드)
- Anthropic Claude API (claude-haiku-4-5)
- Cloudflare Pages 정적 호스팅

### 로컬 실행

```bash
# 정적 파일이라 그냥 index.html 열어도 작동
# 또는 간단한 서버
python -m http.server 8000
# → http://localhost:8000
```

### 배포

Cloudflare Pages에서 GitHub repo `hangglwriter/sea-webapp` 연결만 하면 자동 빌드.
빌드 명령: 없음. 출력 디렉토리: `/` (루트)
