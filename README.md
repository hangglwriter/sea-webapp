# 🎯 Persona Lab - 내 채널 전용 AI 청중 100명

> **썸네일·제목 5종을 사전 검증.** 한국 페르소나가 클릭/스킵 + 이유를 답하고, 실제 데이터로 자가 학습하는 채널 전용 AI 청중. 6개월 후 다른 채널주는 못 베끼는 lock-in 자산.

## 🚀 사용법 (3분이면 끝)

### 1단계: Anthropic API 키 발급 (1분)

1. [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys) 접속
2. 구글 계정으로 로그인 (없으면 회원가입 1분)
3. 우측 상단 "Create Key" 클릭 → 이름 아무거나 → 복사
4. ⚠ 키는 `sk-ant-` 로 시작. 한 번만 보이니까 메모장에 저장 추천

**비용**: 한 번 시뮬에 약 0.05-0.15달러 (한화 70-200원). 신규 가입 시 5달러 무료 크레딧 있어서 30-50회 무료.

### 2단계: 페이지에서 키 입력

- 우측 상단 `⚙ API` 버튼 → 키 붙여넣기 → 저장
- 키는 당신 브라우저에만 저장 (운영자 절대 못 봐요)

### 3단계: 8단계 플로우

1. **랜딩** (10초): "🚀 1분 만에 시작하기" 클릭
2. **채널 톤** (30초): 채널 한 줄 설명 (예: "AI/글쓰기 1인 크리에이터 채널, 40대 여성 톤") + 자막 3편 paste (선택)
3. **페르소나 10명** (5초): 한국 페르소나 자동 생성 + 채널 매칭 코멘트 표시
4. **시안 5종 paste** (1분): 썸네일 텍스트 / 제목 후보 5개 입력
5. **AI 평가** (15-25초): 페르소나 10명이 시안마다 클릭/스킵 + 이유 답변. 클릭률 % + 워드클라우드 표시
6. **보정 시연** (90초): "실제 데이터 입력" 버튼 → 페르소나 자가 토론 + 가중치 보정 시각화
7. **6개월 진화 시뮬** (6초): 정확도 + 청중 수 진화 그래프 가속
8. **베타 신청**: 이메일 + 채널 입력 → 무료 베타 등록

## ❓ FAQ

### Q1. 진짜 무료인가요?
**A.** 페이지는 무료. 단 Anthropic API 호출은 본인 키 비용. 한 번 시뮬에 약 100원 내외. 신규 가입 5달러 무료 크레딧으로 30-50회 가능.

### Q2. 왜 회원가입이 없죠?
**A.** Phase 1 MVP라서. 회원가입 X = 빠른 검증. Phase 2에서 토스페이먼츠 정기결제 + 페르소나 100명 + YouTube Analytics 자동 연동 예정.

### Q3. 페르소나 10명이 정말 한국 청중을 반영하나요?
**A.** 한국 시드 10명 (20대 여대생 / 30대 워킹맘 / 40대 자영업자 / 50대 부장 / 60대 은퇴자 + 알파 5명) + Claude API가 채널 톤 매칭. 100% 정확 X but **사전 검증 도구로 의미**. 진짜 lock-in은 실제 게시 후 데이터 입력 → 자가 보정 (Phase 2).

### Q4. 캔바+ChatGPT로 못 하나요?
**A.** ChatGPT에 "이 썸네일 5개 평가해줘" 가능. 단 (1) 한국 페르소나 시드 X (2) 시안별 클릭률 % X (3) 페르소나별 응답 비교 X (4) 6개월 자가 학습 X. 우리만의 차별점.

### Q5. TubeBuddy / Thumblytics / Ask Rally랑 뭐가 달라요?
**A.**
- **TubeBuddy / Thumblytics**: 1회성 "AI 점수 80점" 추상 점수만. 한국어 X. 채널 톤 X.
- **Ask Rally**: 영문 + B2B 대기업용 ($99+/월). 1인 크리에이터 가격 부담.
- **우리**: 한국어 + 채널 톤 매칭 + 실제 데이터 자가 학습 + 6개월 lock-in (Phase 2).

### Q6. API 키 안전한가요?
**A.** 브라우저 localStorage에만 저장. 우리 서버 X (서버 자체가 없어요 - Cloudflare Pages 정적 호스팅). 키 노출 걱정되면 Anthropic console에서 키 한도 설정 + 주기적 rotation 추천.

### Q7. 모바일에서 잘 되나요?
**A.** 한국 90% 모바일 사용자라서 모바일 우선 디자인. iPhone Safari / Android Chrome 테스트 완료.

### Q8. 어디에 쓰면 좋아요?
**A.**
- **유튜브 썸네일 텍스트** 5종 사전 검증
- **인스타 카드뉴스 카피** 5종 비교
- **블로그 제목** A/B 후보 5종
- **유튜브 영상 제목** 5종
- **이메일 뉴스레터 제목** 5종
- **위너책쓰기 강의 카피** 5종 (민티 본업)
- **인테리어 회사 카드뉴스 카피** (B2B 콘텐츠 마케팅 대행 즉시 적용)

## 📅 로드맵

### Phase 1 (이미 됨) - MVP
- 단일 정적 HTML + Tailwind CDN + Anthropic API
- 페르소나 10명 시뮬 (API 1회 호출)
- 시안 5종 평가 + 보정 시연

### Phase 2 (1-2개월) - 실제 lock-in
- Supabase 사용자 DB + 토스페이먼츠 정기결제
- 페르소나 100명 확장 (batch API)
- YouTube Analytics 자동 import (OAuth) → 자가 보정 학습 진짜 시작
- 채널 전용 청중 자산 저장 (6개월 lock-in)
- 카톡 알림 (주간 보고)

- 인스타 인사이트 CSV → 커스텀 페르소나
- 댓글 emotion 분석
- 화이트라벨 (대행사 도메인 + 로고)
- 영문 서비스
