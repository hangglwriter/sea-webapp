## 영역 #1: 7주 책쓰기 코칭 자동 매니저 (위너책쓰기 OS)

- **누가 왜 필요**:
  - **1순위**: 위너책쓰기 운영자 민티 본인. 7주 동안 수강생 1:1 코칭 3회 + 매주 단계별 가이드라인 + 카페 운영 + 전자책 제작 강의를 카톡/노션/구글폼/캘린더 분산 운영. 한 기수 5-10명만 받아도 매주 "이번 주 누가 어느 단계인지" 수동 추적.
  - **2순위**: 한국책쓰기강사양성협회(한책협) 같은 책쓰기 코치, MKYU 남인숙 책쓰기 아카데미, 홍순성 AI 책쓰기 강사 등 1인 책쓰기 코치 100+명 추정 (한국 시장).
- **기존 도구가 못하는 것**:
  - **Notion**: DB는 가능하지만 "7주 단계 = 기획→목차→1주차 원고→2주차 원고...→탈고→표지→KDP 업로드" 단계별 산출물 검증 + 카톡 알림 + 코치 멘트 자동 발송이 안 됨. 노션은 정적 DB.
  - **클래스101 크리에이터센터**: 플랫폼 종속(수수료) + "단계별 산출물 첨삭" 기능 없음. 영상 강의 진도율만 추적.
  - **Disco/UpCoach (글로벌)**: 영어 인터페이스 + 한국 카톡 알림 불가 + 책쓰기 특화 템플릿 없음 (일반 cohort LMS).
  - **인플런/탈잉/클래스유**: 강의 판매 플랫폼이지 "1:1 코칭 진도 관리"가 아님.
  - **캔바+ChatGPT 5분 컷?**: 불가능. 이건 워크플로우+상태머신+다중채널 통신.
- **클론 검증** (WebSearch 5회+):
  - 한국: 위너책쓰기 자체 시스템 = "행글라이터 카페 + 1:1 코칭"으로 수동. 한책협도 자체 자동화 X. **책쓰기 특화 SaaS 0건 확인**.
  - 글로벌: UpCoach, Simply.Coach, Disco - cohort 코칭 일반 도구. **책쓰기 단계별 산출물 (기획→목차→초고→탈고→KDP) 특화 0건**.
  - Reedsy: 작가-편집자 매칭 마켓플레이스 (코칭 운영 X).
- **수익 모델 단서**:
  - **B2B SaaS**: 책쓰기 코치 1인당 월 3-5만원 (수강생 10명 이하). 코치 50명만 모아도 월 150-250만원.
  - **상위 플랜**: 수강생 11-30명 = 월 8-12만원. 인플런 작가 등 중규모.
  - **1차 사용자 즉시 결제**: 민티 본인 = 즉시 결제. 행글라이터 구독자 중 책쓰기 코치 5-10명 확보 가능 추정.
- **1차 사용자 자산 모집**:
  - 민티 본인이 베타 유저 #1 (위너책쓰기 다음 기수 도구로 운영) = 즉시 사용 사례 + 회고 콘텐츠.
  - 행글라이터 유튜브 = "AI로 책쓰기 코칭 자동화" 영상 1편으로 책쓰기 코치 페르소나 직격.
  - 위너책쓰기 졸업생 중 "나도 코칭 하고 싶다" 트랙 = 자연 파이프라인.
- **출처**:
  - https://www.storywinner.co.kr/winner-writing (위너책쓰기 7주 구조)
  - https://simply.coach/blog/best-coaching-automation-software-2026/ (글로벌 코칭 SaaS 리스트, 책쓰기 특화 X 확인)
  - https://www.disco.co/blog/cohort-based-lms-platforms-2026 (cohort LMS 비교, 책쓰기 templating 0건)

## 영역 #2: 출간 후 6개월 마케팅 자가증식 엔진 (전자책 저자용)

- **누가 왜 필요**:
  - **1순위**: 전자책 출판한 1인 저자 (KDP/리디북스/교보/yes24 알라딘). 한국에서 매년 자가출판 수천 권. 출간 직후 1-2주만 SNS 홍보 → 그 후 "잊혀짐". 6개월간 일관된 마케팅 운영 불가능 (혼자라서).
  - **2순위**: 1인 출판사 (1인이 5-20권 운영). 신간 낼 때마다 인스타/유튜브/광고/온라인서점 상세페이지 콘텐츠 무수히 필요. 디자이너 부족 + 외주 부담.
  - **3순위**: 위너책쓰기 졸업생 (탈고 + KDP 업로드 했지만 마케팅에서 막힘 - 민티 가장 자주 듣는 페인).
- **기존 도구가 못하는 것**:
  - **캔바+ChatGPT**: 카드뉴스 1개 만드는 건 5분. 하지만 "책 1권 → 6개월 = 180일 콘텐츠 캘린더 + 인용구 100개 + 챕터별 카드뉴스 + 독자 후기 자동 수집 + 알라딘 yes24 SEO 키워드 + 신간 발견 알림"은 5분 X. 1인이 운영 불가능.
  - **Buffer/Metricool/Mirra**: 예약 발행 도구. "책 본문에서 인용구/카드뉴스/유튜브 쇼츠 스크립트 자동 추출 + 6개월 캘린더 생성"은 안 함.
  - **Mailchimp/Stibee**: 뉴스레터 발송. 책-독자 관계의 longitudinal 자동화 (출간 D+7, D+30, D+90 시점별 다른 메시지)는 수동 설계 필요.
  - **출판사 자체 마케팅 매니저**: 1인 저자는 못 가짐.
- **클론 검증**:
  - 한국: 가비아 AI 에디터 = 상세페이지 자동 생성 (단발성). **책 1권 → 6개월 콘텐츠 캘린더 도구 0건**.
  - 글로벌: Publer/Publishing.ai = 책 쓰기 자체. 출간 후 마케팅 자동화는 글로벌도 약함. Author Marketing Club (영어권) = 강의 위주, 도구 X.
  - 인디 해커: indiehackers.com "Newsletter OS" $20k/3개월 사례 - 작가용 SOPs는 있지만 한국 시장 변형 0건.
- **수익 모델 단서**:
  - **개인 작가 플랜**: 월 1.9-2.9만원 (책 3권까지 등록).
  - **1인 출판사 플랜**: 월 9.9만원 (책 20권까지).
  - **출판사 B2B**: 월 30-50만원 (책 100권+, 마케터 협업).
  - 한국 자가출판 시장 = 2028년 2조 추정. 출간 후 마케팅 페인은 거의 100%.
- **1차 사용자 자산 모집**:
  - 위너책쓰기 졸업생 즉시 모집 (한 기수당 5-10명, 누적 50+명 추정).
  - 행글라이터 "전자책 출판 6개월 마케팅 자동화" 영상 = 졸업생 + 출판 관심층 직격.
  - 콘텐츠 마케팅 대행 영업 도구로도 활용 (B2B 영업 자료).
- **출처**:

  - https://carat.im/blog/ai-book-marketing-tips (책 한 권 → 홍보 콘텐츠 무제한 - 워크플로우는 수동)
  - https://aieditor.gabia.com/ (가비아 AI 에디터 - 단발성 상세페이지만)

## 영역 #3: 1인 콘텐츠 마케팅 대행사 클라이언트 리포팅 자동화 (B2B 대행 OS)

- **기존 도구가 못하는 것**:
  - **Metricool/Mirra/Hootsuite**: 자체 리포트 PDF는 만들지만 "**클라이언트별 브랜딩 + 한국어 자연어 인사이트 + 카톡/메일 자동 발송 + 캡션 ROI 분석**" 한 번에 안 됨. Hootsuite $99/월 = 1인 대행에 부담.

  - **구글 Looker Studio**: 한국어 자연어 인사이트 X. 인스타 API 연결 복잡 (비개발자 못함).
  - **GA4**: 블로그 트래픽만. 인스타+유튜브+블로그 통합 X.
  - **Datakit (한국)**: 광고 ROAS 위주, 콘텐츠 마케팅 인사이트 X.
- **클론 검증**:
  - 한국: 디스럽트/아이디어키 = 대행사 자체 운영 (외주). **1인 대행용 SaaS 0건**.
  - 글로벌: AgencyAnalytics ($79-239/월, 영어), Whatagraph ($199+/월). **한국어 자연어 인사이트 + 카톡 발송 0건**.
  - Disquiet에 "1인 마케터" 도구 활발 (lever.me, syncly 등) 있지만 대행사 클라이언트 리포팅 자동화 특화 X.
- **수익 모델 단서**:
  - **프리랜서 플랜**: 월 1.9만원 (클라이언트 3개까지).
  - **소규모 대행 플랜**: 월 5.9만원 (클라이언트 10개까지).
  - **에이전시 플랜**: 월 19.9만원 (클라이언트 30개까지, 화이트라벨링).
  - 한국 콘텐츠 마케팅 대행사 = 수만 개. 1% 침투 = 수백 개 = 월 수천만원.
