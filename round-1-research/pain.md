## 페인 #1: "전자책 썼는데 안 팔린다" - 출간 후 마케팅 절벽

- **누가**: 위너책쓰기 7주 코칭 졸업생 + 1인 자가출판 작가 (부크크/유페이퍼/리디 등 출판은 했으나 마케팅 백지)
- **얼마나 자주/심각**: **매일 + 만성 우울**. 출간 첫 1-2주 친구·가족 매수 후 판매 절벽. 한 작가는 "출간하고 한 달 뒤 통계 보니 7권 팔렸다, 그 중 4권은 어머니"라는 솔직 후기. r/selfpublish 서브레딧 투표 결과 **"discoverability(노출/발견 가능성)이 인디 작가 1순위 페인"**. 한국 출판시장 2023년 매출 4.8% 감소 / 영업이익 8.9% 감소로 신인일수록 노출 더 어려움
- **현재 해결책**:
  - 인스타·브런치·블로그 직접 운영 (시간 hell, 책 쓴 사람이 마케팅까지)
  - 부크크/유페이퍼는 메이저 플랫폼 유통 X (부크크 마켓 내부 한정)
  - 출판 마케팅 대행 (월 50-100만 원, 신인 작가 ROI 마이너스)
  - 한계: **"책 한 권 = 한 번 끝"이 아니라 "출간 후 6개월 매일 마케팅이 진짜 일"인데 지원 도구 없음**
- **수익 모델 단서**:
  - 작가 1인당 월 2-5만 원 구독 (출간 후 90일 자동 마케팅 워크플로우)
  - 위너책쓰기 졸업생 = 매년 50-100명 자동 풀 (LTV 6개월 × 3만원 = 18만원)
  - B2B: 1인 출판사·소형 출판사 월 30-50만 원 (책당 마케팅 자동화)
- **1차 사용자 자산 모집 가능성**: **최상.** 위너책쓰기 졸업생 그룹 + 행글라이터 구독자 중 "책 쓰고 싶다/썼다" 비율 높음. 50-100명 즉시 모집 가능. 민티 본인이 출판사 운영 = 도그푸딩 가능
- **출처**:
  - [r/selfpublish 분석 - discoverability 1순위 페인](https://www.ingramspark.com/blog/reddit-for-self-published-authors-building-trust-before-selling-books)
  - [출판N - 2023년 출판시장 매출 4.8% 감소](https://nzine.kpipa.or.kr/sub/inside.php?ptype=view&idx=905)
  - [부크크 자가 출판 솔직 후기](https://brunch.co.kr/@manofpeace/119)

## 페인 #2: "7주 안에 책 한 권" 완주 실패 - 챕터별 진도 무너짐

- **누가**: 위너책쓰기 수강생 + 글ego·위올라잇 등 유사 6-8주 책쓰기 코칭 수강생
- **얼마나 자주/심각**: **주간 + 심각**. 7주 코칭 시작 → 1-2주차 의욕 → 3-4주차 챕터 막힘 → 5-6주차 슬럼프 → 마지막주 벼락치기 또는 포기. 졸업률 추정 30-50%. 책쓰기 슬럼프 극복법이 한국 블로그 검색 상위 결과 = 보편 페인 증명
- **현재 해결책**:
  - 카톡방 매일 인증 (강사 1인이 40명 관리, 강사도 번아웃)
  - 워드/한글 파일 챕터 폴더 분리 (진도 안 보임, 동기 부여 X)
  - 노션 트래커 셀프 구축 (비개발자 진입장벽)
  - PenCake·울리시스 등 글쓰기 앱 (챕터 구조는 되나 코칭 연동 X, 동기부여 X)
  - 한계: **"오늘 몇 단어 썼는지 / 마감까지 몇 챕터 남았는지 / 강사가 어디 막혔는지"가 한 화면에 없음**
- **수익 모델 단서**:
  - 수강생당 월 1-2만 원 (코칭비에 포함되어 강사가 결제 = B2B SaaS)
  - 위너책쓰기 1기수 30명 × 7주 = 210만 원
  - 글로벌 Trackbear 사례 (워드카운트 트래커, 인디 작가 타깃) = 시장 검증됨
- **1차 사용자 자산 모집 가능성**: **최상.** 위너책쓰기 다음 기수 베타 즉시 가능. 민티가 강사로 매주 사용
- **출처**:
  - [글쓰기 슬럼프 극복법](https://wordcreeper.com/%EA%B8%80%EC%93%B0%EA%B8%B0-%EC%8A%AC%EB%9F%BC%ED%94%84-%EA%B7%B9%EB%B3%B5/)
  - [Trackbear 글로벌 인디 작가 트래커](https://scribecount.com/author-resource/writing-tools-for-authors/wordcount-trackers)
  - [위너책쓰기 공식](https://www.storywinner.co.kr/winner-writing)

## 페인 #3: 콘텐츠 1개 → 멀티 플랫폼 재활용 시간 hell (1인 크리에이터)

- **누가**: 행글라이터 구독자 같은 AI/글쓰기/콘텐츠 1인 크리에이터 + 민티 본인
- **얼마나 자주/심각**: **매일 + 시간 도둑**. 유튜브 영상 1개 만들면 → 쇼츠 3개 잘라야 / 블로그 정리 / 인스타 카드 / 스레드 / 뉴스레터까지 6-8개 변환. 한 영상당 후작업 4-6시간. 글로벌 Billion Dollar Boy 2025 조사: **크리에이터 52% 번아웃, 그 중 40%가 "creative fatigue (콘텐츠 변환 피로)"가 원인**
- **현재 해결책**:
  - Vrew / Alphacut / AICO (영상 → 쇼츠 자동) - 영상만 됨, 글/카드는 X
  - 골든래빗 책 "AI 쇼츠 만들기 22제" (자동화 가능 증거 = 페인 검증)
  - 노션 콘텐츠 캘린더 (계획만 됨, 실제 변환은 손)
  - 한계: **"한 번 만들면 멀티 플랫폼 자동 분배 + 톤앤매너 유지"가 안 됨. Repurpose.io 등 글로벌은 있으나 한국어/네이버 블로그/스레드 안 됨**
- **수익 모델 단서**:
  - 크리에이터당 월 3-5만 원 (영상 1개 → 6개 채널 자동 변환)
  - 행글라이터 구독자 풀 = 즉시 시드 사용자
  - B2B: 1인 사업자 콘텐츠 마케팅 월 10-20만 원
- **1차 사용자 자산 모집 가능성**: **상.** 행글라이터 구독자 중 크리에이터 비율 + 위너책쓰기 졸업생 중 채널 운영자 100-300명 추정
- **출처**:
  - [Billion Dollar Boy 2025 - 크리에이터 52% 번아웃](https://painonsocial.com/blog/content-burnout-reddit)
  - [AI 쇼츠 자동화 22제 - 시장 수요 증명](https://goldenrabbit.co.kr/books/9791194383673)
  - [솔로프리너 콘텐츠 번아웃](https://www.flowdevs.io/blog/post/beating-content-burnout-a-weekly-system-for-solopreneurs-who-need-consistency)

## 페인 #4: AI로 쓴 글 "AI 티 남" - 네이버 노출 페널티 + 독자 거부감

- **누가**: ChatGPT/Claude로 블로그·뉴스레터 쓰는 1인 크리에이터 + 민티 강의 수강생 (비개발자 AI 활용)
- **얼마나 자주/심각**: **매주 + 의심증 유발**. AI로 글 빨리 쓰면 좋은데 "이거 너무 AI 같다", "네이버 검색 안 잡힐 것 같다", "독자가 떠날 것 같다" 불안. GPT킬러·Isgen 등 AI 감지기 한국 블로그 글 검색 결과 상위 = 사람들이 매일 검색
- **현재 해결책**:
  - Undetectable.ai / GPT킬러 우회 도구 (글로벌 위주, 한국어 부자연)
  - "사람 같은 글" 재작성 프롬프트 (매번 다시 작성, 시간 hell)
  - 그냥 손으로 다시 쓰기 (AI 쓰는 의미 사라짐)
  - 한계: **"내 톤앤매너 학습 + AI 작성본을 내 글체로 자동 변환 + AI 감지 우회 + 네이버 SEO 친화"가 한 번에 안 됨**
- **수익 모델 단서**:
  - 크리에이터당 월 2-3만 원 (한국어 특화 humanizer + 내 톤 학습)
  - 강의 부가 상품: "민티 강의 + AI 글 변환기 1년" 패키지
  - 글로벌 Undetectable.ai = $9.99/월, 한국어 시장 빈자리
- **1차 사용자 자산 모집 가능성**: **상.** 민티 AI 강의 수강생 + 행글라이터 구독자 즉시 베타. 그러나 "AI 들킴" 도구는 도덕성 시비 위험 (R3 attacker가 짚을 듯)
- **출처**:

## 페인 #5: 자영업자 인스타·블로그 "매일 올릴 거 없음" (B2B)

- **누가**: 인테리어 회사 같은 콘텐츠 마케팅 대행 클라이언트 (민티 현 클라이언트) + 식당·미용실·소상공인
- **얼마나 자주/심각**: **매일 + 사업 직격**. 인테리어 사장은 "현장 관리·견적·CS도 바쁜데 인스타에 뭘 매일 올리지?" 막막. 블로그 시작했다가 1-2개월 만에 포기 비율 매우 높음. 결국 월 50-200만 원에 대행사 위탁 → 사장 입장에서 비용 부담
- **현재 해결책**:
  - 콘텐츠 마케팅 대행사 위탁 (월 50-500만 원, 소상공인 부담)
  - 사장 직접 운영 (포기율 80%+)
  - ChatGPT + Canva 손으로 (비개발자 매번 새로 = 결국 포기)
  - 한계: **"시공 사진 N장 던지면 → 인스타 캡션 7개 + 블로그 1개 + 릴스 대본 자동 생성 + 업로드 일정"이 통합 안 됨**
- **수익 모델 단서**:
  - 자영업자당 월 5-10만 원 (대행사보다 1/10 가격, 사장 직접 운영 가능)
  - 민티 인테리어 클라이언트 = 1호 베타 + 케이스 스터디
  - 동일 업종 클라이언트 5-10곳 모이면 즉시 손익분기 (월 50만 원 × 5 = 250만 원)
- **1차 사용자 자산 모집 가능성**: **중상.** 민티가 현재 인테리어 회사 대행 중 = 즉시 1호 검증. 추가 모집은 콜드 영업 필요 (위너책쓰기/행글라이터 자산 활용도 낮음). B2B는 인입 채널 별도 설계 필요
- **출처**:
  - [인테리어 블로그 마케팅 어려움](https://www.bizer.co.kr/community/detail?index=163)
  - [콘텐츠 마케팅 대행 비용 월 50-500만원](https://locaposting.com/blog/blog-marketing-cost)
  - [회사 규모별 마케팅 예산 월 100만-5000만원](https://ballast.co.kr/insights/%EC%A1%B0%EC%A7%81-%EA%B7%9C%EB%AA%A8%EB%B3%84-%EC%BD%98%ED%85%90%EC%B8%A0-%EB%A7%88%EC%BC%80%ED%8C%85-%EC%98%88%EC%82%B0/)

## 페인 #6: 강의 수강생 카톡방 운영 - 강사 1인 번아웃

- **누가**: 위너책쓰기 강사 민티 + AI 강의·글쓰기 강의 1인 강사 (인프런·클래스101 X, 소수 정예 코칭)
- **얼마나 자주/심각**: **매일 + 강사 시간 hell**. 30-40명 단톡방 = 강사가 낮시간 상시 대기. 학생 질문 중복, 진도 체크 수기, 인증 추적 안 됨. 한 강사 인터뷰: **"단톡방 40명 = 강의 1개 운영 = 강사 풀타임"**. 카톡 채팅 강의 논란 기사도 등장
- **현재 해결책**:
  - 카톡 단톡방 (관리 hell)
  - 클래스팅·노션·디스코드 (수강생 진입장벽, 강사도 매번 셋업)
  - 자체 LMS 구축 (비개발자 불가)
  - 한계: **"카톡 편함 + 진도 자동 추적 + 강사 알림(누가 안 한지) + 졸업장 + 후기 자동"이 한 묶음 안 됨**
- **수익 모델 단서**:
  - 강사당 월 3-5만 원 (강의 1개 기준) 또는 수강생당 월 5천 원
  - 민티 = 위너책쓰기 + AI 강의 + 글쓰기 강의 = 본인 자산 풀 활용
  - 다른 1인 강사 (지피터스 등) 확장 가능
- **1차 사용자 자산 모집 가능성**: **상.** 위너책쓰기 다음 기수 즉시 베타. 민티 본인이 매일 사용

## 페인 #7: 1인 크리에이터 "콘텐츠 아이디어 고갈" + "주간 콘텐츠 캘린더 백지"

- **누가**: 행글라이터 구독자 (AI/글쓰기/콘텐츠 채널 운영자) + 민티 본인 (주간 리포트 매주 작성)
- **얼마나 자주/심각**: **매주 + 만성 스트레스**. 1년 차 유튜버 통계: 4년 뒤 40명 중 39명 채널 중단 = **97.5% 중단율**. 중단 원인 1위 = "콘텐츠 만드는 데 생각보다 엄청난 시간". 매주 월요일 "이번 주에 뭐 만들지?" 막막
- **현재 해결책**:
  - 유튜브 영감 탭 (일반적, 차별화 X)
  - 경쟁 채널 분석 수기 (시간 hell)
  - ChatGPT "아이디어 10개 줘" (얕음, 내 색깔 X)
  - 노션 캘린더 (계획 도구, 발굴 X)
  - 한계: **"내 채널 컨셉 + 최근 트렌드 + 시청자 데이터 + 경쟁사 신규 영상 + 내 과거 인기 영상 패턴"을 종합한 다음 주 7개 아이디어 자동 도출 X**
- **수익 모델 단서**:
