## 신생 카테고리 (총 7개)

### 카테고리 1: Embodied AI Companion (Co-Parent 메커니즘)

- **정의**: AI 캐릭터를 "혼자 키우는" 게 아니라 **2명+ 함께 공동 양육**. 캐릭터 성격이 두 사람 대화/선택의 누적으로 형성됨. 챗봇 X, Tamagotchi 진화형.
- **대표 사례**:
  - **Pengu (by Born)** / 2023년 출시, 2025년 9월 a16z·Accel $15M Series A / 글로벌 1,500만 사용자 / iOS+Android / https://apps.apple.com/us/app/friends-pengu-bao-mellow/id6462927800
  - **Tolan (by Portola)** / 2024 출시, 2025-02 $10M Seed / "embodied companion" (alien Tamagotchi)
  - **Friend pendant ($99 wearable)** / Avi Schiffmann / 2025년 1월 출하 / 항상 듣기 + AI 친구
- **왜 새로운가**: 1세대 AI 챗봇 = 1:1 대화. 2세대 = "**관계의 매개**". 두 사람이 같은 AI 캐릭터를 키우면서 자기들 관계도 깊어짐. 캔바+ChatGPT로 복제 불가 (지속성 + 멀티유저 상태 필요).
- **한국 진입 여부 (WebSearch 검증)**:
  - 한국어 출시? **N** (Pengu/Tolan 한국어 UI 미지원, 한국 앱스토어 .kr 페이지 별도 없음)
  - 한국 클론 존재? **N** (검색어: "AI 다마고치 함께 키우기" / "공동 양육 AI 펫" / "커플 AI 친구" 모두 0건. 한국에 있는 "Peppy: My Talking AI Pets" 등은 1인 챗봇형 - 메커니즘 다름)
  - 결론: **진짜 미진입 + 한국 클론 0**. 신선도 유효.
- **한국 페인 매칭**:
  - 1인 가구 804만 (36.1%), 절반(48.9%)이 "외롭다" 응답 (통계청 2025 사회조사)
  - **단, "혼자 외로움"보다 "관계 안에서 매개체 필요"가 더 맞는 매칭** - 한국 커플/모녀/친구간 "말로 못 하는 감정" 매개로 캐릭터 활용
  - 부모-자식 소통 (KAIST '액세스톡' 사례 - 자폐아 부모 소통, ACM CHI 2025 최우수논문 = **메커니즘 학술 검증됨**)
- **1인/작은 팀 빌드 가능?**: 부분적으로. Pengu는 결국 시리즈 A 받음. 1인 MVP는 가능 (캐릭터 + LLM + 멀티유저 상태). 단 캐릭터 디자인 IP가 핵심.

### 카테고리 2: Always-Listening Memory Layer (음성 메모리 펜던트/앱)

- **정의**: 하루 종일 음성 자동 캡처 → AI가 맥락 압축, 검색 가능한 "삶의 메모리". 회의록 도구가 아니라 **개인 라이프로그**.
- **대표 사례**:
  - **Limitless Pendant** / 2024 출시, **2025-12 Meta 인수** (https://techcrunch.com/2025/12/05/meta-acquires-ai-device-startup-limitless/)
  - **Friend pendant** / $99, 2025-01 출하
  - **Granola** / Christopher Pedregral (전 Google), 데스크톱/iOS 회의 노트, 다만 "회의" 좁은 버티컬
- **왜 새로운가**: 챗봇은 "내가 질문할 때만" 작동. Always-Listening은 **수동적 캡처 → 능동적 회상**. "어제 미팅에서 그 사람 이름 뭐였지?" 같은 페인을 0초에 해결. Meta 인수 = 카테고리 자체 검증.
- **한국 진입 여부 (WebSearch 검증)**:
  - 한국어 출시? **N** (Limitless/Friend 한국어 미지원, 한국 출하 정보 0)
  - 한국 클론 존재? **부분적** - 클로바노트/다글로/에이닷노트/티로 = 모두 **회의록 버티컬** (devocean.sk.com 비교 기사). **"일상 음성 라이프로그"** 카테고리는 한국 0건
  - 결론: 회의록 영역은 포화, **"일상 라이프로그"는 미진입**
- **한국 페인 매칭**:
  - 50대+ 두뇌 기억력 페인 (스토리위너 두뇌톡톡 사용자 타겟과 직접 매칭)
  - 1인 가구 800만, 70세+ 19.8% = "혼잣말/기억 보조" 시장 확정
  - 콘텐츠 크리에이터 (민티 자신 포함) 페인: "강의·인터뷰·아이디어 다 흘러감"
- **1인/작은 팀 빌드 가능?**: 소프트웨어만이면 Yes. 펜던트 H/W는 어려움. **모바일 백그라운드 녹음 + AI 압축**이 1인 MVP 답.

### 카테고리 3: AI Texting/Communication Coach (스크린샷 → 회신 추천)

- **정의**: 사용자가 대화 스크린샷 업로드 → AI가 맥락 분석 → 회신 문안 추천. 단순 챗봇 X, **"보낼 말 골라주는 코치"**.
- **대표 사례**:
  - **Rizz** / 2023 출시, 사용자 1,000만 (65% 남성, 18-25세) / 데이팅 회신 추천
  - **Myrah / MosaicChats** / 챗 히스토리 통째 업로드 → 관계 분석
  - **Mei (textmei.com)** / AI 관계 코치
  - **BestInterest / Parent Copilot / OurFamilyWizard ToneMeter** / **이혼 후 공동 양육 메시지 톤 필터** (BusinessWire 2024-10)
- **왜 새로운가**: 챗봇 = 답을 받음. Coach = **내가 보낼 말을 다듬어줌** (저자성 유지). 2025 Match 조사 = Gen Z 41%가 "연애 조언에 AI 사용".
- **한국 진입 여부 (WebSearch 검증)**:
  - 한국어 출시? **부분적** - Rizz는 한국 앱스토어 한국어 페이지 있음 (apps.apple.com/kr/app/rizz-ai-pickup-lines-wingman). **데이팅 영역은 진입 완료**
  - 미진입 영역: **이혼 후 공동 양육 메시지 톤 필터 (BestInterest 류)** 한국 0건. **부부/연인 갈등 메시지 필터** 한국 0건. **상사/부하 답장 톤 코치** 한국 0건.
  - 결론: **데이팅은 끝났지만 "갈등 상황 메시지 톤 필터"는 미진입**
- **한국 페인 매칭**:
  - 한국 이혼율 OECD 9위, 공동 양육 갈등 시장 잠재
  - 한국 직장 갈등 (워라밸/꼰대/갑질 등 문화 특수 페인)
  - 카톡 단톡방 정치 - "이 말 보내도 될까?" 페인이 글로벌보다 강함
- **1인/작은 팀 빌드 가능?**: Yes. LLM 프롬프트 엔지니어링이 핵심. 한국어 미세 뉘앙스가 진입 장벽이자 보호막.

### 카테고리 4: Grief Tech / Digital Afterlife (디지털 추모)

- **정의**: 고인 영상/음성/문자 데이터 → 대화 가능한 AI 아바타. 사진 한 장 X, **양방향 대화 가능한 디지털 분신**.

- **왜 새로운가**: 사진/영상 추모 → 양방향 대화. Black Mirror "Be Right Back" 비유 = 카테고리 자체가 윤리 논쟁 = **바이럴 보장**.
- **한국 진입 여부 (WebSearch 검증)**:

  - 한국 클론 존재? B2C 일반 소비자용 디지털 추모 앱 = **0건**. 일반인 1만원대 진입 안 됨.
  - 결론: **고가/오프라인은 있고 모바일 B2C는 미진입**
- **한국 페인 매칭**:
  - 제사 문화 (제삿날 = "보고 싶다" 정서 폭발 시점)

  - 한국 정서상 윤리 논란 = 보수 미디어 무료 PR 보장 (양가성)

- **⚠️ 주의**: 2Wai가 글로벌에서 22M 뷰 + 백래시 받은 게 5개월 전. **민티 채널 톤과 윤리 매칭 검토 필수**. researcher-pain·researcher-fun에 의견 청취 권장.

- **왜 새로운가**: 1:1 챗봇 피로감 → **여러 페르소나가 서로 다른 관점 제시**. 사용자가 "오늘 옷 뭐 입지" 물으면 AI 4명이 서로 다른 의견. **결정 보조 + 외로움 해소** 동시.
- **한국 진입 여부 (WebSearch 검증)**:
  - 한국어 출시? Character.AI 한국어 가능 (다중 페르소나 그룹챗 기능 한국어 OK)
  - 한국 클론 존재? 한국형 다중 페르소나 그룹챗 = **0건** (제타·러비 등 한국 AI 친구는 1:1 챗봇형)
  - 결론: **부분 진입 (Character.AI), 한국형 메커니즘 0**
- **한국 페인 매칭**:
  - "친구한테 물어보고 싶은데 부담스러움" 페인 (옷·관계·진로·소비 결정)
  - 단톡방 문화 = 다중 의견 듣기에 익숙
  - 50+ 1인 가구 "결정 도와줄 사람 없음" (사회조사: 1인가구 도움받을 사람 비율 전체 평균 미달)
