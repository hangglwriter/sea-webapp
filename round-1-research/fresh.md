## 카테고리 #1: "내 책의 등장인물과 카톡으로 토론하는 AI 독자 시뮬레이터" (AI Book Club Persona Reader)

- **흥미 시그널**: 위너책쓰기 수강생이 자기 초고를 업로드 → AI가 "주인공/조연/적대자" 페르소나 분리 + "이 책의 가상 독자 5명(20대 직장인 / 40대 워킹맘 / 60대 은퇴자 등)"이 자기들끼리 단톡방을 만들어서 챕터별 진짜 후기·논쟁. 사용자는 그 단톡방을 "관전" + 끼어들기. "내가 쓴 글이 살아 움직인다" 감각. 출간 전 베타테스트가 단톡방 한 화면.
- **신생도 검증**: BookNPC(이북 캐릭터 음성 분리), AI Book Club, Trevari 같은 게 있지만 **"내가 쓴 원고로 작중 인물 + 가상 독자 단톡방을 5분 만에 생성"** 형식 클론 0건 확인. Character.AI는 유명 캐릭터, Jenova는 작가 본인용 worldbuilding. 위너책쓰기 7주 코칭 한국 시장 클론 0건. (Sources: BookNPC, Trevari, Jenova - 검색결과 #4, #8, #1)
- **민티 본업 연계**: ⭐⭐⭐ 만점. 위너책쓰기 7주차 "독자 피드백" 회차 그대로 강의 한 회. 행글라이터 영상 "AI한테 내 책 욕먹어보기" 1편 즉시. 전자책 출판 본인 사례 즉시.
- **바이럴 시그널**: "내 책 욕한 단톡방 캡처" 인스타 공유. "60대 어머니 페르소나가 내 자서전 읽고 운 단톡방" 트위터.
- **수익 모델 단서**: 무료 = 챕터 1개 + 페르소나 3명. 유료 월 2.9만원 = 원고 전체 + 페르소나 10명 + 단톡방 무한 + PDF 리포트.
- **1차 사용자 자산 모집**: 행글라이터 영상 1편 → 위너책쓰기 수강생 + 출판 준비 독자 + 자서전 쓰는 50-60대. 모집 1000+ 가능.
- **출처**: https://www.booknpc.com/ , https://www.jenova.ai/en/resources/ai-interactive-fiction , https://m.trevari.co.kr/

## 카테고리 #2: "내 콘텐츠 시안을 가상 청중 100명한테 미리 보여주는 AI 패널" (Audience Simulator for Creators)

- **흥미 시그널**: 영상 썸네일 / 인스타 카드뉴스 시안 3종 / 책 제목 후보 5개 → AI 페르소나 100명(20대 여대생 / 30대 워킹맘 / 40대 자영업자 등)이 각자 "내가 왜 클릭/스킵하는지" 한 줄 답변 + 클릭률 백분율. "출시 전에 진짜 사람들 반응 알았으면" 욕망 직격. 민티가 매주 썸네일 5종 만들 때 쓰는 노하우 자동화.
- **신생도 검증**: Ask Rally(글로벌, B2B 대기업용, 영문, 월 $99+) 존재. **한국어 + 콘텐츠 크리에이터용 + 썸네일·카드뉴스 시안 비교 형식** 클론 0건. 한국 시장 사례 0건. (Sources: 검색결과 #9 Ask Rally, Synthetic Personas)
- **민티 본업 연계**: ⭐⭐⭐ 만점. 행글라이터 채널 자체가 본인 검증 베드 + 시연 콘텐츠. 콘텐츠 마케팅 대행 인테리어 회사 클라이언트 즉시 활용. 강의 한 챕터.
- **바이럴 시그널**: "AI 100명한테 썸네일 5개 보여줬더니 의외의 결과" 유튜브 쇼츠. 카드뉴스 시안 A/B/C 비교 캡처 인스타.
- **수익 모델 단서**: 무료 = 페르소나 10명 / 월 5회. 유료 월 1.9만원 = 페르소나 100명 / 무제한 + 페르소나 커스텀(우리 인스타 팔로워 페르소나 만들기).
- **1차 사용자 자산 모집**: 행글라이터 구독자 = 100% 잠재 사용자. 영상 1편으로 2000+ 즉시.
- **출처**: https://askrally.com/ , https://every.to/podcast/100-ai-personas-said-you-d-click-this , https://www.delve.ai/blog/synthetic-personas

## 카테고리 #3: "내 글이 쌓이면 나 대신 글 쓰는 AI 분신" (AI Ghostwriter Cognitive Mirror)

- **흥미 시그널**: 민티가 지난 3년치 본인 글(블로그/유튜브 자막/책 원고) 업로드 → AI가 "민티 어투/관점/페인 계층/가치관"을 학습 후 분신 생성. 사용자는 "분신아, 오늘 행글라이터 영상 대본 써줘" / "내가 작년에 이 주제로 뭐라고 했었지?" 질문. 결과물이 "내가 쓴 줄 알았는데"라는 감각. 콘텐츠 자가증식 + 영혼 보존 동시.
- **신생도 검증**: Karpathy LLM Knowledge Base 패턴 / Forte Labs AI Second Brain 글로벌 있음. **한국 콘텐츠 크리에이터 + 자기 어투 학습 + 다음 콘텐츠 자동 시드** 형식 한국 클론 0건. (Sources: Karpathy 시스템, Forte Labs, Building a Second Brain)
- **민티 본업 연계**: ⭐⭐⭐ 만점. 민티 본인 3년치 콘텐츠가 가장 풍부한 입력. 위너책쓰기 "내 스타일 어휘집" 회차. 행글라이터 "Claude로 내 분신 만들기" 시리즈 3편.
- **바이럴 시그널**: "AI한테 내가 쓴 글 1000편 먹였더니" 영상. "분신이 쓴 글 vs 내가 쓴 글 블라인드 테스트" 콘텐츠.
- **수익 모델 단서**: 무료 = 글 100편 업로드 / 분신 1개. 유료 월 3.9만원 = 무제한 글 + 분신 무제한 + 다음 콘텐츠 시드 자동 생성.
- **1차 사용자 자산 모집**: 행글라이터 구독자 중 본인 블로그/유튜브 가진 미니 크리에이터. 영상 1편 1500+.
- **출처**: https://fortelabs.com/blog/introducing-the-ai-second-brain/ , https://codersera.com/blog/karpathy-llm-knowledge-base-second-brain/ , https://hitsuyoaku.substack.com/p/i-built-an-ai-ghostwriter-that-actually

## 카테고리 #4: "내 책 1줄을 인터랙티브 단편소설로 분기 분열시키는 도구" (Choose Your Own Story Spawner)

- **흥미 시그널**: 사용자가 한 문장 ("주인공이 회사를 그만뒀다") 입력 → AI가 5-7개 갈림길 자동 분기 + 각 갈림길마다 또 5-7개 → 30분 만에 인터랙티브 단편소설 완성 + 웹 링크 공유. 독자는 자기 선택지로 결말 본인 결정. 작가는 결말 X개 동시 출판. 위너책쓰기 수강생이 "내 자서전을 인터랙티브로 만들기" + "독자가 내 인생 선택지를 따라 살아보기".
- **신생도 검증**: ChooseYourStory.com(영문, 2000년대 커뮤니티), Adventr(영상 분기), Talefy(글로벌, AI 스토리). **한국어 + AI 분기 자동 생성 + 인스타/카톡 공유 링크 + 5분 완성** 클론 0건. 한국 인터랙티브 이북 시장 거의 비어 있음. (Sources: ChooseYourStory, Talefy, 한국 출판시장 2026)
- **민티 본업 연계**: ⭐⭐ 강. 위너책쓰기 "독자 참여형 자서전" 회차. 행글라이터 "AI로 5분만에 분기 소설 만들기" 영상. 전자책 신규 카테고리 (인터랙티브 자서전).
- **바이럴 시그널**: 카톡으로 "내 인생 분기 살아보기 링크" 공유. "내가 만약 그때 X 선택했다면" 추억 마케팅. 인스타 스토리 공유 강함.
- **수익 모델 단서**: 무료 = 분기 30개 / 월 1개 작품. 유료 월 1.9만원 = 분기 무제한 + 자기 도메인 + 독자 통계 + EPUB 출력.
- **1차 사용자 자산 모집**: 위너책쓰기 수강생 즉시 + 자서전 쓰는 50-60대 + 행글라이터 구독자 글쓰기 관심층. 1000+.
- **출처**: https://chooseyourstory.com/ , https://talefy.ai/ , https://www.professionalghostwriter.com/blog/top-50-book-publishing-companies-in-south-korea/

## 카테고리 #5: "내 책 한 권 쓰는 7주를 게임으로 만든 인큐베이터" (Book Writing Incremental Game)

- **흥미 시그널**: Universal Paperclips 메카닉 + 책쓰기. 매일 들어와서 "오늘 시드 한 줄 → AI 챕터 1단락 → 분량 100자 증가 → 페르소나 독자 1명 만족도 +5". 분량/캐릭터/플롯/독자공감/팔로워 5개 자원이 늘어남. 7주 후 책 한 권 + 잠재독자 300명 완성. **"공부 안 하면 죽는 게임처럼, 안 쓰면 게임이 끝난다"** 도파민. 위너책쓰기 7주 + 게임화.
- **신생도 검증**: Universal Paperclips(2017, 게임), AI Book Writing Accelerator(영문, 6주, 게임화 X), Sckoworks 웹소설 AI(한국, 게임화 X). **한국어 + 책쓰기 incremental clicker + 7주 cohort + 1인용 자서전** 형식 클론 0건. (Sources: Universal Paperclips, AI Book Writing Accelerator)
- **민티 본업 연계**: ⭐⭐⭐ 만점. **위너책쓰기 7주 코칭의 디지털 버전 자체**. 수강생 자가복습 도구 + 신규 리드 마그넷. 행글라이터 영상 "7주 게임으로 책 한 권 진짜로 썼다" 시리즈 7편.
- **바이럴 시그널**: 7주 게임 클리어 인증 스크린샷. "내 책 진척도" 인스타 공유. "오늘 100자 썼다" 카톡 자랑.
- **수익 모델 단서**: 무료 = 7주 무료 / 챕터 3개까지. 유료 19.9만원 (위너책쓰기 동가) = 7주 무제한 + AI 코치 + 출판 EPUB + 위너책쓰기 라이브 1회.
- **1차 사용자 자산 모집**: 위너책쓰기 수강생 + 위너책쓰기 관심 잠재 리드. 행글라이터 영상 1편 2000+ + 위너책쓰기 신규 신청 직격.
- **출처**: https://en.wikipedia.org/wiki/Universal_Paperclips , https://fistbumpmedia.com/ai-author-lab/accelerator/ , https://zdnet.co.kr/view/?no=20240220224140

## 카테고리 #6: "내 영상 대본을 멀티 에이전트 작가실이 짜주는 도구" (AI Writers Room for Creators)

- **흥미 시그널**: 사용자가 영상 주제 한 줄 ("Vrew 3.8 신기능") → AI 에이전트 5명("후킹 카피라이터 / 정보 전달자 / 스토리텔러 / 사실 검증자 / 댓글 도발자")이 자기들끼리 단톡방에서 토론하면서 대본 작성. 사용자는 사회자로 끼어들기. 30분 후 완성 대본 + 토론 로그(콘텐츠 자체로 활용). **"왜 1인 유튜버 대본을 LLM 1개에 시키나, 5명이 토론해야지"** 발상. 행글라이터 자체 워크플로우 (Method C v3) 제품화.
- **신생도 검증**: ScriptGen(Piero/Debbie/Walter 페르소나, 영문, 시나리오용), Squibler, Sudowrite(시리즈 메모리). **한국어 + 1인 유튜버 짧은 영상 대본 + 단톡방 형식 + 토론 로그 콘텐츠화** 클론 0건. (Sources: ScriptGen, Sudowrite Series Folder)
- **민티 본업 연계**: ⭐⭐⭐ 만점. **민티 본인 Method C v3 워크플로우 그대로 제품화**. 행글라이터 영상 "AI 작가 5명한테 대본 시킴" + 강의 "AI 작가실 만들기" 즉시.
- **바이럴 시그널**: AI 5명이 자기들끼리 욕하면서 대본 짜는 단톡방 캡처. "민티 PD가 사회 본 회의록" 인스타.
- **수익 모델 단서**: 무료 = 에이전트 3명 / 월 5건. 유료 월 2.9만원 = 5명 무제한 + 페르소나 커스텀 + 본인 채널 톤 학습.
- **1차 사용자 자산 모집**: 행글라이터 구독자 중 본인 유튜브/인스타 운영자 + 콘텐츠 마케팅 대행 클라이언트. 1500+.

## 카테고리 #7: "나만의 '엄마 페르소나'가 내 콘텐츠를 진짜처럼 욕하는 잔혹한 AI 에디터" (Hostile Critic Persona)

- **흥미 시그널**: "내 글 칭찬해주는 AI"는 이미 다 했는데, **"날 진짜 사랑하는 사람이 진짜로 욕하는 AI"는 없음**. 사용자가 자기 콘텐츠 + 가장 잔혹한 비평가 페르소나(70대 어머니 / 회사 차장님 / 라이벌 친구)를 만들면 → AI가 그 사람 어투로 한 시간 분량 욕 + 약점 + 진짜 개선점. 사용자 반응 = "씨X 맞말이라 더 화남". **재미 + 페인** 동시.
- **신생도 검증**: Rocky.ai 등 enterprise 코칭은 안전한 피드백. Storysnap 진단형. **한국어 + 잔혹 페르소나 커스텀 + 1인 크리에이터 콘텐츠 비평** 클론 0건. "AI한테 잔혹하게 욕먹기" 카테고리 자체가 영문 글로벌도 거의 0. (Sources: Rocky.ai, Storysnap)
- **민티 본업 연계**: ⭐⭐ 강. 위너책쓰기 "혹독한 1차 독자 시뮬레이션" 회차. 행글라이터 "AI한테 1시간 욕먹기" 영상 = 자체 흥미 콘텐츠. 자기 강의 자료 비평도 가능.
- **바이럴 시그널**: "AI 어머니한테 욕먹은 캡처" 인스타 + 트위터. 진심으로 운 후기 댓글 폭주. "MZ 자아 박살남" 콘셉트.
