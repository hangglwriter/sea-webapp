## 메인 Claude 1차 분류 (Steel man + Devil's advocate)

### A급 (R3 토론 살아남을 강력 후보 6개)

#### U1. 작가 마케팅 OS
- **Steel man**: 출간 후 마케팅 절벽 = 페인 #1 만성 우울 강도. 도구가 진짜로 없음. 위너책쓰기 졸업생 풀 300명 + 매년 신규 50-100명 = 자연 자산. 캔바+ChatGPT 5분 컷 불가 (책 한 권 분량 = 50시간). B2B 출판사 진입 가능.
- **Devil's advocate**: 한국 자가출판 시장 작아서 ARR 1억 너무 낙관. 180일 콘텐츠 캘린더 자동 생성 = 콘텐츠 양 많아질수록 품질 의심. 작가가 진짜 매일 자동 콘텐츠 활용? "콘텐츠 잘 만들 시간 없어서 도구 산 작가가 자동 콘텐츠 검토할 시간이 있나"의 모순.

#### U2. 1인 책쓰기·강의 코치 7주 OS
- **Steel man**: 민티 본인 = 보장 결제 + 매주 사용 (도그푸딩 최강). 카톡 알림톡 한국 진입 장벽 = lock-in. B2B SaaS 모델 명확. Year 2 ARR 5000만+ 현실.
- **Devil's advocate**: 한국 책쓰기 코치 100명 = 시장 너무 작음. 카카오비즈니스 API 비개발자 셋업 = 마찰. lock-in 효과 검증 X. 첫 결제는 보장이나 확장 어려움.

#### F1. AI 가상 독자 5명 단톡방
- **Steel man**: 위너책쓰기 7주차 "독자 피드백" 회차 즉시 도구 = 매주 검증 + 마케팅 자료. 인스타 단톡방 캡처 바이럴. 흥미 + 페인 (출간 전 검증) + 수익 (월 2.9만원) 균형. 행글라이터 영상 1편 직격.
- **Devil's advocate**: Character.AI 페르소나 채팅 + 한국 캐릭터봇 클론 다수. "자기들끼리 단톡" 메카닉 차별성 검증 X. 페르소나 5명 멀티턴 = Claude API 토큰 비용 큼. "내 원고 잘 못 읽는 페르소나"가 진짜 가치 있나.

#### F3. 잔혹 비평가 페르소나 (어머니/차장님)
- **Steel man**: 빌드 60-90분 가장 빠름 = R7 한도 안 여유 + 검증 빠름. 가격 0.99만원 충동 결제. 위너책쓰기 슬럼프 회차 + 행글라이터 영상 "AI한테 1시간 영혼파괴" 흥미 폭발. 한국 글쓰기 슬럼프 검색량 보편.
- **Devil's advocate**: 가격 낮아 매출 작음 (1000명 × 1만원 = 1000만원, 시장 작음). 윤리 마찰 (우울증 트리거?). "AI한테 욕먹는 도구" = 1회성 충동 결제 후 재사용? 의심. "AI 비평" 카테고리 클론 1+ 글로벌 (Storysnap 등).

#### F2. AI 청중 100명 썸네일 사전투표소
- **Steel man**: 행글라이터 채널 자체 도그푸딩 (매주 썸네일 5종). 인테리어 클라이언트 즉시 B2B. Ask Rally 한국어 + 1인 크리에이터 클론 0건. 시그널 명확 (클릭률 %).
- **Devil's advocate**: AI 청중 시뮬레이션 정확도 의심 (실제 사람 vs AI 추정 갭 검증 X). Thumblytics 진짜 사람 패널 신뢰도 높음. 토큰 비용 ($0.5-1/회) = 마진 검토 필요.

#### D2. 살아 움직이는 책
- **Steel man**: 카테고리 신생 (출간 후 6개월 자가 증식 + 독자 투표 분기, 글로벌 0건). 페인 #1 완전 반전 (출간 후 매출 발생 패턴). 칠십 비로소 자서전 시장 직격. 한국 50-60대 자서전 매년 수천 권.
- **Devil's advocate**: "AI 분량 = 작가 가치 희석" 도덕성 시비 거대 (한국 AI 책 9000권 출판 논란 진행중). 독자가 매일 들어와서 투표할 동기? 일반 자서전은 1회 읽기 끝. 1회권 9.9만원 = 시장 너무 작음. cron 인프라 마찰.

### B급 (살아남을 가능성 있으나 약점)

#### U3. 유튜브 채널 → 책 1권 변환
- 행글라이터 도그푸딩. 9.9만원 1회권 + KDP 매출.
- **약점**: 챕터당 5000-8000자 자동 생성 품질 의심. 사용자 1-2주 수정 = "자동" 약속 못 지킴. 한국 KDP 시장 작음.

#### U4. 1인 대행 리포팅 + 영업자료 OS
- 민티 인테리어 클라이언트 즉시 + B2B 명확.
- **약점**: 인스타 그래프 API + 유튜브 API + 네이버 블로그 RSS 셋업 마찰 큼. 비개발자 OAuth 진입 장벽. MVP 한계 (수동 paste만).

#### U5. 강사 부교재 5종 묶음
- 민티 강사 도그푸딩 + B2B 사내 강사 매출 큼.
- **약점**: 캔바+ChatGPT 5분 컷 가능 영역에 가까움 (PPT 텍스트 생성 부분). 차별성 = 5종 묶음 자동인데 검증 약함.

#### F4. 7주 책쓰기 incremental 게임
- 위너책쓰기 리드 마그넷 + 매출 직격 (월 1000만원 시나리오).
- **약점**: 빌드 120분 빠듯. 한국 incremental 게임 사용자층 작음. 진짜로 7주 게임으로 책 완성? 의심.

#### F5. AI 직원 5명 매일 출근 단톡방
- F1과 메카닉 유사 + B2B 인테리어.
- **약점**: 매일 9시 알림 cron 필요 (MVP 한계). F1과 중복 (둘 다 페르소나 단톡방). 차별성 작음.

#### D3. 예측 자가 보정 (feedback loop)
- F2 + feedback loop = 신선. 6개월 lock-in 강함.
- **약점**: 사용자가 매주 진짜 데이터 입력 = 마찰 큼. 6개월 후 lock-in 효과 검증 X.

#### D4. 분신 자가 컷
- 의사결정 피로 해결 + 본인 톤 학습.
- **약점**: 1인 크리에이터 본인 손맛 = 자가 컷 받아들임? 검증 X. "AI가 잘라준다" 통제권 상실 트라우마.
