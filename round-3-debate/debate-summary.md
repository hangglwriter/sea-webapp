## 3. 살아남는 후보 5개 (최종 결정)

### Tier 1: 박살에도 강한 4개

#### 1. U4 - 1인 대행 리포팅 + 영업자료 OS
- **살아남은 이유**: user-sim 3명 결제 + meta 부활 권장 + attacker 비교적 약한 박살 + **외부 확장 최강** (한국 1인 마케팅 프리랜서 1만+ / 소규모 에이전시 2000+ / 인테리어 회사 자체 사용)
- **박스 탈출**: 위너책쓰기/행글라이터 비의존 (의심점 #5 해결)
- **사업 모델 진화**: 민티 인테리어 클라이언트 = 1호 케이스 → B2B SaaS 확장 → "AI 회사" 비전 직격
- **약점 (R4 검증)**: OAuth 마찰 (메인 Claude 안내) / 인스타 그래프 API 정책 변화 위험 / 한국 마케팅 대행 시장 정확 규모 검증 필요

#### 2. F2 - AI 청중 100명 썸네일 사전투표소
- **살아남은 이유**: user-sim 3명 결제 + 즉시 가치 (1회 시뮬레이션도 의미) + B2B 트랙 (대행 + 인테리어) + 빌드 빠름 (단일 HTML + Claude API batch)
- **약점**: Ask Rally $20 개인 가능 (fact-check) = 진입 임박. AI 청중 정확도 검증 X (실제 사람 vs AI 갭). 토큰 비용 검토 필요.
- **D3와 통합 검토**: F2 MVP + D3 메카닉 (feedback loop) Phase 2 로드맵 = 자연 진화 가능

#### 3. D3 - 예측 자가 보정 feedback loop
- **살아남은 이유**: F2의 진화 + 6개월 lock-in (Thumblytics/TubeBuddy/Ask Rally 모두 1회성) + user-sim 3명 결제 + 차별성 최강
- **약점**: 사용자가 매주 진짜 데이터 입력 마찰 큼 (YouTube Analytics import 자동화 = Phase 2). 6개월 후 lock-in 효과 검증 X. 시연 어려움 (MVP에서는 "보정 학습" 시연 시나리오 필요).
- **F2와 통합 옵션**: F2 = MVP (즉시 가치) + D3 = Phase 2 (lock-in 진화)

#### 4. D4 - 분신 자가 컷
- **살아남은 이유**: user-sim 3명 결제 + 의사결정 피로 해결 + Blue Pill/UXPin 평가만 (자가 컷 권한 0건) + MVP 빌드 단순
- **약점**: 1인 크리에이터 본인 손맛 통제권 상실 트라우마 (1탭 복원 설계 필요). "AI가 잘라준다" 받아들임 검증 X.
- **D3와 연계 가능**: 분신 학습 = 본인 톤 기반 = D3 청중과 다른 차원의 lock-in

### Tier 2: 위너책쓰기 풀 직격 1개

#### 5. U1 - 작가 마케팅 OS
- **살아남은 이유**: user-sim 2명 결제 (민티+수강생) + 위너책쓰기 졸업생 풀 300명 페인 만성 우울 강도 + 출판사 B2B 진입 가능
- **약점**: 한국 자가출판 시장 작음 (ARR 1억 비현실, attacker 박살). 도그푸딩 박스 일부. 180일 캘린더 양 많아질수록 품질 의심.
- **남은 이유**: 페인 강도가 가장 명확한 1개 (페인 #1 출간 후 절벽). 위너책쓰기 외부 확장 검증 = R4 수익성 평가자 영역.

1. **"민티 매칭 = 보수 트리거" 작동 금지** - 도그푸딩 강조만으로 +점수 X. 외부 확장 = 수익성 핵심.
2. **2026 AI 시대 패러다임 강제** - 빌드 복잡도 가드레일 우려 점수 차감 X (메인 Claude 안내).
3. **시장 추정 fact-check 강화** - ARR 추정 WebSearch 검증.
4. **자가 점수 X** - 5명 평가자 각자 객관 점수.
5. **80점 미만 NO-GO** - 합리화 금지.
6. **거짓 인용 금지** - WebSearch 결과 URL 진짜만.

### 5명 평가자 (병렬)
- **eval-pain** (페인 강도/보편성 25점)
- **eval-utility-fun** (유용성/흥미 20점)
- **eval-differentiation** (차별성 20점, WebSearch 15회+ 의무)
- **eval-revenue** (수익성/시장 크기 20점, WebSearch 5회+ fact-check)
- **eval-feasibility** (실현성 15점, 비개발자 마찰 점수 차감 X)
