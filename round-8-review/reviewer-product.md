- **4점 차감**: API 키 발급 마찰 (-2) + 자가 토론 등장 속도 (-1) + 워드클라우드 한국어 분석 정밀도 (-1).

  - Cloudflare Pages Form / Google Form / Formspree 같은 정적 폼 백엔드 1개 = MVP 90-120분 안에도 가능했음 (영상 시연 URL 보내기 전 1시간 추가). 현 mailto 모델 = 베타 풀 누락 위험 큼.
- **5점 차감**: mailto 모바일 호환성 (-2) + 민티 측 풀 관리 부재 (-2) + 도달률 50-70%로 깔대기 누수 (-1).
